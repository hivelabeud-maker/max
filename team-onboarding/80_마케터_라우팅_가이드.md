# 80. 마케터 에이전트 — "마케터 돌려" 한 마디로 리서치 끝내기

> 읽는 사람: 팀원 전원. 에이전트·스킬을 한 번도 안 써본 사람 기준으로 씁니다.
> 걸리는 시간: 읽기 10분 + 첫 실습 5분.

---

## 0. 한 줄로 말하면

Claude Code에서 **"마케터 돌려 — [카테고리]"** 라고 치면,
경쟁사 조사부터 문제 정의, 아이디어 발산까지 **네 단계가 자동으로 이어서** 돌고,
결과가 **좌측 탭 12개짜리 리서치 대시보드 HTML**로 나옵니다.

레이아웃을 따로 주문할 필요가 없습니다. 마케터를 부르면 그 포맷이 기본값입니다.

## 1. 준비 — agent-pack 설치 (한 번만)

이 폴더의 `agent-pack/`이 마케터 세트 전체입니다. 새 저장소에 옮길 때는 4단계입니다.

```
agent-pack/
├── CLAUDE.md                            → 저장소 루트에 /CLAUDE.md 로
├── agents/  (6개 md)                    → .claude/agents/
├── library/prompts/wide-research.md     → .claude/library/prompts/
└── skills/
    ├── mx-deck-design/                  → .claude/skills/mx-deck-design/
    └── mx-research-dashboard-design/    → .claude/skills/mx-research-dashboard-design/
```

1. **CLAUDE.md를 저장소 루트에 놓는다.** 이게 있어야 Claude가 "마케터 돌려"라는 말을 알아듣습니다.
2. **agents · library · skills 를 `.claude/` 아래 같은 구조로 복사한다.**
3. **Claude Code로 그 저장소를 열고** "시장조사 해줘 — 프리미엄 라면" 이라고 쳐본다.
4. 조사 표가 나오면 성공. **"마케터 돌려 — 프리미엄 라면"** 으로 전체 흐름을 한 번 돌려본다.

> ⚠️ ZIP 파일을 Claude에 그냥 던지면 인식 못 합니다. 압축을 풀어서 위 경로에 파일로 놓아야 합니다.
> ⚠️ 에이전트는 **Claude Code에서만** 자동으로 작동합니다. claude.ai 챗에서는 안 뜹니다 (→ `70_코드_vs_챗.md`).

우리 `max` 저장소는 이미 설치돼 있습니다. 바로 3번부터 하면 됩니다.

## 2. "마케터 돌려" 라고 하면 벌어지는 일 — 4챕터

```
[0. RFP 분석]  →  CH1. 현황 조사  →  CH2. 진단  →  CH3. 문제 정의  →  CH4. 발산
 (RFP 있을 때만)     팩트 모으기       구도·빈자리      문제 한 문장        방향 후보
```

챕터마다 결과물이 하나씩 나오고, 끝나면 **알아서 다음 챕터로 넘어갑니다.**
화면에 `--- CH1 완료. CH2 브랜드 진단으로 넘어갑니다 ---` 같은 줄이 뜨면 넘어간 겁니다.

| 챕터 | 하는 일 | 나오는 것 |
|---|---|---|
| 0. RFP 분석 | 제안요청서를 명시 요구·숨은 니즈·미정의·위험으로 쪼갬 | 니즈 4분류 + 되물을 질문 3개 |
| CH1. 현황 조사 | **판단 없이 팩트만.** 경쟁사·트렌드·레퍼런스 수집 | 브랜드 분석 표(출처 URL 포함), 트렌드 카드, 레퍼런스 그리드 |
| CH2. 진단 | 모은 팩트를 지도로. **여기서 처음 판단** | XY 포지셔닝 맵, 빈자리 목록(기회냐 함정이냐) |
| CH3. 문제 정의 | 진단을 한 문장으로 증류 | "[타깃]은 [상황]에서 [불편]을 겪는다. 왜냐하면 [원인]." |
| CH4. 발산 | 그 문제를 푸는 방향 후보 | 서로 겹치지 않는 방향 2~3개 + 키워드 |

마지막에 **한 장 요약**(핵심 문제 / 경쟁 구도 / 빈자리 / 트렌드 / 방향 후보)으로 닫힙니다.

## 2-1. CH1은 6스텝을 다 밟습니다 — 경쟁사 목록만 훑고 끝나지 않게

"조사"라고 하면 보통 경쟁사 몇 개 훑는 걸로 끝납니다. 그러면 뒤 단계가 전부 얕아집니다.
그래서 CH1은 아래 6스텝이 정해져 있습니다.

| 스텝 | 무엇을 조사하나 | 최소 조사량 |
|---|---|---|
| S1. 카테고리 정의 | 이 시장이 어디까지인가. 뭐가 이 시장이고 뭐가 아닌가 | 정의 1문단 + 옆동네 카테고리 2개 |
| S2. 시장 규모·추이 | 얼마나 큰 시장인가, 크고 있나 줄고 있나 | 숫자 3개 (각각 몇 년 기준인지 + 출처) |
| S3. 공급측 = 경쟁사 | 브랜드들이 뭘 팔고 뭐라고 말하나 | 빠르게 5~8개 / 제대로 15~30개 |
| S4. 수요측 = 소비자 | **손님이 실제로 쓰는 말.** 왜 사고 왜 안 사나 | 리뷰·커뮤니티 원문 10건 이상 |
| S5. 이종업계 | 같은 문제를 다른 업계는 어떻게 풀었나 | 사례 3개 |
| S6. 트렌드·레퍼런스 | 요즘 흐름 + 훔칠 포인트 | 트렌드 3개 + 레퍼런스 5개 |

- **"빠르게"라고 해도 S1·S2·S3·S6은 무조건 돕니다.**
- **"제대로 조사해줘"** 라고 하면 S4·S5까지 돕니다.
- **S4가 제일 중요합니다.** 브랜드가 하는 말만 모으면, 나중에 나오는 포지셔닝 맵의 축이
  결국 광고 문구를 옮겨 적은 게 됩니다. 축은 손님이 쓰는 말에서 나와야 합니다.

### 자료는 등급을 매겨서 걸러냅니다

| 등급 | 무엇 | 쓰나 |
|---|---|---|
| T1 | 통계청, 상장사 공시, 공식 발표, 협회 통계 | ⭕ 가장 신뢰 |
| T2 | 주요 언론 보도, 유료 리서치 리포트, 논문, 어워드 수상작 | ⭕ |
| T3 | 업계 블로그, 개인 리뷰·커뮤니티 글 | ⭕ 단, 손님 말 모을 때만 |
| T4 | 출처 없는 요약글, 광고성 보도자료, AI가 쓴 요약글 | ❌ 본문에서 뺍니다 |

- 숫자에는 **항상 "몇 년 기준"과 출처 링크**가 붙습니다. "크게 성장했다" 같은 문장은 안 씁니다.
- 중요한 숫자는 **출처 두 곳에서 교차 확인**합니다. 값이 다르면 둘 다 적고 왜 다른지 씁니다.
- 못 찾은 건 **"DATA GAP"** 이라고 비워 둡니다. 대충 추정해서 채우지 않습니다.

## 2-2. 어려운 말은 반드시 풀어 씁니다 — 초등 5학년 기준

마케팅 용어를 모르는 사람이 읽어도 이해되게 씁니다. 용어를 지우는 게 아니라 **뜻을 붙입니다.**

| ❌ 이렇게 안 나옵니다 | ⭕ 이렇게 나옵니다 |
|---|---|
| 화이트스페이스를 공략 | **화이트스페이스**(빈자리 — 아무도 안 하고 있는 자리)를 노림 |
| 포지셔닝 맵상 좌하단 군집 | **포지셔닝 맵**(브랜드들이 어디쯤 서 있는지 그린 지도)에서 왼쪽 아래에 몰려 있음 |
| CAGR 12% | 해마다 평균 12%씩 커짐(**CAGR** = 연평균 성장률) |
| 페인포인트 | 불편한 점(**페인포인트**) |

- 같은 용어는 **처음 나올 때 한 번만** 풀어 씁니다. 매번 붙이면 오히려 읽기 나빠집니다.
- 대시보드로 뽑으면 **02 팩트북 뷰 아래에 "이 문서에 나온 말 풀이" 표**가 붙습니다.
- 한 문장에 생각 하나. 너무 길면 자릅니다. 비유는 안 씁니다.

**결과물을 받았는데 못 알아듣는 단어가 있으면 그건 잘못 나온 겁니다.**
`"이 단어 풀어서 다시 써줘"` 라고 하세요.

## 3. 라우팅 — 이렇게 말하면 여기까지 돕니다

전부 돌릴 필요가 없을 때는 챕터 하나만 부르면 됩니다.

| 이렇게 말하면 | 도는 챕터 |
|---|---|
| "RFP 분석" / "과업 분석" | 0 → CH1으로 자동 이어감 |
| "시장조사" / "경쟁사 분석해줘" / "현황 조사" | CH1 |
| "제대로 30개로" | CH1을 30개 심화 조사로 확장 |
| "트렌드 봐줘" | CH1 중 트렌드 파트만 |
| "레퍼런스 찾아줘" | CH1 중 레퍼런스 파트만 |
| "브랜드 진단" / "포지셔닝 맵" / "빈자리 찾아줘" | CH2 |
| "문제 정의" / "진짜 문제가 뭐야" | CH3 |
| "브레인스토밍" / "아이디어 줘" | CH4 |
| **"마케터 돌려" / "리서치 쭉 돌려줘"** | **0 → CH1 → CH2 → CH3 → CH4 전체** |

**쓸 때 요령**: 뒤에 대상을 붙이세요. "마케터 돌려" 만 치면 뭘 조사할지 모릅니다.
- ❌ `마케터 돌려`
- ⭕ `마케터 돌려 — 30대 남성 타깃 프리미엄 라면 카테고리`
- ⭕ `마케터 돌려` + RFP 파일 첨부

## 4. 결과가 어떤 모양으로 나오나 — 리서치 대시보드 12뷰

마케터 결과를 문서나 HTML로 뽑으면 `mx-research-dashboard-design` 스킬이 붙습니다.
**왼쪽에 탭 12개가 세로로 있고, 클릭하면 오른쪽 내용이 바뀌는 화면**입니다.

| 뷰 | 내용 | 어느 챕터에서 오나 |
|---|---|---|
| 00 요약 대시보드 | 결론 먼저 + 진행 상황 + 핵심 지표 | 종합 |
| 01 브리프·문제 정의 | 받은 요청 → 진짜 결정해야 할 문제 | 0 · CH3 |
| 02 브랜드 팩트북 | 대상 브랜드 기본 팩트 | CH1 |
| 03 경쟁 리서치 | 경쟁사 분석 표 | CH1 |
| 04 포지셔닝 맵 | XY 축 위에 브랜드 배치 | CH2 |
| 05 화이트스페이스 | 빈자리 + 기회/함정 판정 | CH2 |
| 06 이종업계 | 다른 업종에서 훔칠 것 | CH1 |
| 07 핵심 인사이트 | 진단에서 뽑은 통찰 | CH2 |
| 08 브랜드 밸류 키워드 | 문제 정의에서 나온 가치어 | CH3 |
| 09 전략 대안 | 방향 후보 비교·점수 | CH4 |
| 10 추천 전략 | 고른 안 + 하지 않을 것 | CH4 |
| 11 출처·근거 추적 | 모든 출처를 티어(T1~T4)로 | 전 챕터 |

**규칙 두 가지만 기억하면 됩니다.**
- **00 요약과 11 출처 추적은 절대 빠지지 않습니다.** 빠졌으면 잘못 나온 겁니다.
- 색은 모노톤 + 포인트 4색 고정입니다. 파랑=T1 핵심, 라임=T2 기회, 핑크=T3 보류, 주황=T4 위험.
  새 색을 만들지 않습니다.

### 덱 스킬이랑 헷갈릴 때

| | `mx-research-dashboard-design` | `mx-deck-design` |
|---|---|---|
| 생김새 | 좌측 탭 12개, 클릭해서 전환 | 슬라이드가 순서대로 스크롤 |
| 쓰는 곳 | **마케터 리서치 결과 (기본값)** | 클라이언트 앞에서 발표하는 제안서 |
| 부르는 말 | "리서치 대시보드로 정리" | "덱 만들어줘" / "제안서로 정리" |

내부 검토는 대시보드, 클라이언트 발표는 덱. 이 한 줄이면 됩니다.

## 5. ⚠️ 기록이 필요하면 반드시 Claude Code에서

리서치 결과는 **파일로 저장해야 남습니다.**

- **챗(claude.ai)에서 돌리면** — 대화창이 닫히는 순간 사라집니다. 검토용 초안까지만.
- **Claude Code에서 돌리면** — `.claude/projects/YYYYMM_프로젝트명/` 에 파일로 저장되고,
  깃허브에 커밋으로 남습니다. 나중에 "그때 왜 그 결론이었지?"를 되짚을 수 있습니다.

저장 위치 규칙:

```
.claude/projects/202608_클라이언트_업무/
├── 00-note.md          ← 프로젝트 노트 (요약 + 원본 로그)
└── 리서치대시보드.html   ← 마케터 산출물
```

산출물을 받으면 **"이거 프로젝트 폴더에 저장해줘"** 라고 한 마디 덧붙이세요.

## 6. 첫 실습 — 5분

1. Claude Code로 `max` 저장소를 연다.
2. `시장조사 제대로 해줘 — 프리미엄 즉석밥` 이라고 친다. ("제대로"를 붙이면 소비자 리뷰까지 봅니다)
3. 세 가지를 확인한다.
   - 브랜드 표에 **출처 URL + 등급(T1~T4)** 이 붙어 있나
   - 시장 규모 숫자에 **"몇 년 기준"** 이 붙어 있나
   - **모르는 단어가 괄호로 풀려 있나**
4. `이어서 브랜드 진단까지 가줘` 라고 친다 → 포지셔닝 맵이 나오는지 본다.
5. `이 결과 리서치 대시보드로 정리해서 프로젝트 폴더에 저장해줘` 라고 친다.
6. 좌측에 탭 12개가 있고, 00·11 뷰가 살아 있고, 02 뷰 아래 **말 풀이 표**가 있으면 정상입니다.

## 7. 자주 막히는 것

| 증상 | 원인 | 해결 |
|---|---|---|
| "마케터"라고 했는데 반응이 없다 | 챗(claude.ai)에서 함 | Claude Code에서 저장소를 열고 다시 |
| 조사는 되는데 대시보드가 안 나온다 | 산출 요청을 안 함 | "리서치 대시보드로 정리해줘" 추가 |
| 슬라이드 덱 모양으로 나왔다 | `mx-deck-design`이 잡힘 | "좌측 탭 12뷰 대시보드로" 라고 명시 |
| 출처가 없다 | 조사 깊이 부족 | "출처 URL과 등급(T1~T4) 붙여줘" |
| 조사가 얕다 | "빠르게" 모드로 돌아감 | "제대로 조사해줘 — 소비자 리뷰까지" (S4·S5 추가) |
| 무슨 말인지 모르겠다 | 용어 풀이 누락 | "이 단어 풀어서 다시 써줘" |
| 결과가 사라졌다 | 파일로 저장 안 함 | 5번 항목대로 프로젝트 폴더에 저장 |
| 탭 12개 중 몇 개가 비었다 | 데이터 부족 | 정상. 빈 뷰는 "DATA GAP"으로 표기되게 요청 |
