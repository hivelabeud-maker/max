## 설치 — 4단계 (Claude Code 저장소 기준)

1. **CLAUDE.md 복사** — `CLAUDE.md` → 새 저장소 루트(`/CLAUDE.md`)
   이게 있어야 Claude가 조직구조(라우팅)를 인식해요.
2. **에이전트·스킬 복사** — 폴더 구조 그대로:
   - `agents/` 내용물 → 새 저장소의 `.claude/agents/`
   - `library/prompts/wide-research.md` → 새 저장소의 `.claude/library/prompts/`
   - `skills/mx-deck-design/` → 새 저장소의 `.claude/skills/mx-deck-design/`
   - `skills/mx-research-dashboard-design/` → 새 저장소의 `.claude/skills/mx-research-dashboard-design/`
   (폴더가 없으면 만들면 돼요. 경로만 같으면 끝.)
3. **확인** — Claude Code로 그 저장소를 열고 **"시장조사 해줘 — [카테고리]"** 라고 불러보세요.
   출처 URL 붙은 브랜드 표 + 포지셔닝 맵이 나오면 성공.
4. **전체 흐름 테스트** — **"마케터 돌려 — [카테고리]"** (RFP 파일이 있으면 첨부).
   RFP 4분류 → 경쟁 구도 → 트렌드·레퍼런스 → 방향 후보까지 쭉 돌면 완료.

> ⚠️ 에이전트는 **Claude Code에서만 자동 작동**해요. 일반 챗(claude.ai)에서는 md 내용을
> 프로젝트 지침에 직접 붙여넣어야 해요. (자세히: [`../60_에이전트_공유하기.md`](../60_에이전트_공유하기.md))

## 쓰는 법 — 4챕터 자동 체이닝

"마케터 돌려"면 아래 4챕터가 자동으로 순서대로 돌아요. 챕터 하나만 요청해도 돼요.

```
[0. RFP] → CH1. 현황 조사 → CH2. 진단 → CH3. 문제 정의 → CH4. 발산
              팩트 수집        구도·빈자리     문제 한 문장      방향 후보
```

| 이렇게 말하면 | 도는 챕터 |
|---|---|
| "RFP 분석" / "과업 분석" | 0 → CH1 자동 이어감 |
| "시장조사" / "경쟁사 분석해줘" / "현황 조사" | CH1 — 팩트 수집 |
| "브랜드 진단" / "포지셔닝 맵" / "빈자리 찾아줘" | CH2 — 구도·빈자리 |
| "문제 정의" / "진짜 문제가 뭐야" | CH3 — 핵심 문제 한 문장 |
| "트렌드 봐줘" / "레퍼런스 찾아줘" | CH1 중 해당 파트 |
| "브레인스토밍" / "아이디어 줘" | CH4 — 방향 후보 발산 |
| **"리서치 쭉 돌려줘" / "마케터 돌려"** | **전체 (0→CH1→CH2→CH3→CH4)** |

산출물은 마지막에 **한 장 요약**(핵심 문제 + 경쟁 구도 + 빈자리 + 트렌드 + 방향 후보 2~3개)으로 닫혀요.

## v8.1에서 더해진 세 가지 — 조사 깊이·자료 품질·읽기 난도

### 1. CH1은 조사 6스텝을 다 밟아요

경쟁사 목록만 훑고 끝나면 뒤 단계가 전부 얕아져요. 그래서 순서를 고정했어요.

| 스텝 | 무엇을 조사하나 | 최소 조사량 |
|---|---|---|
| S1. 카테고리 정의 | 이 시장이 어디까지인가 | 정의 1문단 + 옆동네 카테고리 2개 |
| S2. 시장 규모·추이 | 얼마나 크고, 크고 있나 | 숫자 3개 (기준연도 + 출처 + 티어) |
| S3. 공급측(경쟁) | 브랜드들이 뭘 팔고 뭐라 말하나 | 빠르게 5~8개 / 제대로 15~30개 |
| S4. 수요측(소비자) | **손님이 실제로 쓰는 말** | 리뷰·커뮤니티 원문 10건 이상 |
| S5. 이종업계 | 같은 문제의 다른 업계 해법 | 사례 3개 |
| S6. 트렌드·레퍼런스 | 요즘 흐름 + 훔칠 포인트 | 트렌드 3개 + 레퍼런스 5개 |

- **"빠르게"라고 해도 S1·S2·S3·S6은 무조건** 돌아요.
- **"제대로 조사해줘"** 라고 하면 S4·S5까지 돌아요.
- S4를 빼면 포지셔닝 맵의 축이 결국 광고 문구를 옮겨 적은 게 돼요.

### 2. 자료는 등급을 매겨 걸러요

| 등급 | 무엇 | 본문에 쓰나 |
|---|---|---|
| T1 | 통계청, 상장사 공시, 공식 발표, 협회 통계 | ⭕ |
| T2 | 주요 언론, 유료 리서치 리포트, 논문, 어워드 | ⭕ |
| T3 | 업계 블로그, 개인 리뷰·커뮤니티 글 | ⭕ 손님 말 모을 때만 |
| T4 | 출처 없는 요약글, 광고성 보도자료, AI가 쓴 요약 | ❌ 뺍니다 |

숫자에는 "몇 년 기준"과 출처가 붙고, 핵심 수치는 두 곳에서 교차 확인해요.
못 찾은 건 추정으로 채우지 않고 **DATA GAP**으로 비워 둬요.

### 3. 어려운 말은 풀어 써요 — 초등 5학년 기준

용어를 지우는 게 아니라 뜻을 붙여요. `화이트스페이스(빈자리 — 아무도 안 하고 있는 자리)` 처럼요.
같은 말은 처음 나올 때 한 번만 풀고, 대시보드에는 **02 팩트북 뷰 아래 「이 문서에 나온 말 풀이」 표**가 붙어요.

> 결과물에 못 알아듣는 단어가 있으면 그건 잘못 나온 거예요. **"이 단어 풀어서 다시 써줘"** 라고 하세요.
