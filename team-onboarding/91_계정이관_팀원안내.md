# 91. 클로드 계정 초대를 받으면 — 무엇을 눌러야 하나

> **누가 읽나**: 팀 클로드(Claude) 초대 메일을 받은 사람 전원
> **왜 읽나**: 초대를 수락하면 선택 화면이 뜬다. **한 번 고르면 되돌릴 수 없다.**
> 잘못 고르면 지금까지 나눈 대화가 전부 사라진다.
> **읽는 시간**: 3분

---

## 1. 먼저 확인할 것 — 내 클로드 계정 이메일

지금 클로드에 로그인한 이메일이 **회사 메일**인지 본다.

- 회사 메일이면 → 2번으로
- 개인 메일(지메일 등)이면 → **4번으로** (옮기는 방법이 다르다)

확인하는 곳: claude.ai → 왼쪽 아래 내 이름 → 설정(Settings)

---

## 2. 초대를 수락하면 이 화면이 뜬다

세 갈래 중 하나를 고른다.

| 고르는 것 | 어떻게 되나 |
|---|---|
| **두 계정 유지** | 개인 계정이 그대로 살아 있다. 회사 계정과 번갈아 쓴다 |
| **조직 계정만 사용 → 데이터 가져오기** | 대화·프로젝트·파일이 회사 계정으로 옮겨진다. 개인 계정은 닫힌다 |
| 조직 계정만 사용 → 데이터 삭제 | 개인 계정이 닫히고 **아무것도 안 옮겨진다** |

### 👉 우리 팀은 **"조직 계정만 사용 → 데이터 가져오기"** 를 고른다

두 계정을 유지하면 어느 쪽에서 일했는지 매번 헷갈린다. 그리고 팀이 볼 수 없는 개인 계정에 업무 대화가 계속 쌓인다.

> 유료(Pro·Max)를 쓰고 있었다면 남은 기간은 환불된다.
> 바로 안 고르면 일주일 정도 배너로 다시 물어본다. 그 안에 정한다.

---

## 3. 무엇이 따라오고 무엇이 안 따라오나

| 따라온다 ✅ | 안 따라온다 ❌ |
|---|---|
| 대화 전체 | **스킬** (클로드에 만들어 둔 기능) |
| 프로젝트 | 다른 앱 연결 (구글 드라이브 등) — 회사 계정에서 다시 연결 |
| 올린 파일 | 남에게 보낸 **공유 링크** — 영구히 안 열린다 |
| 메모리 (클로드가 기억하는 내 정보) | Cowork 클라우드 작업물 |

### 옮기기 전에 할 일 2가지
1. **공유 링크를 남에게 보낸 적 있으면** 그 사람에게 미리 알린다. 링크가 끊긴다
2. **Cowork에서 만든 파일**이 있으면 미리 내려받는다

> 우리 팀 스킬·에이전트는 걱정 안 해도 된다. 전부 깃허브 저장소에 파일로 있어서 계정과 상관없이 따라온다.

---

## 4. 개인 메일로 쓰고 있었다면

회사가 만든 팀 계정과 이메일이 다르면 **자동으로 옮기는 기능이 없다.** 손으로 옮긴다.

1. **내보내기** — claude.ai → 설정 → 개인정보(Privacy) → 데이터 내보내기. 메일로 파일이 온다
2. 받은 파일은 **읽기용**이다. 회사 계정에 다시 넣는 기능은 없다
3. 계속 쓸 것만 골라 손으로 옮긴다 — 프로젝트 설명, 올려둔 자료, 자주 쓰는 명령문
4. 자주 쓰는 명령문은 대화에 두지 말고 **저장소에 올린다**. 그러면 다음에 또 이 일을 안 한다
   - 올리는 곳: `.claude/library/prompts/`
   - 올리는 법을 모르면 김효정에게 요청한다

---

## 5. 결제 주의 (해당되는 사람만)

**아이폰 앱스토어로 클로드 유료 결제를 하고 있었다면**, 개인 계정이 닫혀도 애플이 계속 돈을 뺀다.
애플 쪽에서 따로 해지한다: 아이폰 설정 → 내 이름 → 구독 → Claude → 구독 취소
