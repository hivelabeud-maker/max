# 99. 우리 팀 규칙 (회사 고유값)

> 나머지 문서(00~90)는 어느 팀이든 그대로 쓸 수 있는 **공통 자산**이고, 이 파일이 **우리 회사 값을 채우는 칸**이다.
> **표기**: ✅ 확정 = 저장소 문서로 이미 정해진 값 · ❓미정 = 사람이 정해야 하는 값
> 미정 항목을 채우는 순서는 `90_팀전환_마이그레이션.md` 참조.
> 최근 갱신: 2026-09-11 (팀 전환)

## 2. 접근·보안 규칙
| 항목 | 값 | 상태 |
|---|---|---|
| 기밀 등급 | 공개 / 내부 / 대외비 3단계 | ✅ 확정 |
| 입력 금지 | 개인정보(실명+연락처·이메일·주민번호·계좌), 단가·견적 원본, 토큰·API 키·비밀번호, 미공개 계약 조건, NDA 대상 자료 | ✅ 확정 (`CLAUDE.md` 팀 운영 규칙 2번) |

| 파일 차단 | `.gitignore`가 `unit-rates.md` · `quote-sot/` · `data-sources.md` · `.env` · `*.key` 등을 막는다 | ✅ 확정 |
| 외부 반출 | 클라이언트 발송물은 발송 담당이 아래 3게이트를 거친 뒤 실장 최종 OK | ✅ 확정 |
| 발송 전 검수 게이트 | ① `fact-checker`(사실·숫자) → ② `tone-guardian`(톤) → ③ `delivery-gate`(라이트모드·PII·잘림) | ✅ 확정 |
| 사고 시 | 민감정보를 넣었으면 줄을 지우는 걸로 끝나지 않는다(이력에 남는다). 즉시 오너에게 알린다 | ✅ 확정 |
