> **2026-09-04 갱신**: 스킬 카드·궁극기 슬롯·보스 컷인·엔드카드 화면을 전부 걷어낸

| 항목 | 규칙 | 이유 |

| 배경 | **투명 PNG 권장.** 순백(#FFFFFF) 배경도 자동 제거됨 | 회색/그라데이션 배경은 경계가 지저분해짐 |

| 안티에일리어싱 | 도트 원화는 **끄고** | 흐린 픽셀은 확대 시 뭉개짐 |

## 1. 캐릭터 — 프레임 시퀀스 (필수)

**애니메이션 시퀀스 3벌**이 필요하다. 정지 이미지 1장이 아니라 **폴더당 여러 장의 번호 붙은 프레임**.

```
src/art/raw/seq/<캐릭터>_idle/이름-idle_00.png, _02.png, _04.png ...
src/art/raw/seq/<캐릭터>_run/이름-run_00.png ...
src/art/raw/seq/<캐릭터>_fire/이름-attack_00.png ...   (발사/공격 동작)
```

- 프레임 번호는 **건너뛰어도 된다** — `tools/prep_anim.py`가 지정한 매수만큼 균등 샘플링한다
- 세 시퀀스(idle/run/fire)는 **캔버스 크기가 서로 달라도 된다** — 캔버스 중심 기준으로 자동 정렬된다
- 무기는 캐릭터에 붙여서 그려도 됨
- 받침대·원형 디스크 없이, 발이 바닥에 닿게

**교체 지점** — `tools/prep_anim.py`의 `CHARS` 잡 하나 추가 + `src/data/character.js`의 `id`/`hLogic`/`feet`
(feet 좌표는 실측 필요 — 눈대중 금지, [실패 이력] 참고)

---

## 2. 몬스터 — 종류당 걷기 시퀀스 1벌

지금은 5종. 각각 **걷기 애니메이션 프레임 여러 장**(정지 1장 아님).

```
src/art/raw/seq/m_<이름>_walk/원본이름-walk_00.png, _02.png ...
```

| 역할 | 목표 높이(px) | 비고 |
|---|---|---|
| 잡몹 (물량, 색만 다르게 3종) | 96 | 가장 많이 나옴 |
| 헬멧형 (약간 더 강함) | 104 | |
| 엘리트 (가장 강함, **실루엣이 확연히 달라야 함**) | 120 | 색만 다른 확대판은 "같은 놈 확대"로 읽힘 |

**광고에서 위계는 색이 아니라 실루엣으로 읽힌다.** 잡몹과 엘리트가 윤곽부터 달라야
"작은 게 몰려온다 → 강한 게 나온다"가 3초 안에 전달된다.

**교체 지점** — `tools/prep_anim.py`의 `MONS`(높이) + `MON_ANIMS`(애니 이름) 리스트,
`src/data/enemies.js`의 `ENEMY_SET.types`(hp/speed/dmg/hLogic)

## 4. UI 아이콘 6종 (선택 — 없으면 도트로 자동 폴백)

```
src/art/raw/ui/<이름>.png
```

없으면 `tools/gen_icons.py`가 만든 도트 아이콘으로 게임이 그대로 완주된다.
**퀄리티를 올리고 싶을 때만** 아래 6개를 채워 넣으면 된다.

| 파일명 | 쓰이는 곳 | 목표 높이(px) | 비고 |
|---|---|---|---|
| `ic_kill.png` | 상단 처치 카드 + 결과 화면 | 128 | 아이콘만, 숫자는 코드 |
| `ic_time.png` | 상단 생존 카드 + 결과 화면 | 128 | |
| `ic_reward.png` | 결과 화면 보상 행 | 128 | |
| `ic_hp.png` | 하단 HP 게이지 왼쪽 | 128 | |
| `title_clear.png` | 결과 화면 상단 타이틀 | 500 | "STAGE CLEAR" 자리 — 문구는 코드가 얹으므로 **글자 없이** |
| `btn_cta.png` | 인게임 + 결과 화면 **공용** 설치 버튼 | 폭 기준 920 | **3분할(좌캡/중앙 늘림/우캡)**로 그려야 문구 길이가 달라져도 안 깨진다. 표시 문구는 코드가 얹으므로 **글자 없이** 비워서 |

표시 크기의 2~3배로 구워서 주면 축소 렌더 시 항상 선명하다(위 px가 이미 그 배율 반영값).

**퀄리티 스킨**: 위 이미지를 안 줘도 `--uihd`/`--dot` 빌드 플래그로 벡터 드로잉 스킨을 바꿀 수 있다
(다크 퍼플 프레임+스터드 / 도트 프레임). 이미지와 벡터 스킨은 **같이 못 쓴다** — 이미지가 있으면 이미지가 우선.

## 5. 지금 화면에 있는 게 전부다 (참고 — 여기 없는 요소는 발주하지 않는다)

이전 버전 문서에 있던 **스킬 슬롯·스킬 칩·궁극기 게이지·BOSS 컷인 띠·엔드카드 화면**은
전부 삭제됐다. 지금 화면은 딱 두 장면뿐이다.

1. **플레이 화면** — 상단 처치/생존 카드 2개, 캐릭터 위 HP바(위험할 때만), 하단 HP 게이지 + CTA 버튼
2. **결과 화면** — 타이틀 + 처치 수(히어로) + 생존시간/보상(반폭 2개) + 다시하기/CTA

새 IP로 바꿀 때 **이 두 장면 밖의 것을 발주하지 말 것** — 코드에 자리가 없다.
