## Context — 왜 만드는가

넷마블 브리프(`docs/reference/브리프_넷마블_2차.jpg`)에는 레퍼런스가 둘이다.

| | 레퍼런스 | 우리 프로젝트 |
|---|---|---|
| 1 | 어두운 우주 + 네온 탄막 디펜스 | `neon_defense_playable` (완료) |
| 2 | **Pop Orb** — 순검정 + 원색 공 터뜨리기 | **이 프로젝트** |

같은 브리프의 **두 번째 방향**이다. 1과 A/B 로 돌릴 수 있게 별도 프로젝트로 만든다.
코어 루프가 다르므로 스킨 추가가 아니라 새 게임이다.

### 레퍼런스 실측 (`docs/reference/레퍼런스_poporb_*.png` · 원본 19.87초 화면기록)

원본 영상을 프레임 단위로 뜯어 확인한 사실만 적는다.

**플레이어**
- 시안 오브 + 흰 막대(조준 방향). 막대는 총구다
- **거의 움직이지 않는다.** 1.2초간 좌표 (283,332) → (281,349) — 사실상 제자리 부유
- 조준만 회전한다. 조준을 훑으면 탄 줄기가 곡선으로 남는다 —
  레퍼런스에서 보이는 "점선 궤적"의 정체가 이것이다 (궤적 예측선이 아니다)

**표적**
- 회색·파랑·초록·주황·빨강 원이 떠다닌다. 크기가 제각각이다
- 큰 원 주변에 작은 원이 겹쳐 있는 프레임이 여러 장 있다 → **분열**로 판단했다.
  큰 공을 터뜨리면 작은 공으로 쪼개진다. 콤보 x76 같은 수치는 분열 연쇄로만 설명된다

**escalation (약 13초 게임 + 클리어 + 루프)**
| 시각 | 화면 |
|---|---|
| 0~2s | 평온. 오브 하나 + 표적 몇 개 |
| 3~5s | `COMBO x7` → `x8`, `BONUS +75`, 배너 **`Tempo Up!`** |
| 6~11s | **`HYPER FRENZY!!` / `COMBO x50`~`x76` / `DOMINATION xN`**. 화면 전체 금색 폭발 |
| 12s | **`ROUND CLEAR` / `NEW UNLOCKED: ICE FREEZE BALLS!` / `CLEAR BONUS +3,520` / `NEXT ROUND IN 3...`** |
| 이후 | 루프 |

**HUD**
- 상단 앱바: 둥근사각 아이콘 + 타이틀
- 좌: `ROUND 2` (시안 소문자 대문자)
- 중앙: 대형 점수 + `GOAL: 4,600 LEFT` + `COMBO xN` / `BONUS +N`
- 우: `TOP RANKED` / 랭커명 / 점수
- **하단 중앙: 도넛형 조이스틱** (회색 링 + 밝은 노브)
- HP 게이지가 없다. 실패 조건은 체력이 아니라 목표·시간이다

## 확정 사항 (2026-09-09 · 실장 결정)

| 항목 | 결정 | 영향 |
|---|---|---|
| 플레이어 | **리타** (1차와 동일) | 넷마블 IP 노출 유지. 추상 오브 대신 픽셀 캐릭터 + 조준 막대 |
| 하단 배치 | **조이스틱 중앙 + CTA 그 위** | 레퍼런스 배치를 지키고 CTA 는 조이스틱 위 띠로. 플레이 영역이 줄어든다 |
| 컬러 톤 | **Pop Orb 그대로** (순검정 + 원색) | 1차 네온 우주 톤과 의도적으로 다르게 간다 — A/B 시 변인이 "게임 방식"으로 좁혀진다 |

### 조이스틱은 실제로 동작한다
"눌러도 반응 없는 버튼 = 광고 이탈 요인"이다. 조이스틱은 장식이 아니라
`Input` 드래그를 받아 조준을 돌린다. 안 만지면 오토플레이가 대신 훑는다.

### ⚠️ 레퍼런스에서 가져오면 안 되는 것
- **타이틀 `Pop Orb`** — 타 사 게임명이다. 넷마블 광고에 그대로 넣으면 안 된다.
  `THEME.appTitle` 한 줄로 빼뒀다
- **랭커명 `Elite_Miner`** — 같은 이유. `THEME.rankName` 으로 뺐다
- **`ICE FREEZE BALLS!`** — Pop Orb 의 콘텐츠다. 해금 문구는 `THEME.unlockText` 로 뺐다

## 1차·2차와의 관계 (무엇을 물려받나)

`neon_defense_playable` 을 복제해 시작했다. 엔진과 도구는 1차에서 검증된 것 그대로다.

| 영역 | 판정 |
|---|---|
| `src/core/` 10개 | ✅ 거의 무수정. `engine.js` 루프 배선만 |
| `tools/` 전부 | ✅ 무수정 (qa.js 규칙 1건 제외 — 아래 참조) |
| `game/player.js` | 🟡 조준·연사·부유로 재작성 |
| `game/bullet.js` | 🟡 표적 판정만 교체 |
| `game/hud.js` | 🔴 재작성 (Pop Orb HUD) |
| `game/screens.js` | 🟡 배경·결과 조정 |
| `game/enemy.js` · `data/enemies.js` | ❌ 삭제 → `game/orb.js` · `data/orbs.js` 신규 |
| `data/neonmob.js` · `game/damage.js` | ❌ 삭제 (2차 1안 전용) |
| 신규 | `game/orb.js` · `game/stick.js` · `data/orbs.js` |

### ⚠️ `roundRect` 위치가 바뀌었다
1차에서는 `game/skill.js` 맨 아래에 전역으로 있었다(hud·screens 가 의존).
이 프로젝트는 `skill.js` 를 지우므로 **`core/stage.js` 로 옮겼다.** 그게 원래 자리다.

### ⚠️ `qa.js` ⑥ 전폭 딤 규칙에 예외를 뒀다
레퍼런스에는 **상단 앱바**(화면 폭 전체를 채우는 어두운 띠)가 있다. 이건 규칙이 막으려던
"플레이 화면 위에 깔리는 스크림"이 아니라 앱 UI 그 자체다.
규칙을 우회하지 않고 **검사에 명시적 예외를 넣었다** — 앱바 영역(y < 60) 안의 채우기만
허용하고, 그 아래는 여전히 실패시킨다. 우회했다가 규칙이 무력해지는 게 더 위험하다.

## 작업 계획

### 1단계 — 톤·배경
`theme.js` 를 순검정 + 원색 팔레트로. 배경은 격자·별 없이 **순검정**(레퍼런스가 그렇다).
`screens.js drawBG` 를 순검정 + 아주 옅은 비네트만 남긴다.

### 2단계 — 표적 오브 (`game/orb.js` · `data/orbs.js`)
- 화면 안을 떠다니며 벽에 반사되는 공. 크기 4단계
- 맞으면 **분열**한다: 크기 4 → 3 → 2 → 1 → 소멸. 분열이 콤보 연쇄의 엔진이다
- 색은 원색 6종. 큰 공일수록 어둡고, 작아질수록 채도가 오른다(터질수록 화면이 밝아진다)

### 3단계 — 조준·연사 (`player.js`)
- 리타는 화면 중앙 부근에 부유(상하 호흡). 이동은 미세하게만
- 조준 = 조이스틱 방향. 연사 간격 0.07초 (1차 0.16초의 2배 이상) — 점 줄기가 만들어진다
- 오토플레이: 조준을 스윕하며 표적 밀집 방향을 향한다

### 4단계 — 조이스틱 (`game/stick.js`)
- 하단 중앙 도넛 + 노브. `Input` 드래그를 받아 노브가 따라간다
- 안 만지면 오토 조준 방향을 노브가 따라간다(직접 조작하는 것처럼 보인다)
- ⚠️ CTA 히트박스와 겹치지 않게 할 것. `HUD.hitCTA` 가 먼저 먹으면 조이스틱이 죽는다

### 5단계 — HUD + 콤보 escalation
- 앱바 / ROUND / 대형 점수 / GOAL N LEFT / COMBO xN·BONUS / TOP RANKED
- 콤보 임계값에서 배너: `Tempo Up!`(x8) → `HYPER FRENZY!!`(x30) → `DOMINATION xN`(x50)
- 점수는 `Game.killShown` 스무딩 패턴 복제 — 분열 연쇄로 한 번에 수십 점이 들어온다

### 6단계 — 라운드 클리어 + 결과
- 19.5초에 `ROUND CLEAR` / `NEW UNLOCKED` / `CLEAR BONUS`
- 21.5초 결과 화면 (1차 레이아웃 유지)

### 7단계 — 파이프라인·검수
길이 21.5초 유지 → `qa.js` 하드코딩 상수 그대로 쓸 수 있다.
