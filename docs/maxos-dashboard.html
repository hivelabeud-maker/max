각 역할 에이전트가 담당하는 스킬과 트리거 키워드. 이 목록 중 하나를 말하면 해당 에이전트가 자동으로 활성화된다.

⚡ 빠른 시작 — 업무가 들어오면 3줄

  1. RFP·과업지시서가 있으면 먼저 RFP 분석 → 진짜 니즈부터 잡는다.
  2. 근거가 필요하면 마케터 돌려 → 시장조사·트렌드·레퍼런스·발산이 한 번에 돈다.
  3. 디자인 착수 전 관점 잡아줘 → 브랜드 관점 한 문장을 고정하고 그 위에서 만든다.

새 대화를 열면 마케터가 저절로 켜지나아니다

새 대화창을 열고 프로젝트명만 쳐도 아무 에이전트도 안 켜진다. 켜지는 조건은 하나, 문장 안에 트리거 단어가 있어야 한다. "크래프톤"이라고만 치면 대기 상태다. "크래프톤 RFP 분석해줘"라고 쳐야 rfp-analyst가 켜진다.

지금 CLAUDE.md에는 "새 프로젝트 인입 시 자동으로 마케터부터 돈다"는 규칙이 없다. 자동으로 켜지게 만들고 싶으면 이 한 줄을 CLAUDE.md에 추가하면 된다. 그 전까지는 매번 트리거 단어를 직접 던져야 한다.

레인 조직도는 실제로 이렇게 움직인다 — 예시 1건

가상 프로젝트 "하이브 신작 게임 브랜딩"으로 처음부터 발송까지 따라가 본다. 「레인 조직도」 탭을 같이 열어두고 순서대로 눌러보면 노드가 켜지는 순서와 똑같다.

1
"하이브 신작 RFP 분석해줘"라고 친다 → 인입 박스의 rfp-analyst가 켜진다 → 4분류(명시·숨은·미정의·위험) + 확인 질문 3개가 나온다. MARKETER 진입
2
"마케터 돌려"라고 친다 → MARKETER 레인이 위에서 아래로 순서대로 켜진다: market-research(경쟁 맵) → GATE·리서치 통과 → design-trend-radar → reference-curator → brainstormer(방향 후보 2~3개). MARKETER
3
방향 후보가 나오면 "관점 잡아줘"라고 친다 → STRATEGIST 레인의 concept-director가 켜진다 → 브랜드 관점 한 문장이 고정된다. 이 문장을 이후 모든 매체가 상속한다. STRATEGIST
4
관점이 고정되면 "무드보드 만들어줘" 또는 "키비주얼 뽑아줘"라고 친다 → DESIGNER 레인이 순서대로 켜진다: moodboard-builder → visual-generator → 필요하면 storyboard-maker · figma-bridge. DESIGNER
5
시안이 나오면 "시안 검수"라고 친다 → DIRECTOR 레인이 순서대로 켜진다: design-critique → design-system-guardian → creative-director → fact-checker → tone-guardian → delivery-gate → GATE FINAL. 여기서 하나라도 걸리면 발송이 멈춘다. DIRECTOR

업무 유형이 뭐든 아래 6단계 위를 흐른다. 왼쪽 상황을 만나면 「이렇게 말한다」의 트리거를 던지면 담당 에이전트가 활성화되고 산출물이 나온다.

GATE · 리서치
market-research·트렌드·레퍼런스의 출처·빈자리 근거가 충족돼야 발산(brainstormer)으로 넘어간다.

fact-checker·delivery-gate·tone-guardian를 전부 통과해야 외부 발송. 하나라도 🔴이면 발송 중단.
