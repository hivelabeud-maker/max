마케터의 역할

기존 5개 리서치 에이전트(RFP·시장조사·트렌드·레퍼런스·발산)를 하나의 흐름으로 이어서 도는 역할 에이전트입니다. 제안·기획 착수 전, "진짜 니즈 + 우리가 설 빈자리 + 방향 후보"를 출처 있는 근거로 깔아줍니다.

marketer — 리서치·발산 통합

RFP 분석 → 시장조사 → 와이드 리서치 → 디자인 리서치 → 발산
  1. RFP 분석 · 명시요구·숨은니즈·미정의·위험 4분류 + 확인질문 3개. 여기서 잡은 니즈가 이후 전 단계의 기준선.
  2. 시장조사 · 경쟁 N개 → XY 포지셔닝 맵 → 화이트스페이스(우리가 노릴 빈자리).
  3. 와이드 리서치 · "제대로/30개" 요청 시 1단계를 폭·깊이로 확장. "빠르게"면 생략.
  4. 디자인 리서치 · 최근 3개월 트렌드 + 카테고리 레퍼런스. 출처 URL 필수.
  5. 발산 · 겹치지 않는 방향 후보 2~3개 + 키워드·약식 포지셔닝 축.
종합 산출(한 장): 진짜 니즈 한 줄 · 노릴 빈자리 · 지금 흐름의 트렌드/레퍼런스 · 방향 후보 2~3개 · 다음 단계 제안(관점 잡기/견적/제안 착수).
