# 최종 산출물 · 출고 · 영상 추출

## 1. 최종 산출물이 무엇인가

빌드하면 **HTML 파일 하나**만 나옵니다. 그 안에 코드·이미지·폰트설정이 전부 들어 있고
**외부로 요청을 한 건도 보내지 않습니다.**

| 파일 | 용도 | 특징 |
|---|---|---|
| `dist/playable_uihd.html` | **광고 출고용** | 애드네트워크에 이 파일 하나만 업로드 |
| `dist/playable_uihd_video.html` | **영상 추출용** | 위와 동일 + 녹화 모듈 포함 |
| `dist/playable_uihd_demo.html` | 시연·캡처용 | 위와 동일 + 화면비 9:16 고정 (납품 금지) |

> ⚠️ **`playable.html` / `playable_video.html`(이름에 `uihd` 가 없는 것)은 flat 스킨 구버전이다.**
> 실제로 쓰는 건 UIHD 뿐이라 이 파일들은 갱신되지 않는다. **출고에 쓰지 말 것.**
> (예전 이 표가 `playable.html` 을 출고용으로 지정하고 있어서, 최신 수정이 하나도 안 들어간
>  구버전이 나갈 뻔했다 — 2026-09-04 수정)

세 파일 모두 더블클릭하면 브라우저에서 바로 재생됩니다. 서버도 빌드도 필요 없습니다.
선행 3개 프로젝트(`Dreamy Match` 256KB / `Penguin` 666KB)와 같은 형태입니다.

```bash
python3 tools/slice.py     # 아트 시트 → 개별 스프라이트 (아트 바뀔 때만)
python3 tools/build.py     # → dist/playable.html            (flat, 광고 출고용)
python3 tools/build.py --video          # → dist/playable_video.html       (flat + 녹화 모듈)
python3 tools/build.py --uihd           # → dist/playable_uihd.html        (UIHD, 광고 출고용)
python3 tools/build.py --uihd --video   # → dist/playable_uihd_video.html  (UIHD + 녹화 모듈)
node tools/qa.js           # 자동 검증
```

> **`--video`만 켜면 flat 스킨으로 빌드됩니다.** 지금 실제로 쓰는 건 UIHD뿐이므로
> 영상을 뽑을 때는 반드시 **`--uihd --video`를 같이** 켜야 한다 — 하나만 붙이면
> (build.py의 출력 파일명 분기가 `UIHD > VIDEO > DOT` 우선순위라) 스킨이 예전 flat으로 나온 채
> 녹화 모듈만 붙어서, HUD 패널·버튼 스타일이 전부 달라 보이는 걸 겪은 적이 있다.

## 2. 해상도 — 상수 하나로 올라갑니다

**논리 화면은 540×960 (정확히 9:16) 하나로 고정**되어 있고,
모든 좌표·글자·선굵기가 그 안의 단위로만 쓰여 있습니다.
그래서 배율만 바꾸면 레이아웃이 그대로 커집니다. **도트는 정수 배율이라 흐려지지 않습니다.**

| `scale` | 출력 해상도 | 용도 |
|---|---|---|
| 1 | 540 × 960 | 미리보기 |
| **2** | **1080 × 1920** | 인스타/틱톡/유튜브 쇼츠 표준 |
| 3 | 1620 × 2880 | |
| **4** | **2160 × 3840** | 4K 세로 |

```
dist/playable_uihd_video.html?video=1&scale=4
```

> 도트 원본(12~48px)을 그대로 들고 있다가 화면에서 정수배로만 키우기 때문에
> 4K에서도 계단이 살아 있는 **선명한 도트**로 나옵니다.
> 나중에 해상도를 더 올리고 싶으면 `scale` 숫자만 바꾸면 됩니다. 재작업이 없습니다.

## 3. 영상으로 뽑기 — MP4 1080p

### 방법 A — 브라우저에서 바로 (권장, 설치 불필요)

```
dist/playable_uihd_video.html?record=1&scale=2
```

Chrome 또는 Safari로 열면 끝입니다.
- 입력이 자동으로 꺼지고 **오토플레이로 처음부터 끝까지 1회** 재생
- 좌상단에 `● REC 1080×1920 MP4` 표시
- 약 30초 뒤 **`pixel_survivor_1080x1920.mp4`가 자동 다운로드**

**MP4로 직접 녹화**되므로 변환 과정이 없습니다. (mp4 미지원 구형 브라우저에서만 webm으로 폴백)
같은 시드를 쓰므로 몇 번을 돌려도 **완전히 동일한 영상**이 나옵니다.

### 해상도 표

| `scale` | 출력 | 용도 |
|---|---|---|
| 1 | 540 × 960 | 미리보기 |
| **2** | **1080 × 1920** | **인스타/틱톡/유튜브 쇼츠 표준 (1080p 세로)** |
| 3 | 1620 × 2880 | |
| 4 | 2160 × 3840 | 4K 세로 |

### 편집 프로그램에 넣을 때

MP4가 바로 나오므로 프리미어·파이널컷·캡컷에 그대로 임포트됩니다.
webm으로 떨어진 경우에만 변환이 필요합니다.

```bash
ffmpeg -i pixel_survivor_1080x1920.webm -c:v libx264 -crf 16 -pix_fmt yuv420p out.mp4
```

### 스틸컷

`?video=1&scale=4&t=24.3` 처럼 **원하는 초로 바로 점프**해 4K 스틸을 뽑을 수 있습니다.

## 4. 조작 · 디버그 URL 파라미터

| 파라미터 | 예시 | 설명 |
|---|---|---|
| `video` | `?video=1` | 540×960 고정 (9:16 정확). 기기 반응형 해제 |
| `scale` | `?scale=4` | 출력 배율 (1~8) |
| `t` | `?t=19.4` | 해당 초로 즉시 점프 (연출 확인·스틸 추출) |
| `record` | `?record=1` | 영상 녹화 후 자동 다운로드 (video 빌드 전용) |
| `debug` | `?debug=1` | 히트박스·발밑 원점·FPS·엔티티 수 표시 |

`?debug=1` 은 **캐릭터를 교체했을 때 반드시 한 번 보세요.**
발밑 십자선과 히트박스가 같이 보이므로 캐릭터가 바닥에 떠 있거나 파묻히는 사고를 즉시 잡습니다.

## 5. 광고 출고 체크리스트

| 항목 | 기준 | 현재 |
|---|---|---|
| 단일 HTML | 필수 | ✅ |
| 파일 크기 | Meta 2MB / AdMob 5MB | ✅ 1,099 KB (압축 출고본 1,058 KB · Meta 2MB 의 54%) |
| 외부 요청 | 0건 | ✅ (`node tools/qa.js` 가 후킹해서 실측) |
| 금지 API | localStorage / eval / XHR / fetch / WebSocket / document.write | ✅ 0건 |
| CTA | `FbPlayableAd.onCTAClick()` → `mraid.open()` → `ExitApi.exit()` → `window.open` | ✅ 폴백 체인 |
| CTA 자동 발동 | 금지 | ✅ 0건 (사용자 탭에서만) |
| CTA 중복 호출 | 금지 | ✅ 1회만 |
| 사망/게임오버 | 없어야 함 | ✅ HP 하한 15% 클램프 |
| 무입력 완주 | 필수 | ✅ 오토플레이로 endcard 도달 |
| 기기 대응 | 16:9 ~ 21:9 + 4:3 태블릿 | ✅ 10종 검증 |
| 사운드 | 없음 | ✅ (음소거 재생이 대부분) |
| 방향 | 세로 고정 | ✅ |

### 출고 전 반드시 바꿀 것

`src/data/theme.js` 의 `storeUrl` 한 줄.

```js
storeUrl : 'https://play.google.com/store/apps/details?id=com.example.game',
```

- **Meta 전용이면 수정 불필요** — Ads Manager에서 선택한 앱으로 자동 연결됩니다
- AppLovin / Unity / ironSource 등은 실제 스토어 URL 필요

### 네트워크별

| 네트워크 | 업로드 | CTA |
|---|---|---|
| Meta (FB/IG/AN) | 단일 HTML. **티저 영상/이미지가 별도로 필요합니다** | `FbPlayableAd.onCTAClick()` |
| Google Ads / AdMob | 단일 HTML 또는 ZIP | `mraid.open()` |
| AppLovin / ironSource / Unity / Vungle | 단일 HTML | 폴백 체인이 알아서 처리 |

> Meta는 `developers.facebook.com → Tools → Playable Ads Preview` 에서
> 업로드만 하면 용량·CTA 자동 검사를 통과 여부로 알려줍니다.
