# 새 IP로 재스킨하기 — 새 세션 요청서

> 대상: 이 프로젝트(PIXEL SURVIVOR / 리타·슬라임)의 **엔진은 그대로 두고 캐릭터·몬스터·UI만
> 새 IP로 갈아끼우는** 2회차 작업. 장르 자체가 바뀌는 거면 이 문서 대상이 아니다
> ([04_제작프로세스.md](04_제작프로세스.md) §5 "장르 변경 = 별도 프로젝트" 참고).

새 세션은 이 대화를 기억 못 한다. 아래 두 가지만 있으면 처음부터 다시 설명할 필요가 없다 —
**① 어디에 뭘 만들지(폴더링)**, **② 뭐라고 요청할지(요청 문구)**.

---

## 1. 폴더링 — 원본은 절대 직접 건드리지 않는다

같은 폴더 안에서 에셋을 덮어쓰면 리타 빌드가 사라진다. **새 IP = 새 폴더**로 통째로 복제한 뒤
그 안에서만 작업한다. 엔진(`src/core/`)과 도구(`tools/`)는 100% 재사용, 새로 채우는 건
`src/data/*.js`와 `src/art/raw/`뿐이다 ([04_제작프로세스.md](04_제작프로세스.md) §2 재사용 표 참고).

```bash
# 예: 새 IP 이름이 "포츈캣" 이라면
cp -R /Volumes/2TB_main/Code/pixel_survivor_playable \
      /Volumes/2TB_main/Code/fortunecat_playable
cd /Volumes/2TB_main/Code/fortunecat_playable

# 이전 IP 산출물·원본 에셋은 지운다 (엔진 코드는 안 건드림)
rm -rf dist/* preview/* releases/*
rm -rf src/art/raw/* src/art/sheets/*
rm -rf src/art/octopus src/art/mood src/art/ui   # ★ 이전 IP 원본 29MB — 빼먹기 쉽다
rm -rf .git                                       # 이전 프로젝트 이력까지 딸려오지 않게
```

복제 후 이 폴더는 [pixel_survivor_playable README.md](../README.md)와 같은
**5폴더 표준**(`README.md` / `docs/` / `src/` / `tools/` / `dist/` / `preview/`)을 그대로 유지한다 —
새로 이름 붙일 필요 없이 이미 그 구조다.

`src/art/` 안에 뭐가 있는지:

| 폴더 | 빌드에 쓰이나 | 새 IP 로 갈 때 |
|---|---|---|
| `art/raw/` | 간접 (prep_anim.py 의 입력) | **비우고 새 원화를 넣는다** |
| `art/sheets/` | ★ 직접 (build.py 가 base64 인라인) | 비운다. prep_anim.py 가 다시 만든다 |
| `art/octopus/` | ✗ 안 쓰임 | **지운다** — 이전 IP 원본 29MB |
| `art/mood/` | ✗ 안 쓰임 | 지운다 — 레퍼런스 이미지 |

그 다음 `git init` 으로 새 이력을 시작하면 된다 (되돌리기는 [README](../README.md) 참고).

## 2. 새 세션에 붙여넣을 요청 문구 (그대로 복사해서 채우면 됨)

```
/Volumes/2TB_main/Code/fortunecat_playable 프로젝트에서 작업할 거야.
pixel_survivor_playable(리타·슬라임)을 복제해서 만든 재스킨 2회차 프로젝트고,
엔진(src/core/, tools/)은 그대로 재사용, 캐릭터·몬스터·UI만 새 IP로 바꿀 거야.

- 새 IP: [IP/캐릭터 이름]
- 참고 자료: [레퍼런스 영상 또는 무드보드 — 파일로 src/art/raw/mood/ 에 넣어둠]
- 캐릭터 원화: src/art/raw/seq/ 에 넣어둠 (idle·run·공격 시퀀스)
- 몬스터 원화: src/art/raw/seq/ 에 넣어둠 (몬스터별 걷기 시퀀스, N종)
- UI 스킨: [flat 유지 / dot / uihd 중 선택] — 이미지 커스텀 없이 벡터 스킨으로 충분함
  (커스텀 이미지 쓸 거면: src/art/raw/ui/ 에 넣어둠)

docs/02_에셋명세.md 규칙대로 tools/prep_anim.py 의 CHARS/MONS/BGS 잡 목록에
새 항목 추가하고, src/data/character.js · enemies.js · theme.js · timeline.js 값 새로 잡아서
빌드해줘. 길이·조작 방식(드래그 1종)·화면 구성(플레이→결과 2장면)은 그대로 유지.
```

**대괄호 안만 채우면 된다.** 파일은 미리 폴더에 넣어두고(채팅 첨부 금지 —
[04_제작프로세스.md](04_제작프로세스.md) 철칙 1), 경로만 문장에 적어주면 새 세션이 바로 찾는다.

## 3. 시작 전에 폴더에 넣어둘 것 (체크리스트)

- [ ] `src/art/raw/seq/<이름>_idle/`, `_run/`, `_fire/` — 캐릭터 프레임 시퀀스 3벌
- [ ] `src/art/raw/seq/m_<이름>_walk/` — 몬스터별 걷기 시퀀스 (최소 1종, 이상적으로는 3종 이상 실루엣 다르게)
- [ ] `src/art/raw/bg.png` — 배경 9:16 전체
- [ ] (선택) `src/art/raw/ui/*.png` — 커스텀 UI 아이콘 6종
- [ ] (선택) `src/art/raw/mood/` — 레퍼런스 영상 캡처·무드보드

정확한 파일 규격(픽셀 크기·프레임 수·이름 규칙)은 **[02_에셋명세.md](02_에셋명세.md)**에 전부 있다.
에셋이 하나도 없어도 그레이 빌드(도트 폴백)로 21.5초가 완주되니, 순서를 못 지켜도 P1(그레이 빌드)부터
시작할 수 있다.
