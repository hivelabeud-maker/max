넷마블 플레이어블 광고 — 360° 원형 코어 디펜스 (리타)
=====================================================
v4 · 2026-09-10 · HIVELAB MAX실
(v3 대비 : 배경 보라 성운 / 캐릭터 30% 축소 / 탄막 보라 + 잔상
          발밑 링 네온 보라 / 결과창은 CTA 하나만
          블루 기준색 #6DDBFF 하나로 통일 / 게이지 바 길이 자동
          하단 CTA 등장 3.0초 → 1.2초 / 보스 도형 기계 코어
          좌우 여백 24px 통일 / 글리프 네온 2겹)

■ 여는 법
  index.html 을 브라우저로 그냥 열면 됩니다.
  외부 요청 0건짜리 단일 파일이라 서버도 인터넷도 필요 없습니다.
  (캐릭터 이미지까지 파일 안에 들어 있습니다)

  세로 화면입니다. 브라우저 창을 세로로 길게 하면 꽉 찹니다.
  무입력으로 두면 오토플레이로 28초를 끝까지 갑니다.
  마우스를 끌면 리타의 사격 방향이 따라옵니다.

  결과창에는 CTA 버튼 하나만 둡니다.
  다시 보시려면 새로고침하면 됩니다.

■ 규격
  화면비 9:16 (내부 720x1280, 상수 하나로 1080x1920까지 확대)
  길이 28초 · 결과창 포함 종료 약 29초
  용량 100KB · 외부 요청 0건

■ 타임라인 (영상 편집용)
  1.2초     하단 CTA 버튼 등장 (0.22초 만에 다 뜬다)
  0~4초     드래그 조준 시연
  4~12초    스킬 2종 해금 (안내 문구 없이 연출만)
  12~19.5초 몹 물량 최대 · SHIELD 0 · HP 380까지
  19.5초    보스 등장 (기계 하우징 + 균열 난 에너지 코어)
  21.8초    각성 (전 스킬 최대)
  25.0초    마지막 일격 → ALL CLEAR
  27.6초~   CLEAR 결과 + CTA

  엔드카드를 따로 붙이신다면 27.6초 앞에서 자르시면
  ALL CLEAR 여운에서 자연스럽게 넘어갑니다.

■ 교체할 곳 세 군데 (index.html 상단)

  1) CTA_URL
     지금 값: 'STORE_URL_HERE'
     넷마블 스토어 링크로 바꿔야 CTA 버튼이 동작합니다.
     영상으로만 쓰실 거면 안 바꾸셔도 됩니다.

  2) CHARACTER.frames
     지금 값: 세븐나이츠 리타 SD 공격 8프레임
     다른 캐릭터로 바꾸려면 이 배열만 교체하면 됩니다.
     w = 표시 크기(지금 120), fps = 애니메이션 속도

     캐릭터는 회전하지 않고 좌우 반전만 합니다.
     픽셀아트를 각도로 돌리면 계단이 뭉개지기 때문입니다.
     그래서 정면(또는 옆모습) 기준 스프라이트를 주시면 됩니다.

     총구 위치는 w 값에 연동됩니다.
     캐릭터를 키우거나 줄여도 탄이 몸에서 나갑니다.

  3) BG_IMAGE
     지금 값: '' (비어 있음)
     비워두면 코드가 보라 성운 배경을 직접 그립니다.
     외부 요청 0건과 용량을 지키려고 이렇게 두었습니다.

     사진 파일을 그대로 쓰시려면 여기에
     data URI 를 넣거나 같은 폴더의 파일명을 적으면 됩니다.
       const BG_IMAGE = 'bg.jpg';
     화면비는 유지한 채 화면을 꽉 채우도록(cover) 들어갑니다.

■ 영상으로 다시 뽑으려면
  주소 끝에 ?record=1 을 붙여 열면
  브라우저가 프레임을 한 장씩 넘기는 모드로 바뀝니다.
  난수 시드가 고정되어 있어서 몇 번을 돌려도 같은 영상이 나옵니다.
  (색이나 타이밍만 바꿔서 재렌더링할 때 유용합니다)

■ 색 바꿀 곳 (index.html · const P 블록)
  탄막 색은 세 값으로 정리해 두었습니다.
    violet  #8E5CF7  — 탄 몸통 + 글로우
    violetL #C9A4FF  — 탄두 밝은 부분 + 잔상 끝
    violetD #6D2BF5  — 잔상 꼬리(투명으로 사라지는 쪽)
  세 값만 바꾸면 탄막 계열 전체가 같이 바뀝니다.

  탄두 심(가장 안쪽)은 흰색으로 고정했습니다.
  보라 배경 위에서 탄이 묻히지 않게 하려는 장치입니다.

  캐릭터 발밑 링도 같은 이유로 두 번 긋습니다.
  굵은 바이올렛으로 헤일로를 깔고 그 위에 가는 흰빛 심을 얹습니다.
  drawHero() 안에 있고, 한 겹으로 줄이면 배경에 묻힙니다.

■ 블루는 한 색입니다 — #6DDBFF
  게이지·전리품 아이콘·버튼·조준 마커·연쇄 번개까지
  화면의 블루는 전부 이 한 색에서 나옵니다.

  const P 블록의 두 줄이 전부입니다.
    cyan  #6DDBFF  — 기준색 (게이지 밝은 쪽, 아이콘, 마커)
    cyanD #15A6D5  — 게이지 어두운 쪽 (같은 색조를 어둡게)
    ice   #D6F5FF  — 거의 흰 블루 (실드 아이콘, 파편 적)

    cta   #6DDBFF  — 버튼 위쪽 + 발광 (기준색 그대로)
    ctaL  #B3ECFF  — 버튼 안쪽 테두리
    ctaD  #00B8F5  — 버튼 아래쪽 (위→아래 그라디언트)

  여섯 값이 전부 같은 색조(hue 195°)입니다.
  색을 바꾸실 땐 cyan 과 cta 를 같은 값으로 두고
  나머지 넷은 밝기만 맞추면 화면 전체가 같이 따라옵니다.

■ 좌우 여백은 한 값입니다
  index.html 안에 GUT = 24 한 줄이 있습니다.
  재화 pill, 경험치, HP/SHIELD, 스킬 패널, CTA 버튼,
  결과창의 전리품 패널까지 전부 이 값에서 나옵니다.

  블록을 새로 넣으실 때도 CONT_L(24) ~ CONT_R(696) 안에 두면
  나머지와 같은 세로선에 섭니다.

■ 아이콘이 뿌옇지 않은 이유
  네온 아이콘은 두 번 긋습니다.
  색으로 번지는 무리 한 겹, 그 위에 흰빛에 가까운 심 한 겹.

  한 겹으로 같은 색만 번지게 하면 획이 자기 무리에 먹혀 뭉칩니다.
  glyph() 안에 있고, 심의 밝기는 lighten(col, .62) 의 숫자입니다.
  인게임 하단 버튼과 결과창 버튼이 같은 함수(ctaButton)를 씁니다.
  세 값만 바꾸면 두 곳이 같이 바뀝니다.

■ 게이지 바 길이는 자동입니다
  피해 수치 옆 게이지는 숫자 폭을 재서 길이를 정합니다.
  숫자와 바 사이 여백을 16px(인게임 14px)로 고정하려는 것입니다.

  결과창은 수치가 멈춘 화면이라 실제 숫자를 재서 딱 맞춥니다.
  인게임은 수치가 계속 올라서, 자릿수가 늘 때 바가 튀지 않도록
  최대 자릿수('999k')를 기준으로 한 번 재고 고정합니다.
