# 프로젝트 브리프

- 프로젝트명: 2026MMORPG_AI_CINEMATIC_BACKGROUND_OS
- 대상 게임·IP: AION2
- 영상 길이: 25초 (현재 확보된 SB 기준. 실제 SB 업로드 후 재확인)
- 화면비: 16:9 (스틸 마스터 기준)
- 최종 해상도: 미정 — Gate 7에서 확정
- 핵심 메시지: 홀로 향하던 길이 동료와의 합류, 초월적 상승을 거쳐 서로 다른 존재들이 하나의 성역에서 마주하고 한 빛의 중심으로 모이는 서사
- 반드시 유지할 게임 고유 조형:
  - 유기적 고딕의 수직성 + 날개·깃·에테르를 연상시키는 곡선형 금속 리브
  - 뾰족 아치 안의 치밀한 에테르 문양
  - 아이보리·은회색(밝은 구조)과 짙은 청회색·흑철(기단·내부)의 구조적 혼합
  - 청록 에테르(문양 인레이용, 제한적) + 극소량의 자청색(깊은 그림자·잔향용)
- 사용 도구: Seedream 5.0 Pro / Nano Banana Pro / Higgsfield / Magnific Precision V2
- 마감 일정: 미정

## 세계관 핵심 규칙

- 천족(Elyos)과 마족(Asmodian)을 화면 좌우 두 진영으로 분리하지 않는다. 하나의 태초 공중 성역 안에서 두 조형 언어를 구조적으로 통합한다.
- 성역의 수호 여신상은 Western high-fantasy sanctuary guardian으로 표현한다. 두 손을 가슴 앞에 모아 기도하는 장대한 로브 차림, 풍화된 창백한 석재, 장엄하게 드리운 로브. 불교 보살상이나 동양 사찰 조각으로 오해되지 않도록 `not Buddhist`, `not East Asian temple sculpture`를 프롬프트에 필요 시 명시한다.
- 단순한 유리 포털, 평평한 문, 동양식 궁궐 형태를 금지한다.
- 원경에서 미세 문양이 안 보이면 억지로 보존하려 하지 말고 큰 실루엣·리듬·명암으로 번역한다.

## 공간 연속성

1. 하위 공중 성역 외부 광장 + 닫힌 거대 관문
2. 관문 개방 후 내부의 끝없는 차원 계단
3. 계단 정상의 더 넓고 상위에 있는 공중 성 + 대치 광장
4. 성 위의 완전한 하늘 + 서로 다른 빛의 궤적이 모일 합성 공간

각 단계는 다른 세계가 아니라 같은 공중 문명의 위계적 확장으로 다룬다.

## 캐릭터 합성 고려

- 동시에 배치될 캐릭터 수: 4명
- 캐릭터가 화면에서 차지할 위치와 비율: 화면 하단 15–25%, 관문·성문이 상단까지 압도
- 날개 등 큰 부속이 펼쳐질 여백: 전면 광장을 넓고 비운 상태로 확보. 대치 장면은 좌우 인물 그룹 여백을 주되 배경 자체는 진영으로 분리하지 않는다.

## 하늘 플레이트 전용 규칙

- 완전한 하늘 뷰에는 성·지형을 넣지 않는다.
- 청회색과 따뜻한 은금색이 공존하는 자연스러운 구름광을 쓴다.
- 중앙 35–40%를 캐릭터·빛 궤적 합성 공간으로 비운다.
- 빛 궤적은 배경 단계에서 만들지 않고 별도 FX 플레이트로 제작한다.

## 성공 기준

- 원경에서 AION 고유 조형 문법이 일반 판타지로 뭉개지지 않고 읽힌다.
- 4인 캐릭터 합성 공간이 모든 핵심 샷에서 확보된다.
- 승인된 Structure Master 하나로 원경·근경·좌우·상공 파생이 전부 가능하다.

## 절대 금지

- 문이 닫힌 상태에서 내부 발광·틈새 빛·바닥 투사광을 생성하는 것
- 캐릭터·FX를 무인 배경 확정보다 먼저 다루는 것
- 천족·마족을 좌우 색상 진영으로 분리하는 것
- 수호 여신상을 불교·동아시아 사찰 조각으로 오인될 수 있게 표현하는 것
