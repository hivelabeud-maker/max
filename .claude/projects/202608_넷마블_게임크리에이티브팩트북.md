# 넷마블 게임 크리에이티브 팩트북

- **클라이언트**: 넷마블 (사내 과제 형태로 착수)
- **업무 범위**: 넷마블 게임 14개 타이틀별 크리에이티브 팩트북 제작 + 통합 비교·클러스터·AI 자산화 전략
- **일정**: 2026.08 착수 ~ 납기 미정 (협의 필요)
- **견적**: 미정
- **상태**: 1단계 — 타이틀 검증표 완료, 레이븐2 샘플 팩트북 완료. 담당자 확인 대기

## 요약 (매 세션 종료 시 갱신)

- **핵심 결정사항**
  1. 산출물 위치를 `netmarble-game-factbook/` 로 확정 (브리프의 폴더 구조 준수, 번호 접두 유지)
  2. 팩트북 12개 섹션 구조 유지하되, **분량을 A4 2~3p 수준으로 압축**. 초안이 과다 서술로 부풀었던 것을 정정
  3. **검증 안 된 항목은 채우지 않고 `공식 확인 필요` / `내부 자료 필요`로 명시**한다. 페르소나 수치·욕망 점수 등 임의 배점은 사용 금지
  4. 레이븐2의 크리에이티브 축은 **헤븐스톤(거신의 유해)** 으로 확정 — 세계관 설정과 성장 시스템이 동일 오브젝트라는 점이 이 IP의 유일한 고유 자산

- **결정 근거**
  - 1차 초안에서 세계관("정파·사파"), 핵심 인물(빛의 왕/어둠의 사도), 타깃 수치(남성 80~85%, 월 결제액), 욕망 점수를 **근거 없이 생성**했고 출시일·전작 플랫폼도 오기했다. 팩트북은 제작자가 그대로 믿고 콘티를 짜는 문서라 가공 정보는 IP 사고로 직결된다. 전면 재작성하고 출처·미확인 항목을 분리 표기하는 구조로 전환.
  - 레이븐2 실제 설정은 "세 여신 → 거신 → 거신의 유해 헤븐스톤이 환란의 씨앗" 구조이며, 헤븐스톤은 인게임 핵심 성장 장비이기도 하다. 강해지는 행위 = 재앙의 원인을 몸에 지니는 행위라는 아이러니가 경쟁작과 구분되는 유일한 지점.

- **다음 액션**
  1. **담당자 회신 필요** — 검증표 §6의 6개 질문 (특히 나혼렙 어라이즈 vs 오버드라이브 / 프로젝트 옥토퍼스 내부자료 가능 여부 / 최종 사용처 / 대상 국가)
  2. 레이븐2 샘플 승인 후 → 2단계 샘플 2종(세븐나이츠 리버스, 나 혼자만 레벨업) 제작
  3. 구조 확정 후 나머지 11종 확장 → 통합 비교표·클러스터·AI 자산화
