07

무드 4축과 레퍼런스

18건 · 전부 검색결과로 URL 확인

각 축은 규칙 + 그 규칙이 실제로 작동하는 제품으로 짝지어 둔다. 규격 문서는 08로 분리했다 — 규칙의 출처와 무드의 출처는 다른 것이다.

01

온기

차갑지 않은 회색.

  • radius를 3단으로 분화 — 카드 16 / 버튼·입력 12 / 칩·프로그레스 full
  • 본문 색은 웜 차콜 계열. 청색 그레이 배제(N70·N80이 이 역할)
  • 온기의 출처를 채도가 아니라 형태와 웜 뉴트럴 면적에 둔다

주의 — 당근·Duolingo는 고채도다. 형태 언어만 가져오고 채도는 버린다.

02

신뢰

03

신호

색 단독으로 신호를 만들지 않는다.

  • 색 + 아이콘 형태 + 짧은 라벨 3중 인코딩. 직사광·장갑·색각이상을 한 번에 처리
  • 긴급과 주의는 같은 컴포넌트의 색 변형이 아니라 별도 등급의 컴포넌트
  • 긴급 버튼에 오발동 방지 — 길게 누르기 / 밀어서 취소
  • 토큰을 역할 기반으로 명명해 BI 후행 리스크를 흡수

09

선례가 없는 지점

레퍼런스로 방어되지 않는 영역

"웜 파스텔 기조에서 긴급을 살린" 완성 사례를 찾지 못했다

신호 축에 등재한 4건은 신호 논리는 강하지만 톤이 전부 우리와 다르다 — Birdie는 고채도 RAG, Dexcom은 의료기기, Life360은 다크, Gojek은 고채도 그린. 즉 "따뜻한 손길 × 긴급"의 조합은 우리가 처음 푸는 문제에 가깝다. 레퍼런스로 방어할 수 없으므로, 06의 UI 스펙이먼처럼 실물 대비 검증을 우리가 직접 만들어 근거로 남기는 것이 유일한 방법이다.

NanumSquare Round의 실서비스 본문 선례가 없다

폰트 자체 정보(산돌 제작, 상업적 사용 가능)만 확인됐고, 이 폰트가 실제 앱 본문에서 어떻게 읽히는지 검증된 사례를 찾지 못했다. 라운드 계열은 소자 크기에서 획이 뭉치므로, 방문 시각·연락처 같은 숫자 가독성과 12sp 이하 대역을 자체 실측해 본문 하한을 정해야 한다.

개발사 = 한강시스템, 확인됐다

케어포 가족돌봄(com.hangang.carefor_family)의 개발사가 한강시스템(주)이고 자사 사업 페이지에 "장기요양 운영관리 시스템 케어포"가 올라와 있다. 개발사가 이미 요양 도메인 UI 관행을 갖고 있다는 뜻이므로, 우리 신호 체계·radius·타이포 위계가 기존 관행과 충돌하는 지점을 QA 전에 문서로 못 박아야 한다.

10

처리할 것

10/26 개발 QA 기준
  1. 신호를 3중 인코딩으로 확정한다. 색 + 아이콘 형태 + 짧은 라벨. Birdie의 RAG 문자 코드(n/t·m/t)가 직접 근거다. 직사광·장갑·색각이상 세 조건을 한 장치로 처리하는 유일한 해법이며, #FFCF1C가 텍스트로 못 쓰이는 제약도 이 규칙으로 흡수된다.
  2. radius를 3단으로 분화한다. 현재 "12~16px"은 범위일 뿐 규칙이 아니다. 카드 16 / 버튼·입력 12 / 칩·프로그레스 full 로 확정한다.
  3. 컬러 토큰을 역할 기반으로 명명한다. brand-primary가 바뀌어도 signal-urgent·signal-caution·signal-done은 불변이 되도록. NHN 내부 BI가 후행 적용될 때 재작업 범위를 확정 4색으로 한정하는 장치이자, 회신에 박아둔 "BI가 확정 무드와 크게 다르면 별도 산정" 방어선의 기술적 뒷받침이다.
  4. 긴급 버튼 오발동 방지를 한강시스템과 협의한다. 장갑 착용·이동 중 조작이라 오탭 위험이 크다. 길게 누르기 / 밀어서 취소 모델은 개발 구현 부담이 있으므로 10/26 QA에 꺼내면 반영이 안 된다.
  5. 터치 타깃 44px → 48dp. 제안서 표기가 iOS 기준이다. 안드로이드 비중이 높은 사용자층에는 Material 48dp가 안전하다. 이미 납품된 분량이 있으므로 QA 구간 수정 범위로 잡는다.
  6. 레퍼런스 링크 전수 확인. 무드 16건은 검색결과로 URL이 확인됐으나 화면을 열어보지는 못했다. 국내 앱(케어포·케어네이션·맞춤돌봄케어)은 직접 설치해 캡처해야 하며, 개발사 관행 파악 목적상 케어포가 1순위다.
  7. 완료 색 #4C7A34 → #456E2F 교체 완료. 원안은 tint 위 4.48:1로 미달이었다. 교체값은 5.27:1로 주의·긴급과 같은 대역에 들어온다.
