## 이 파일을 쓰는 법

**언제 한 줄 추가하나** — 아래 중 하나라도 해당하면 추가한다.
- 에이전트·스킬의 **라우팅(트리거 말)** 이 바뀌었을 때
- **산출 포맷**(어떤 레이아웃으로 나오나)이 바뀌었을 때
- 폴더 **분류 구조**가 바뀌었을 때 (파일을 옮기거나 폴더를 새로 팠을 때)
- 팀원이 **다시 설치·다시 배포**해야 하는 변경일 때

**언제 추가하지 않나** — 오타 수정, 문구 다듬기, 예시 추가. 이건 git 커밋으로 충분하다.

**버전 이름 규칙** — `agent-pack v8`처럼 `대상 + 판번호`로 쓴다. 날짜만 쓰면 나중에 "그 v8이 어느 거였지"를 못 찾는다.
