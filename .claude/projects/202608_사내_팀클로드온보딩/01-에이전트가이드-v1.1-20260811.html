사용 가이드

조사가 필요한 업무는 기능을 하나씩 부를 필요가 없습니다. 자료를 붙이고 "마케터 돌려" 한 문장이면 요청 분석부터 시장조사, 진단, 문제 정의, 아이디어 발굴까지 4단계가 이어서 돕니다. 결과는 왼쪽 탭 12개짜리 대시보드 화면 하나로 나옵니다.

이 파일을 처음 여는 사람이 할 일3분

1. 팀에 배포된 agent-pack 폴더를 받습니다. 그 안의 agents/와 skills/ 폴더를 본인 작업 폴더의 .claude/ 안에 그대로 넣습니다.

2. Claude를 열고 조사할 자료(RFP·브리프·회의록·링크)를 붙입니다.

3. 마케터 돌려 라고 씁니다. 끝입니다. 아래 4단계가 자동으로 이어집니다.

더 깊게 원하면 마케터 돌려, 제대로 라고 씁니다. 조사량이 늘어나고 소비자 리뷰·다른 업계 사례까지 봅니다.

한 문장을 쓰면 이 4단계가 자동으로 돕니다

각 단계가 끝나면 --- CH1 완료. CH2로 넘어갑니다 --- 같은 줄이 화면에 뜹니다. 그게 다음 단계로 넘어갔다는 신호입니다.

STEP 0
요청 분석
붙인 자료에서 목표·요구사항·빠진 정보·위험을 4가지로 나눕니다.
→ 확인 질문 3개
CH1
현황 조사
사실만 모읍니다. 아래 조사 6스텝을 순서대로 돕니다. 판단은 아직 하지 않습니다.
→ 팩트북·경쟁사 표
CH2
진단
모은 사실 위에 브랜드들을 지도처럼 배치하고, 아무도 없는 빈자리를 찾습니다.
→ 포지셔닝 맵·빈자리
CH3
문제 정의
"진짜 풀어야 할 문제"를 한 문장으로 씁니다. 이 문장이 이후 모든 제작의 기준선입니다.
→ 문제 한 문장
CH4
발산
그 문제를 푸는 방향 후보를 서로 겹치지 않게 2~3개 냅니다.
→ 방향 후보 + 키워드
CH1 조사 6스텝 — 이 순서를 건너뛰지 않습니다

경쟁사 목록만 훑고 끝내면 다음 단계 진단이 얕아집니다. 그래서 조사 단계를 6개로 고정했습니다. "빠르게"라고 해도 S1·S2·S3·S6은 무조건 돕니다. S4·S5는 "제대로"라고 썼을 때 추가로 돕니다.

스텝무엇을 조사하나최소 조사량
S1. 카테고리 정의필수이 시장이 어디까지인지 선을 긋습니다. 무엇이 이 시장이고 무엇이 아닌지.정의 1문단 + 옆 동네 시장 2개
S2. 시장 규모·추이필수시장이 얼마나 크고, 최근 3년간 커지는지 줄어드는지 봅니다.숫자 3개 이상, 각각 기준연도·출처
S3. 경쟁사 조사필수파는 쪽 이야기입니다. 브랜드별로 가격대·내세우는 말·비주얼 분위기를 모읍니다.빠르게 5~8개 / 제대로 15~30개
S4. 소비자 조사제대로사는 쪽 이야기입니다. 실제 후기에서 사람들이 쓰는 말 그대로 모읍니다. 왜 사고 왜 안 사는지.리뷰·커뮤니티 원문 10건 이상
S5. 다른 업계 사례제대로같은 고민을 다른 업종은 어떻게 풀었는지 봅니다. 여기서 새 아이디어가 나옵니다.사례 3개 + 옮길 원리 한 줄씩
S6. 트렌드·레퍼런스필수지금 디자인 흐름과, 우리가 참고할 만한 실제 사례를 모읍니다.트렌드 3개+ / 레퍼런스 5개+
S4를 특히 빼먹으면 안 되는 이유. 브랜드가 하는 말만 모으면, 다음 단계에서 그리는 지도의 가로·세로축이 결국 광고 문구를 옮겨 적은 것이 됩니다. 축은 소비자가 실제로 쓰는 말에서 나와야 합니다. 그래서 깊은 조사가 필요한 건은 제대로를 꼭 붙이세요.
양질만 남기는 규칙 — 출처 등급 T1~T4

모은 자료마다 등급을 매깁니다. T4는 본문에서 뺍니다. 아무 자료나 긁어와서 그럴듯하게 채우는 걸 막는 장치입니다.

등급무엇예시
T1발표한 곳이 직접 낸 자료통계청·KOSIS, 상장사 실적발표·사업보고서, 브랜드 공식 발표, 정부·협회 통계
T2취재·심사를 거친 자료주요 언론 보도, 유료 시장조사 리포트, 학술 논문, 어워드 수상작(Awwwards·D&AD 등)
T3참고용 — 개인 관점이 섞인 자료업계 블로그, 개인 리뷰·커뮤니티 글 (S4 소비자 말 모으는 용도로는 유효)
T4본문 사용 금지출처 불명 요약글, 조회수용 짜깁기 기사, AI가 만든 요약, 광고성 보도자료 복붙, 날짜 없는 페이지
여기에 따라붙는 규칙 4가지.
1) 숫자에는 반드시 기준연도와 출처 링크를 답니다. "시장이 크게 성장" 같은 문장은 쓰지 않습니다 → "2024년 8,200억 원, 전년 대비 +12%".
2) 중요한 숫자는 서로 다른 출처 2곳에서 확인합니다. 값이 다르면 둘 다 적고 왜 다른지 한 줄 붙입니다.
3) 3년 넘은 자료는 제목에 "○○년 기준"을 박습니다. 최신인 척하지 않습니다.
4) 못 찾았으면 DATA GAP이라고 씁니다. 추측으로 채우지 않습니다. 빈칸이 틀린 숫자보다 낫습니다.
어려운 말은 반드시 풀어 씁니다

RFP, 브리프 또는 업무 내용을 입력하면 '업무 요청 분석' 기능이 목표·타깃·범위·일정·제약조건을 정리합니다. 이후 조사·이해, 전략·기획, 디자인·제작, 검수·납품 순서로 업무가 진행되며, 각 검토 단계를 통과한 결과만 다음 단계로 전달됩니다. 기능 카드를 누르면 아래에서 역할과 요청 예시를 확인할 수 있습니다.

실행 기능 중간 검토 최종 승인 다음 단계 전달
업무 요청 입력 · 시작 단계
업무 요청 분석
RFP, 브리프, 회의 내용을 분석해 목표·타깃·범위·일정·제약조건과 추가 확인 질문을 정리합니다.
→ 조사 필요 항목 → 조사·이해
→ 목표·제약조건 → 전략·기획
▲ 위 업무 단계에서 실행 기능이나 검토 단계를 누르면 역할과 요청 예시가 표시됩니다.

각 업무 단계에서 사용할 수 있는 기능과 요청 예시입니다. 필요한 업무와 가까운 문장을 입력하면 해당 기능이 실행됩니다.

⚡ 빠른 시작 — 업무가 들어오면 이렇게 요청하세요

  1. RFP·과업지시서·브리프를 첨부하고 "업무 요청을 분석해줘"라고 요청합니다.
  2. 조사 근거가 필요하면 "시장·고객 조사부터 진행해줘"라고 요청합니다.
  3. 제작을 시작하기 전 "핵심 방향과 비주얼 콘셉트를 정리해줘"라고 요청합니다.

업무 요청을 입력하면 자동으로 실행되나요직접 요청 필요

프로젝트명만 입력해서는 어떤 기능도 실행되지 않습니다. 실행 조건은 하나, 요청 문장에 필요한 내용이 들어 있어야 합니다. "크래프톤"이라고만 입력하면 대기 상태입니다. "크래프톤 업무 요청을 분석해줘"라고 입력해야 실행됩니다.

지금은 "새 업무 요청이 들어오면 자동으로 조사·이해 단계부터 실행한다"는 규칙이 설정되어 있지 않습니다. 자동으로 실행되게 만들고 싶다면 이 규칙을 별도로 추가하면 됩니다. 그 전까지는 매번 필요한 요청 문장을 직접 입력해야 합니다.

업무는 실제로 이렇게 진행됩니다 — 예시 1건

가상 프로젝트 "하이브 신작 게임 브랜딩"으로 요청부터 납품까지 따라가 봅니다. 「업무 실행 흐름」 탭을 같이 열어두고 순서대로 눌러보면 실행되는 순서와 똑같습니다.

1

4
핵심 방향이 정리되면 "무드보드를 만들어줘" 또는 "디자인 시안을 제작해줘"라고 요청합니다 → 디자인·제작 단계가 순서대로 진행됩니다: 무드보드 제작 → 디자인 시안 제작 → 필요하면 스토리보드 제작 · Figma 전달·연동. 디자인·제작
5
시안이 나오면 "디자인과 사실관계를 검수하고 납품 가능 여부를 확인해줘"라고 요청합니다 → 검수·납품 단계가 순서대로 진행됩니다: 디자인 품질 검수 → 디자인 가이드 확인 → 크리에이티브 최종 확정 → 사실·수치 확인 → 문체·톤 확인 → 납품 파일 최종 점검 → 최종 승인. 하나라도 기준에 못 미치면 납품이 멈춥니다. 검수·납품
