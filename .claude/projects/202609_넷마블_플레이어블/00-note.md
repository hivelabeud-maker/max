# 넷마블 플레이어블 · 360° 원형 코어 디펜스

- **클라이언트**: 넷마블
- **업무 범위**: 플레이어블 광고 1편 — 28초 페이크 게임 영상 (단일 HTML, 외부 요청 0건)
- **일정**: 2026-09-09 착수 · 납기 미확정
- **견적**: 협의중
- **상태**: v4 배포판 완료. CTA 링크·영상 추출 규격 회신 대기

## 요약 (매 세션 종료 시 갱신)

- **핵심 결정사항**
  - 장르는 **360° 원형 코어 디펜스**(뱀서라이크 A 액션·서바이버). 레퍼런스는
    Geometry Cannon : Idle Defense — 게임 구조만 가져오고 룩은 쓰지 않는다.
  - 룩은 v4에서 **우주**로 고정. 검정 `#04030A` + 보라 성운, 탄막만 바이올렛 계열.
  - 배경은 사진을 심지 않고 코드로 그린다. 용량과 외부 요청 0건을 지키기 위함.
    사진이 필요해질 때를 위해 `BG_IMAGE` 슬롯을 열어 뒀다.
  - 조작은 드래그 하나. 무입력이면 오토플레이로 28초를 완주한다.
  - 결과창에는 **CTA 하나만** 둔다. `다시 보기`는 스토어 이동과 시선을 나눠 갖는다.
  - CTA 버튼은 **블루**(#38C6F4 → #1478B8). 인게임 하단과 결과창이 같은 함수를 쓴다.
  - HP에 하한(170)을 걸어 **절대 지지 않는다**. 광고라서 패배 화면이 없어야 한다.
  - 교체 슬롯 3개(`CTA_URL` · `CHARACTER.frames` · `BG_IMAGE`)만 만지면 다른 타이틀로
    재사용된다.

- **결정 근거**
  - 광고 네트워크 상한(대개 5MB)에 여유를 남겨야 나중에 캐릭터 프레임을 늘릴 수 있다.
    성운 사진을 data URI로 넣으면 용량이 서너 배가 되므로 코드 드로잉을 택했다.
  - 배경과 탄막이 둘 다 보라라서 중앙에서 탄이 묻힌다. 탄두 안쪽 34%를 흰색으로
    남겨 대비를 만들었다.

- **다음 액션**
  - 넷마블 — `CTA_URL` 스토어 링크 회신
  - 넷마블 — 영상 추출 규격(1080p 여부) 확정
  - MAX실 — 실기기 프레임 확인 (지금 수치는 소프트웨어 렌더링 기준)

### 2026-09-10
- 2차 세션. 실장님 지시 세 줄을 반영해 **v4**를 만들었다.
  1. 배경 교체 — 딥 네이비 격자 그리드 → 검정 + 보라 성운
  2. 캐릭터 30% 축소 — 표시 폭 172px → 120px
  3. 탄막을 보라 계열로 — 글로우 + 잔상
- **배경**: 참고 이미지(검정 우주 + 중앙 보라 성운 + 붉은 별 섞인 별밭)를 받았으나
  파일 원본을 세션에서 꺼낼 수 없어 같은 톤을 코드로 재현했다.
  `buildSky()` 로 한 번만 굽고, 시드 RNG를 써서 열 때마다 같은 별자리가 나온다.
  - 첫 시도는 성운 감쇠가 가팔라 원 테두리가 보였다 → 감쇠를 완만하게 깔고
    세로로 1.14배 늘려 정원(正圓)으로 보이지 않게 고쳤다.
  - 사진을 그대로 쓰고 싶을 때를 위해 `BG_IMAGE` 슬롯을 만들었다.
    값을 넣으면 구워둔 성운을 그 이미지가 덮는다(cover).
- **캐릭터**: `CHARACTER.w` 한 값만 바꿨다. 발밑 골드 링은 원래 `w`에 연동돼 있었고,
  총구 위치는 상수 58이 박혀 있어 `CHARACTER.w * 0.34`로 바꿨다.
  이걸 안 고쳤으면 축소한 캐릭터 바깥에서 탄이 튀어나왔을 것이다.
- **탄막**: 핑크 → 바이올렛(`violet` `violetL` `violetD` 3토큰으로 분리).
  잔상은 탄마다 6칸 배열 하나를 붙여 프레임당 좌표 1점을 밀어 넣는 방식.
  각성 구간에 탄이 100발 넘게 남는데, 탄마다 배열을 새로 만들면
  초당 수천 개가 생겼다 사라져 프레임이 떨어진다.
- **버린 대안**: 잔상을 고스트 3장(같은 다트를 뒤로 겹쳐 그리기)으로 만드는 방법.
  유도탄이 곡선을 그려서 직선 뒤로 겹치면 궤적이 어긋난다. 좌표 기록 방식으로 갔다.
- 검증: Chromium 헤드리스로 2·6·14·20.5·23·26·28.2초 프레임을 렌더링해 확인.
  콘솔 에러 0건, 외부 요청 0건, 용량 100KB.

### 2026-09-10 (2차 · 같은 날 추가 지시)
- 실장님 지시 두 건 반영.
  1. 결과창에서 `다시 보기` 제거
  2. 캐릭터 발밑 링을 골드 → 네온 보라로
- **다시 보기**: 문구·탭 영역(`placeHit`)·클릭 핸들러·죽은 상수 `END_AGAIN` 까지
  같이 걷어냈다. `showEnd()` 는 이제 CTA 하나만 켠다.
  `reset()` 함수 자체는 남는다 — 최초 시작과 녹화 하네스가 쓴다.
- **발밑 링**: 한 겹으로 그었더니 배경 성운과 같은 계열이라 바닥에 묻혔다.
  골드일 때는 보색이라 한 겹으로도 떴는데 보라는 안 된다.
  네온관 구조로 두 번 긋는 방식으로 바꿨다 —
  굵은 바이올렛(#8E5CF7, 11px) 헤일로 + 가는 흰빛(#EADCFF, 4px) 심.
- 아티팩트로도 게시했다 (문서 껍데기만 벗기고 게임 코드는 동일).
  https://claude.ai/code/artifact/8b1171c8-1950-443a-8291-ed0d8ef7445e
  재생성: `index.html` 에서 1~7행과 37~38행, 마지막 2행을 빼고 `<title>` 만 갈면 된다.

### 2026-09-10 (2차 · 3차 지시)
- 실장님 지시 네 건. 참고 이미지 2장(인게임 블루 버튼 / 결과창 빨간 표시) 동봉.
  1. 인게임 하단 CTA 버튼을 블루톤으로
  2. 결과창 `CLEAR` 아래 가로 구분선 제거
  3. 피해 게이지 우측 빈 여백을 줄이도록 바를 길게
  4. 결과창 버튼도 같은 블루로
- **CTA 블루**: 팔레트에서 `lime/limeL/limeD` 를 `cta/ctaL/ctaD` 로 갈았다.
  `ctaButton()` 한 함수를 인게임 하단과 결과창이 같이 쓰므로 3·4번이 한 번에 해결됐다.
  색 이름 대신 역할 이름(`cta`)으로 둔 건, 다음에 또 색이 바뀌어도
  토큰 이름이 거짓말이 되지 않게 하려는 것.
- **게이지 길이**: 고정 폭 420px이라 `27k` 같은 짧은 수치에서 80px 가까운
  빈 칸이 남았다. 숫자 폭(`tw()`)을 재서 바 길이를 역산하도록 바꿨다.
  - 결과창은 수치가 멈춘 화면이라 실측값으로 딱 맞춘다.
  - 인게임은 수치가 계속 올라서, 실측으로 재면 `9.9k → 10k` 넘어가는 순간
    바 길이가 튄다. 최대 자릿수(`999k`)를 한 번 재서 고정했다.
- **범위 밖 판단**: 실장님이 짚은 건 결과창이었지만, 인게임 하단
  `스킬 피해 현황` 패널이 같은 위젯에 같은 결함이라 같이 고쳤다.
  결과창은 1.5초, 인게임 패널은 28초 동안 보인다.
- 검증: 7개 시점 재렌더링, 콘솔 에러 0건.
