- **클라이언트**: 넷마블 (프로젝트 옥토퍼스)
- **업무 범위**: 9:16 페이크 플레이어블 광고 소재 **2종**. 1차와 같은 캐릭터(리타), 브리프의 레퍼런스 1·2를 각각 구현
- **일정**: 2026-09-09 착수 / 납기 미정
- **견적**: 협의중
- **상태**: 2안 모두 구현 완료. QA 전 항목 통과. 아티팩트 발행 · 고객사 컨펌 대기

## 요약 (매 세션 종료 시 갱신)

- **산출물 2종** (같은 브리프의 두 레퍼런스를 각각 구현 — A/B 용)

| | 1안 NEON DEFENSE | 2안 ORB POP |
|---|---|---|
| 레퍼런스 | 1 (우주 네온 디펜스) | 2 (Pop Orb) |
| 코어 루프 | 몰려오는 적을 막는다 | 떠다니는 공을 터뜨려 쪼갠다 |
| 조작 | 드래그로 이동 | 드래그·조이스틱으로 조준 |
| 톤 | 어두운 우주 + 시안/마젠타 | 순검정 + 원색 |
| 하단 | 대형 CTA | 조이스틱 + 그 위 CTA |
| 실패 조건 | HP | 없음 (목표 점수·시간) |
| 폴더 | `neon_defense_playable/` | `orb_pop_playable/` |
| 아티팩트 | https://claude.ai/code/artifact/d0612727-ece6-4b08-a183-912b974b784a | https://claude.ai/code/artifact/97985492-1bef-45ce-938c-7258ba87d9d4 |

- **핵심 결정사항**
  - 1차 프로젝트에 스킨을 얹지 않고 **별도 프로젝트로 복제**했다 (`neon_defense_playable`)
  - 그래픽은 **레퍼런스 무드(어두운 우주 + 네온)**. 넷마블 던전 아트는 안 쓴다
  - 리타(캐릭터)만 재사용. **몬스터·배경은 그림 파일 없이 코드로 그린다**
  - 이펙트는 레퍼런스만큼 화려하게 — 1차에서 줄였던 값을 되돌렸다
  - HUD 는 레퍼런스처럼 조밀하게. 표시값 3개 → 10개
  - 길이 21.5초 (브리프 "25초 이내" 충족, 엔드카드 +5초 해도 30초 이내)

- **결정 근거**
  - 우주·네온 무드는 절차적 렌더링이 유리해서 **넷마블 아트 대기 없이 착수**된다.
    브리프의 "우선 가장 기본형으로 캐릭터만 적용한 버전"과도 정확히 맞는다
  - 1차 문서가 "조용한 UI"를 네 번 못박고 있어서, 코드 주석과 설계서를 먼저 다시 썼다.
    안 고치면 다음 세션이 문서를 근거로 되돌린다 (이 저장소가 이미 겪은 사고)

- **2안 확정사항 (2026-09-09 실장 결정)**
  - 플레이어는 리타 (1안과 동일) — 추상 오브 대신 IP 노출 유지
  - 하단은 조이스틱 중앙 + CTA 그 위 — 레퍼런스 배치를 지킨다
  - 톤은 Pop Orb 그대로 (순검정 + 원색) — 1안과 의도적으로 다르게 가서
    A/B 시 변인이 "게임 방식"으로 좁혀진다

### 2026-09-09 (이어서) — 2안 ORB POP
- 실장이 레퍼런스 2 케이스를 별도로 요청. "가운데 하단에 컨트롤러도 고려" 지시
- 업로드된 19.87초 화면기록을 프레임 단위로 실측했다. 추측으로 만들면 안 되는 부분이라
  ffmpeg 로 뜯어서 확인했고, 이 실측이 설계의 근거 전부다:
  · 플레이어가 1.2초간 (283,332) → (281,349) 로만 움직였다 = 제자리 부유.
    움직이는 건 조준뿐이고, 조준을 훑으며 나온 탄 줄기가 화면의 곡선 점선이다.
    이걸 "궤적 예측선"으로 잘못 읽었으면 게임이 통째로 달라졌다
  · 큰 원 주변에 작은 원이 겹친 프레임이 여럿 → 분열 판정. 콤보 x76 은 분열 연쇄
    말고는 설명이 안 된다. 분열이 이 게임의 엔진이다(스폰이 아니라)
  · escalation 3단이 서로 다른 자리에 동시에 있다: Tempo Up!(대형 배너) /
    HYPER FRENZY!!(상단 HUD) / DOMINATION xN(중앙 대형)
  · HP 게이지가 없다 → 실패 조건이 체력이 아니라 목표 점수·시간
- 조이스틱 vs CTA 자리 충돌은 실장 판단으로 "조이스틱 중앙 + CTA 그 위"로 확정.
  조이스틱은 장식이 아니라 실제로 조준을 돌린다("눌러도 반응 없는 버튼 = 이탈 요인")
- 캡처를 보고 되돌린 판단 6건: 오브 크기 축소 / 헤일로 완화 / 콤보 창 단축 /
  점수 3배 / DOMINATION 이중 렌더 분리 / 탄 경계를 Orbs.field() 로
  (버린 대안: 오브 밀도를 director 로 조절 — 분열 상한으로 푸는 게 더 안전했다)
- qa.js 의 "전폭 딤 금지" 규칙에 상단 앱바 예외를 **명시적으로** 넣었다.
  우회해서 통과시키면 규칙 자체가 무력해진다(3회 재발 이력이 있는 규칙이다)
- 두 케이스를 아티팩트로 발행해 바로 확인 가능하게 함 (9:16 고정 시연본)
