| 항목 | AION2 1주년 (씬 기반) | 숏폼 영상 (미완성) | 다른 방식 (상세형) |
|---|---|---|---|

## 🎬 각 방식의 특징

### ① AION2 1주년 (씬 기반)
**장점:**
- ✅ 명확한 이야기 호 구조 (6개 장면)
- ✅ 각 씬마다 4개 컷으로 변화/진행 표현
- ✅ 비주얼 임팩트 강함 (효과 중심)

**단점:**
- ❌ 각 컷의 상세 정보 부족 (시간, 카메라, 대사 없음)
- ❌ 영상 제작자가 컷 타이밍·대사 자유도가 높음
- ❌ 클라이언트와 의견 충돌 가능성

**메타데이터:**
- 장면명 (한국어)
- 의도 (한두 줄)
- 이미지 4개

---

### ② 숏폼 영상 (미완성)
**상태:** 🚧 템플릿 단계 (작업 중)

**방향:**
- 카테고리 기반
- 비주얼 + 스케치
- 매우 단순한 구조

**문제:**
- ❌ CUT 01만 있고 반복
- ❌ 실제 모든 컷이 채워지지 않음
- ❌ 메타데이터 불충분

---

### ③ 다른 방식 (상세형)
**장점:**
- ✅ 가장 상세함 (타임코드 정확)
- ✅ 각 컷의 역할 명확 (제목+설명)
- ✅ 감정/캐릭터 정보 포함
- ✅ 제작팀이 실행 가능한 수준의 상세도

**단점:**
- ❌ 정보가 많아서 한눈에 흐름 파악이 어려움
- ❌ 컷이 16개이면 스크롤이 길어짐

**메타데이터:**
- 타임코드 (정확함)
- 한국어 제목
- 영어 설명 (감정/액션)
- 제목 텍스트
- 캐릭터/감정 마크

---

## 🎯 최적 SB 구조 제안

### 통합 구조 = ① + ③의 장점

```
헤더
├─ 프로젝트명
├─ 포맷 (16:9 또는 9:16)
├─ 길이 & 컷 수
├─ 톤 한 줄
└─ 메타박스 (PROJECT / DURATION / CUTS / FRAME)

💡 톤 한 줄
└─ "어두운 세계에서 천족이 등장한다. 색이 없는 일상 → 황금색 휘광"

참고 영상 2~3개
└─ 각 영상에서 가져올 포인트

연출 방향 5항목
├─ 카메라: 광각, 무브 성향, 역광
├─ 색: 무채색 → 금색 그라데이션
├─ 편집: 한 컷 2~3초, 블랙 전환
├─ 사운드: 오케스트라 + 임팩트 SFX
└─ 타이포: 한글 제목 + 영문 설명

타임라인 바
└─ 컷별 초수 시각화 (막대 그래프)

컷 그리드 (or 씬 기반 섹션)
└─ 각 컷:
    ├─ CUT 번호 + 제목
    ├─ 타임코드 (00:00–00:03)
    ├─ 이미지
    ├─ 화면 설명
    ├─ 앵글 / 샷사이즈
    ├─ 움직임 + 전환
    ├─ 대사 (화자 표기)
    ├─ 사운드 (SFX/BGM/AMB)
    └─ 리소스 (AI생성 / 실사 / 그래픽)
```

## 🔍 AION2 1주년 SB 분석

### 현재 6개 씬 구조

| 씬 | 한국어명 | 컷 수 | 핵심 |
|---|---|---|---|
| 01 | 흔들 움직이는 길음 | 4 | 천족 등장·어둠 |
| 02 | 날개 움직이는 길음 | 4 | 날개 펼침·힘 |
| 03 | 인물을 드러내는 길음 | 4 | 클로즈업·표정 |
| 04 | 새로 강해지는 길음 | 4 | 변신·에너지 |
| 05 | 사람 분해하여 아이온의 새 | 4 | 클라이맥스·통합 |
| 06 | ALL WAYS, AION2 | 4 | 엔딩·로고 |

**현재 상태: 24컷 완성**

### 누락 가능성 분석

```
🤔 검토 필요 항목:
1. 각 씬마다 4컷이 정확히 필요한가?
   → 일부 씬은 3컷으로 충분할 수 있음
   → 일부 씬은 5~6컷이 필요할 수 있음

2. 도입(Opening) 씬이 있는가?
   → Scene 01 "흔들 움직이는 길음"이 도입인가?
   → 더 명확한 세계 설정 씬이 필요한가?

3. 전개 장면이 명확한가?
   → Scene 02→03→04는 점진적 상승인가?
   → 중간에 회의/갈등 씬이 필요한가?

4. 클라이맥스가 확실한가?
   → Scene 05가 진정한 클라이맥스인가?
   → Scene 04와 Scene 05 사이에 전환 씬이 필요한가?

5. 엔딩(로고) 씬의 마무리
   → Scene 06이 충분한가?
   → 브랜드 메시지가 명확한가?
```

## ✨ 스토리보드 재구성 방향

### 추천: 씬 기반 + 컷 상세 하이브리드

**구조:**
```
Scene 01: 흔들 움직이는 길음 (1~5초, 4컷)
  ├─ CUT 01: 어둠 속 움직임 (0:00-1:00)
  ├─ CUT 02: 천족 실루엣 (1:00-2:00)
  ├─ CUT 03: 시선 마주침 (2:00-3:00)
  └─ CUT 04: 에너지 분출 (3:00-5:00)

Scene 02: 날개 움직이는 길음 (5~10초, 4컷)
  [같은 방식]

... (Scene 03~06)

Appendix: 사운드 큐시트
```

**각 컷 정보:**
- ✅ 타임코드 (정확)
- ✅ 이미지
- ✅ 화면 설명 (무엇이 보이나)
- ✅ 앵글/무브 (카메라가 무엇을 하나)
- ✅ 대사/사운드 (무엇이 들리나)
- ✅ 리소스 (어디서 오나)
