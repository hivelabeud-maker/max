# 캠페인 카피 시스템 — 내러티브부터 UA 소재까지 4단계

제안서의 카피는 감으로 뽑으면 심사장에서 무너진다. **왜 이 단어인지 설명할 수 없으면 쓰지 않는다.**
이 스킬은 내러티브 → 슬로건 → 카피 → 소재를 한 줄로 꿰어, 카피 하나하나에 근거가 붙게 만든다.

## 들어가기 전 — 두 가지를 먼저 확인한다

1. **관점이 정해졌는가** — `concept-director`의 관점 한 문장이 있으면 그것을 상속한다. 없으면 먼저 잡는다.
   관점 없이 뽑은 슬로건은 다음 회의에서 다시 뒤집힌다.
2. **제안 건인가** — RFP·입찰·경쟁 PT면 `proposal-psychology` 스킬을 먼저 통과한다.
   특히 렌즈 ④(자랑보다 의도와 과정)가 Step 1 내러티브의 기준이 된다.

---

## Step 1. 마케팅 내러티브 & 타임라인 (기승전결)

제안서 전체를 관통하는 스토리라인과 톤을 **3~4단계 타임라인**으로 요약한다.

| 단계 | 채울 것 |
|---|---|
| 導 도입 | 어떤 상황에서 시작하는가. **유저의 현재 감정**을 한 줄로 |
| 展 전개 | 무엇을 보여주는가. 정보가 아니라 **변화의 조짐** |
| 轉 절정 | 어디서 뒤집는가. 캠페인의 **가장 큰 한 방** |
| 結 결말 | 무엇이 남는가. 캠페인이 끝난 뒤 유저에게 **남아야 할 문장** |

그리고 **몰입 흐름을 한 문장으로** 쓴다.
형식: `"[도입 감정] → [전개 감정] → [절정 감정] → [결말 감정]"`
예시 형식만 참고 — 실제 내용은 프로젝트에서 뽑는다.

**금지** — 단계마다 형용사만 채우는 것. 각 단계에 **유저가 실제로 보는 것**(영상·배너·이벤트)이 하나씩 붙어야 한다.

---

## Step 2. 메인 슬로건 3안 + 키워드 기획 의도

게임의 핵심 가치와 **서비스 주기**를 동시에 관통해야 한다.
주기별로 슬로건이 잡아야 할 것이 다르다.

| 주기 | 슬로건이 잡아야 할 것 |
|---|---|
| 론칭 | 이 세계가 무엇인지 · 왜 지금 들어와야 하는지 |
| 사전예약 | 기다림을 자산으로 · 놓치면 손해라는 감각 |
| 주년 | 지나온 시간의 의미 + 다음 약속. **감사만 하면 실패** |
| 챕터·시즌 업데이트 | 세계가 넓어진다는 감각 · 지금 들어와도 늦지 않았다 |
| 복귀 캠페인 | 떠난 이유가 해결됐다는 신호 · 자리가 남아 있다는 안심 |

**각 안마다 반드시 함께 쓴다**
- 슬로건 (국문 / 영문 병기)
- **핵심 키워드와 기획 의도** — 왜 이 단어인가. 숫자 '1', 첫 만남, 일·One 같은 언어유희면 그 중의성을 설명
- **어느 주기·타깃에 붙는가**
- **번역 내구성** — 글로벌 전용 가능성이 있으면 10개 언어로 옮겼을 때 뜻이 깨지는지 판정

**3안은 서로 달라야 한다.** 같은 방향의 표현 변주 3개는 1안이다.
축을 나눈다 — 예: `유산·시간 축` / `확장·미래 축` / `관계·소속 축`.

---

## Step 3. 목적별 카피 리스트업 — 4유형 × 각 3개 이상

같은 캠페인이라도 붙는 자리가 다르면 말투가 달라야 한다.

### ⚡ 1. 스케일 / 혜택 강조형
역대급·최초·파격 보상 계열. **가장 빨리 소진되는 유형이다.**
- 숫자를 넣는다. "역대급"보다 "3배"가 강하다
- 이미 닳은 단어(역대급·레전드·최초·미친)는 **숫자와 붙을 때만** 쓴다
- 붙는 자리: 성과형 배너, 스토어 배지, 이벤트 고지

### 🎮 2. 유머 / 밈 & 위트형
트렌드 반영, 가볍고 친근한 톤. **아래 커뮤니티 톤 게이트를 통과해야만 쓴다.**
- 붙는 자리: 숏폼, 커뮤니티 게시물, SNS 리플라이
- 공식 계정 반말체는 브랜드 합의가 먼저다

### 🏛️ 3. 사자성어 / 한자어형
언어유희로 임팩트를 만드는 유형. 게임 카피에서 **가장 저평가된 무기**다.
- 사자성어를 그대로 쓰지 말고 **한 글자를 바꾼다** — 게임 고유명사·숫자·키워드로 치환
- `일(一)·일(日)·One` 같은 동음이의를 주년·1주년 캠페인에 붙인다
- 한자를 병기할지는 타깃 연령으로 판단. 30~40대 MMORPG 타깃이면 병기가 먹힌다
- 붙는 자리: 키비주얼 헤드라인, 옥외, 영상 타이틀 카드

### ❄️ 4. 감성 / IP 메타포형
IP 고유 감성을 건드리는 유형. **그 IP를 아는 사람에게만 통한다.**
- IP의 **고유 상징**을 먼저 목록화한다 (예: 날개·비행·진영·아비스)
- 계절·시간 은유(첫돌·첫눈·첫 비행)는 주년 캠페인의 기본 재료
- 붙는 자리: 브랜드 영상, 주년 키비주얼, 복귀 유도 소재

**각 카피에 반드시 붙이는 3항목**
`카피` / `붙는 자리` / `왜 이 표현인가 한 줄`
세 번째가 없으면 리스트업이 아니라 낙서다.

## 커뮤니티 톤 게이트 (유머·밈형을 쓸 때 필수)

게임 커뮤니티는 광고 문법에 **가장 민감한 집단**이다. 인벤·루리웹·디시 갤러리·아카라이브가 주 무대다.

**쓰기 전에 반드시 한다**
1. 해당 타이틀 커뮤니티에서 **최근 2주 게시물 30건 이상**을 읽는다 — 여론과 톤을 파악하는 조사 기간
2. 유저가 **실제로 쓰는 단어**를 그대로 수집한다. 바꿔 쓰지 않는다
3. 최근 논란·불만 키워드를 확인한다. 그 주제를 건드리는 카피는 뺀다
4. **쓰려는 밈 자체가 발생·유행한 지 1개월 이내인지 확인한다.** 조사 기간(2주)과는 별개 기준이다 —
   여론은 최근 2주만 봐도 파악되지만, 밈은 **속도가 생명**이라 한 달을 넘기면 이미 죽은 밈이다.
   기원을 못 찾겠거나 1개월을 넘겼으면 **후보에서 뺀다.** "요즘도 쓰나?"로 감으로 판단하지 않는다.

**밈은 유통기한이 짧다.** 지금 도는 밈을 여기 적어두면 3개월 뒤 틀린 문서가 된다.
그래서 이 스킬은 **밈 목록을 담지 않는다.** 대신 매번 직접 확인한다.

**꾸준히 유효한 관찰**
- **숫자에는 관대하고 형용사에는 가혹하다.** "압도적 스케일"은 조롱당하고 "동시접속 15만"은 인용된다
- **자학 유머는 유저의 것이다.** 유저가 "망겜ㅋㅋ" 하는 건 애정이지만, 회사가 따라 하면 무성의로 읽힌다
- **반박자 늦은 밈이 가장 위험하다.** 안 쓰는 것보다 나쁘다
- **1인칭 해명은 잘 먹힌다.** 개발자·운영자가 자기 말로 설명하면 광고보다 신뢰가 크다
- **과장 광고의 기억이 누적돼 있다.** 실제 게임에 없는 화면을 쓰면 그 자체가 사건이 된다

**이 게이트를 통과 못 하면 유머·밈형을 빼고 3유형으로 간다.** 억지로 채우지 않는다.

## Step 4. UA 소재 · 영상 연계 가이드

Step 2~3의 카피가 **화면에서 어떻게 보이는지**까지 정한다. 카피만 주면 제작에서 다시 막힌다.

각 카피군마다 아래를 한 줄씩 붙인다.

| 항목 | 채울 것 |
|---|---|
| 화면 | 무엇이 보이는가. **실제 인게임 화면 기준** |
| 카피 위치 | 상단 / 하단 / 중앙. 세이프 영역 |
| 길이 | 숏폼 몇 초 지점에 나오는가 |
| 다국어 | 텍스트 레이어 분리 여부 · 최장 언어 기준 폭 |

**UA 소재 절대 원칙 — 광고에서 본 화면이 게임에 있어야 한다**
클릭률을 올리려고 실제 게임에 없는 일러스트나 다른 장르 화면을 쓰지 않는다.
설치는 늘지만 하루 만에 빠져나가고, 커뮤니티 감성이 직접 내려간다.
성과는 CTR 단독이 아니라 **CTR × 설치 후 D1 잔존**으로 본다.

## 산출 형식

- 채팅 답변이면 Step 1~4를 그대로 순서대로
- 문서·HTML이면 `mx-deck-design`(발표용) 또는 `mx-research-dashboard-design`(대시보드)
- 영상 컷까지 가면 `storyboard-deck-design`으로 넘긴다

**글은 `anti-ai-writing`을 통과시킨다.** 부정 병렬 금지, 형용사는 숫자로, 비유 기본 0개.
카피 자체는 예외 — 카피는 수사가 일이다. 다만 **설명문은 예외가 아니다.**

## 흔한 실수

- 관점 없이 슬로건부터 뽑음 → 다음 회의에서 뒤집힌다
- 3안이 사실상 1안 → 축을 나눠야 3안이다
- 카피에 "왜 이 표현인가"가 없음 → 심사장에서 질문 하나에 무너진다
- 커뮤니티 확인 없이 밈 사용 → 반박자 늦은 밈은 안 쓰느니만 못하다
- 밈 기원 확인 없이 "익숙해서" 씀 → 1개월 넘은 밈은 이미 죽었다. 발생 시점을 먼저 확인한다
- 사자성어를 원형 그대로 사용 → 한 글자를 바꿔야 카피다
- UA 소재를 실제 게임과 다르게 만듦 → 단기 설치를 사고 장기 신뢰를 판다
