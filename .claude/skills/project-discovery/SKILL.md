# Project Discovery — 프로젝트·브랜드·문제 정의 (STEP 1~3)

시장조사보다 **먼저** 프로젝트 대상과 진짜 문제를 못 박는다. 산출은 Markdown 3종:
`outputs/01_project_discovery.md` · `outputs/02_brand_factbook.md` · `outputs/03_problem_definition.md`.

> 정보가 부족하면 **임의로 채우지 않는다.** 아래 정보 상태 태그로 구분해 남긴다.

## 정보 상태 태그 (모든 항목에 부착)
- `FACT` 공식/내부 문서로 확인된 사실
- `CLIENT CLAIM` 클라이언트 전달, 외부 미검증
- `INFERENCE` 확인된 사실 기반 해석
- `HYPOTHESIS` 추가 검증 필요 가설
- `UNKNOWN` 현재 확인 불가

부족 시 기록: 확인된 것 / 확인 안 된 것 / 확인이 필요한 이유 / 클라이언트 질문 / 외부 조사 항목.

## STEP 1 — 프로젝트 디스커버리 → `01_project_discovery.md`
RFP가 있든 초기 자료만 있든 대응. 필수 항목:
고객사명 · 업무명 · 프로젝트명 · 프로젝트 유형 · 시작 배경 · 클라이언트 표면 요청 · 요청 산출물 ·
프로젝트 범위 · 주요 의사결정자 · 주요 실무 사용자 · 일정 · 예산·리소스 조건 · 평가 기준 · 성공 기준 ·
유지할 요소 · 변경 가능 요소 · 제약사항 · 모호/충돌 요구 · 추가 확인 필요.

**프로젝트 유형** (1개 이상 선택): 신규 브랜드 · 리브랜딩 · 브랜드 확장 · 제품 브랜드 · 서비스·플랫폼 ·
공간·장소 · 기업·B2B · 콘텐츠·IP · 캠페인·행사 · 신규 사업 · 디자인 시스템 · 기타.

## STEP 2 — 브랜드 팩트북 → `02_brand_factbook.md`
단순 소개문이 아니라 **문제 정의·시장조사의 기준이 되는 사전 이해 문서.**

**브랜드 기본**: 브랜드명 · 영문명 · 운영사 · 설립/론칭 · 운영 지역 · 카테고리 · 사업 영역 · 주요 제품/서비스 · 공식 웹/SNS · 현재 상태 · 이번 프로젝트 대상 범위.
**목적·역할**: 존재 이유 · 해결 고객 문제 · 핵심 가치 · 사업 내 역할 · 선택 이유 · 만들고 싶은 미래.
**제품·서비스·경험**: 핵심 제공물 · 주요 기능 · 이용/구매 과정 · 사용 장면 · 가격대 · 구매 방식 · 고객 접점 · 경쟁 대안 · 강점 · 약점.
**타깃** (인구통계 아니라 **행동·욕구·선택기준·장벽** 중심): 핵심/보조 타깃 · 구매자 · 사용자 · 연령·지역·환경 · 행동 특성 · 관심사 · 동기 · 선택 기준 · 불편·장벽 · 접점 · 기대 경험 · 기대 변화 · 자발적 공유 가능성.
**아이덴티티**: 비전 · 미션 · 핵심 가치 · 성격 · 현재 포지셔닝 · 핵심 메시지 · 톤앤매너 · 비주얼 특징 · 로고·컬러·그래픽 자산 · 유지할 자산 · 개선할 부분.
**이름·스토리**: 이름 의미 · 어원 · 발음·연상 · 시작 배경 · 철학 · 감정적 변화 · 기존 슬로건 · 소개문.

### 유형별 확장 조사 (프로젝트 유형에 따라 자동 적용)
- **공간·장소**: 위치 · 지역 특성 · 상권 · 기능 · 방문 목적 · 체류 방식 · 이용 시간 · 방문 전·중·후 경험 · 발생 행동 · 입점 콘텐츠 · 동선 · 지역 관계 · 촬영·공유 행동 · 상징적 역할.
- **제품**: 카테고리 · 주력 제품 · 기능 · 사용 상황 · 소재 · 제조 방식 · 가격대 · 구매 주기 · 라인업 · 패키지 · 유통 · 기능/감성 차별성.
- **서비스·플랫폼**: 핵심 과업 · 이용 흐름 · 가입/구매 · 반복 사용 구조 · 수익 모델 · 기술/데이터 요소 · 이탈 지점 · 핵심 순간.
- **기업·B2B**: 사업 영역 · 고객 산업 · 의사결정자 · 사용자 · 영업 방식 · 계약 구조 · 전문성 · 기술력 · 신뢰 근거 · 기업↔제품 브랜드 관계.
- **콘텐츠·IP**: 세계관 · 캐릭터 · 팬층 · 형식 · 플랫폼 · 참여 방식 · 장기 서사 · 확장 가능성 · 핵심 정서.
- **캠페인·행사**: 목적 · 기간 · 타깃 · 참여 행동 · 메시지 · 참여 장벽 · 채널 · 온·오프 연결 · 확산 방식 · 성과 지표.

## STEP 3 — 목표·문제 재정의 → `03_problem_definition.md`
4대 비교: `Brand Says`(주장) / `Brand Does`(실제 제공) / `Customer Sees`(인식) / `Market Compares`(경쟁 대비 위치).

도출: 현재 상태 · 희망 상태 · 활용 가능 자산 · 해결할 격차 · 미검증 가설 · 표면 요청 · 요청 이면의 사업 목적 · **진짜 해결 문제** · 내려야 할 의사결정 · 성공 기준 · 이후 리서치 질문.

**문제는 현상·산출물이 아니라 의사결정 질문으로.** 형식:
```
표면적 요청 → 현재 현상 → 원인 가설 → 진짜 해결 문제(“…하려면 …는 무엇이어야 하는가?”)
```
