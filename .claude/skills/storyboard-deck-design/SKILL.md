# Storyboard Deck Design — 영상 콘티 조판 시스템

컷을 카드로 세우고, 카드 안에 **보이는 것 / 들리는 것 / 카메라가 하는 것**을 같은 자리에 놓는다.
누가 만들어도 같은 문서로 보이게. 색·타이포·필드 순서는 고정, 내용만 갈아끼운다.

## 언제 쓰나

- 광고 영상(15초·30초) 컷 콘티를 제안서에 넣을 때
- 브랜드 필름·시네마틱(1분 30초 이상) 시퀀스 구성을 보여줄 때
- 게임 업데이트 영상, 프로모 영상 A안/B안 비교
- AI로 스틸을 뽑아 붙이는 프리비주얼 단계

쓰지 말 것: 슬라이드형 제안서 전체(`mx-deck-design`), 리서치 대시보드(`research-deck-design`).
**스토리보드 한 편 = HTML 한 장.** A안·B안은 파일을 나누거나 한 파일 안에 섹션을 반복한다.

## 1. 화면 비율부터 고른다 (레이아웃이 두 개다)

같은 30초라도 가로 영상과 세로 영상은 문서 구조가 다르다. **파일을 먼저 고르고 시작한다.**

| | 가로 16:9 | 세로 9:16 |
|---|---|---|
| 파일 | `template.html` | `template-vertical.html` |
| 쓰는 곳 | TV·유튜브 광고, 브랜드 필름, 게임 시네마틱 | 릴스, 쇼츠, 틱톡, 세로 브랜드 필름 |
| 컷 카드 | 그림 위 · 글 아래로 쌓는다 | 그림 왼쪽 · 글 오른쪽에 붙인다 |
| 1440px 기준 | 5열 · 카드 높이 429px | 3열 · 카드 높이 223px |
| 화면 안전 영역 | 없음 | 있다 (앱 버튼이 가림) |
| 자막 | 대사에 딸린 요소 | **대사보다 앞선다** (소리 끄고 봄) |
| 훅 | 없음 | 1~2컷째 고정 |

**왜 카드 구조를 바꾸는가.** 9:16 그림을 가로용 카드에 그대로 넣으면 그림 하나가 세로 400px을 넘는다.
카드가 700px이 되고 40컷이면 페이지가 8,000px을 넘어간다. 그래서 세로용은 그림을 왼쪽에 세우고
글을 오른쪽에 붙여 카드 높이를 223px로 눌렀다. **같은 40컷이 가로는 3,272px, 세로는 3,120px에 들어온다.**

### 컷 수 프리셋 — 가로 16:9

| 길이 | 쓰는 곳 | 컷 수 | **최대** | 한 컷 평균 | 덩어리 |
|---|---|---|---|---|---|
| 6초 | 범퍼·티저 | 2~3컷 | **3컷** | 2~3초 | 안 나눔 |
| 15초 | 숏폼·짧은 광고 | 5~8컷 | **8컷** | 1.5~3초 | 안 나눔 |
| **30초** | 광고 본편 | **10~14컷** | **14컷** | 2~3초 | 안 나눔 |
| 60초 | 프로모·인게임 | 16~22컷 | **22컷** | 2.5~4초 | 2~3덩어리 |
| 90초 이상 | 시네마틱·브랜드 필름 | 24~40컷 | **40컷** | 3~5초 | 세 덩어리 (필수) |

### 컷 수 프리셋 — 세로 9:16

세로는 같은 길이에 컷이 더 많이 들어간다. 화면이 자주 바뀌어야 손가락이 멈추기 때문이다.

| 길이 | 쓰는 곳 | 컷 수 | **최대** | 한 컷 평균 | 훅 |
|---|---|---|---|---|---|
| 6초 | 범퍼 광고 | 3~4컷 | **4컷** | 1.5~2초 | 1컷째 |
| 15초 | 릴스·쇼츠 | 6~10컷 | **10컷** | 1.5~2.5초 | 1~2컷째 |
| **30초** | 숏폼 본편 | **12~18컷** | **18컷** | 1.5~2.5초 | 1~2컷째 |
| 60초 | 긴 숏폼 | 20~30컷 | **30컷** | 2~3초 | 1~2컷째 |
| 90초 이상 | 세로 브랜드 필름 | 28~44컷 | **44컷** | 2~3.5초 | 1~3컷째 |

**엔드카드는 컷 수에 포함한다.** 로고·일정 고지도 컷이다.

### 최대치를 넘기지 않는 이유

30초를 25컷으로 쪼개면 산수로는 한 컷에 1.2초씩 들어간다. 보는 사람 눈에는 화면이 번쩍이는 것으로만 남는다.
그래서 가로는 14컷, 세로는 18컷을 실무 상한으로 둔다.

반대 방향도 있다. 한 컷이 5초를 넘으면 화면이 멈춘 것처럼 보인다(시네마틱 롱테이크 제외).
카메라만 움직이는 컷이면 앞 컷에 붙인다.

### 컷 수 검산 — 조판 전 반드시

```
총 초수 ÷ 컷 수 = 컷당 평균 초
```
- 가로 1.2초 · 세로 1.5초 아래 → 컷이 너무 많다. 붙일 컷을 합친다.
- 5초 위(시네마틱 제외) → 컷이 헐겁다.
- 시네마틱은 **한 컷 8초 이상을 롱테이크로 명시**해도 된다. 카드에 `LONG TAKE` 배지를 단다.

### 시퀀스(막) 쓰는 기준
60초 이상이면 컷 카드 위에 시퀀스 헤더를 얹는다. 막 이름, 담당 초수 구간(`00:00–00:32`), 한 줄 의도.
90초 이상에서 시퀀스를 안 쓰면 컷 30장이 평평하게 나열되어 리듬이 안 보인다.

## 1-1. 세로 9:16 전용 규칙

### 화면 안전 영역
세로 영상은 화면 전체를 못 쓴다. 템플릿의 컷 그림 위에 점선으로 표시돼 있다.

| 영역 | 크기 | 무엇이 가리나 |
|---|---|---|
| 위 | 12% | 사용자 이름, 상태바 |
| 아래 | 20% | 설명글, 음원 표시 |
| 오른쪽 | 18% | 좋아요·댓글·공유 버튼 |
| 자막 자리 | 아래 22~36% | (여기 둔다) |

인물 얼굴·제품·로고를 가려지는 자리에 두지 않는다.
위 숫자는 릴스·쇼츠·틱톡을 겹쳐놓고 가장 좁게 잡은 값이다. **한 곳에만 올릴 거면 그 앱을 직접 띄워 확인한다.**

### 훅
1~2컷째(첫 3초)를 훅으로 고정한다. 여기서 손을 멈추게 못 하면 나머지 27초는 아무도 안 본다.
타임라인 막대에서 훅 컷은 파란색으로 표시한다.

### 자막이 대사보다 앞선다
소리를 끄고 보는 사람이 많다. 자막만 읽어도 내용이 전달되는지 확인한다. 한 줄 12자 안쪽.

## 1-2. 세로 스크롤 구조 (실측)

두 템플릿 다 **컷이 늘면 아래로 길어지는 세로 스크롤 구조**다. 컷 그리드는 `auto-fill`이라 화면이 넓으면 열이 늘고 좁으면 줄어든다.

가로 16:9 기준 컷 그리드 높이(카드 429px + 간격 18px):

| 화면 폭 | 열 | 14컷 | 22컷 | 40컷 |
|---|---|---|---|---|
| 1920px | 6열 | 1,341px | 1,788px | 3,129px |
| 1440px | 5열 | 1,341px | 2,235px | 3,576px |
| 1280px | 4열 | 1,788px | 2,682px | 4,470px |
| 768px | 2열 | 3,129px | 4,917px | 8,940px |
| 390px | 1열 | 6,258px | 9,834px | 17,880px |

**40컷을 모바일로 보면 17,880px, 화면 22번 스크롤이다.** 시네마틱 40컷은 반드시 시퀀스 헤더로 세 덩어리를 끊는다.
클라이언트가 폰으로 볼 문서라면 컷을 20개 아래로 유지하거나 파일을 막 단위로 나눈다.

## 2. 레퍼런스 · 연출 방향 (컷보다 먼저 온다)

컷 그리드 위에 이 블록이 무조건 들어간다. 순서: 톤 한 줄 → 레퍼런스 카드 → 연출 방향 항목.

### 톤 한 줄
컷 전체를 지배하는 문장 하나. 형용사 나열 금지, 상태를 쓴다.
- 나쁨: "감각적이고 세련된 무드"
- 좋음: "무채색 일상 → 붉은 전장. 색이 바뀌는 순간이 클라이맥스." (레퍼런스 B안 방식)

### 레퍼런스 카드 — 출처 URL 필수
카드 1장 = 레퍼런스 1편. 담는 것 네 가지:
1. 썸네일(또는 플레이스홀더)
2. 제목 + 제작사/브랜드
3. **훔칠 포인트 한 줄** — "이 레퍼런스에서 가져오는 건 정확히 무엇인가"
4. 출처 링크 `youtu.be/xxxx ↗` (12px, muted)

레퍼런스는 2~4편. 5편 넘어가면 방향이 흐려진다.
**URL을 모르면 링크를 지어내지 않는다.** `출처 미확인 — 제목만 전달받음`이라고 쓴다.

### 연출 방향 — 5항목 고정
아래 다섯 줄은 항목 이름을 바꾸지 않는다. 내용이 없으면 `해당 없음`이라고 쓴다.

| 항목 | 쓰는 것 |
|---|---|
| 카메라 | 주 렌즈감, 무브 성향(핸드헬드/고정/크레인), 시점(1인칭·관찰자) |
| 컬러 | 베이스 톤 → 클라이맥스 톤 변화. HEX 또는 색 이름 |
| 편집 | 컷 리듬(평균 초), 전환 방식, 비트 맞추는 지점 |
| 사운드 | BGM 장르·템포, SFX 밀도, 무음 구간 위치 |
| 타이포 | 자막·카피 등장 방식, 폰트 방향, 엔드카드 처리 |

## 3. 컷 카드 필드 (순서 고정)

카드 하나에 들어가는 것. **위에서 아래로 이 순서.**

| # | 필드 | 필수 | 형식 |
|---|---|---|---|
| 1 | CUT 번호 + 컷 제목 | 필수 | `CUT 03` 배지 + 한 줄 제목 |
| 2 | 타임코드 | 30초 이상 필수 | `00:05–00:08 (3s)` |
| 3 | 스틸 | 필수 | 16:9. 없으면 플레이스홀더 |
| 4 | 화면 설명 | 필수 | 보이는 것만. 감정 해석은 빼고 상태를 쓴다 |
| 5 | 앵글 / 샷 | 필수 | 아래 용어 사전 |
| 6 | 모션 · 전환 | 필수 | 카메라 무브 + 다음 컷으로 넘어가는 방식 |
| 7 | 대사 · NA | 있을 때 | `화자: 대사` — 화자 표기 필수 |
| 8 | 사운드 | 필수 | `SFX:` / `BGM:` / `AMB:` 접두어 |
| 9 | 리소스 | 선택 | `AI 생성` / `실사 촬영` / `인게임 캡처` / `보유 소스` |

### 화자 표기
`NA`(내레이션), `주인공`, `혈맹원`, `메인 카피`처럼 **누가 말하는지를 앞에 붙인다**(레퍼런스 B안 방식).
자막만 뜨고 소리가 없으면 `자막:`을 쓴다.

### 사운드 3종 구분
- `SFX:` 화면에 붙는 효과음 — "노트북 닫는 소리(딱)"
- `BGM:` 음악 — 시작·전환·정지 지점을 함께 적는다
- `AMB:` 배경음 — "새벽 도시 소음, 낮게"

무음도 표기한다: `SFX: 무음 (0.4초)`. 무음은 연출이므로 빈칸으로 두면 안 된다.

### 앵글 · 샷 용어 사전 (괄호 풀이 그대로 쓴다)

| 표기 | 뜻 |
|---|---|
| EWS | 아주 넓게 — 인물이 작게, 공간이 주인공 |
| WS | 넓게 — 인물 전신 + 주변 |
| MS | 중간 — 허리 위 |
| CU | 클로즈업 — 얼굴 |
| ECU | 아주 가깝게 — 눈, 손, 물건 하나 |
| OTS | 어깨 너머로 보는 시점 |
| POV | 인물이 보는 그대로의 시점 |
| 하이앵글 | 위에서 내려다봄 — 인물이 작아 보임 |
| 로우앵글 | 아래에서 올려다봄 — 인물이 커 보임 |

무브: `고정` / `팬(좌우)` / `틸트(위아래)` / `달리 인·아웃(앞뒤 이동)` / `트래킹(따라감)` / `핸드헬드(손으로 든 흔들림)` / `크레인`
전환: `컷` / `디졸브` / `매치컷(형태 이어붙임)` / `휩팬(빠르게 훑어 넘김)` / `플래시` / `암전`

## 4. 디자인 토큰 (사내 표준 고정)

`intel-deck-design` · `research-deck-design`과 **같은 토큰**을 쓴다. 여기서 새 색을 만들지 않는다.

```css
:root{
  /* 기본 = 모노톤 */
  --bg:#f2f1ee; --panel:#fff; --panel2:#faf9f6;
  --ink:#161616; --muted:#77756e; --line:#e3e1da;
  --accent:#1a1a17;          /* 강조는 검정이다. 파랑이 아니다 */
  --accent2:#e6e4dd; --ph:#ece9e2;
  /* 포인트 4색 (고정) */
  --pink:#ff86f6; --blue:#2e53f9; --lime:#c5ff79; --orange:#ff6e23;
  --pink2:#ffeafd; --blue2:#e7ecfe; --lime2:#eeffd9; --orange2:#ffe4d3;
}
```

### 이 덱에서의 배정

| 색 | 쓰는 자리 |
|---|---|
| `--accent` 검정 | 상단 룰, CUT 배지, 메타박스 밑줄, 시퀀스 구분선, 타임라인 막대 |
| `--blue` | 대사·NA, LONG TAKE 배지, 링크 hover |
| `--orange` | 사운드 (SFX/BGM/AMB) |
| `--lime` `--pink` | 이 덱에서는 쓰지 않는다 |

**대사는 파랑, 소리는 주황.** 훑을 때 어디에 소리가 붙는지 바로 보이게 하려는 배정이다.
그 둘 말고는 전부 무채색이다.

### 색 쓰는 법 (사내 공통 규칙)

- `--blue` `--orange` : 글자색으로 바로 써도 된다
- `--lime` `--pink` : 배경으로만. 글자로 쓸 땐 어둡게 바꾼다 (lime → `#5a7d1a`, pink → `#c23bb3`)
- soft 계열(`--blue2` 등)은 배경, deep은 그 위 글자. 항상 쌍으로

| Concept Line | `clamp(15px, 1.4vw, 18px)` Regular | 톤 한 줄 |
| Seq Title | 20px Bold | 시퀀스 헤더 |
| Cut Title | 14px SemiBold | 컷 제목 |
| Body | 13px Regular, lh 1.55 | 화면 설명 |
| Label | 11px Medium, `--muted` | 필드 라벨 |
| Source | 11px, `--muted` | 출처 링크 |

숫자·타임코드는 `font-variant-numeric: tabular-nums`.

## 6. 레이아웃 규칙

1. 컷 그리드: `repeat(auto-fill, minmax(230px, 1fr))`, gap 18px. 데스크톱 4~5열, 태블릿 2~3열, 모바일 1열.
2. **읽는 순서는 좌→우, 위→아래.** 컷 번호가 그리드 순서와 어긋나면 안 된다.
3. 스틸 비율은 템플릿이 정한다. 가로 `16/9`, 세로 `9/16`. 세로는 카드가 `grid-template-columns: 118px 1fr` 가로 배치다.
4. 절대좌표 금지. 컷이 8개에서 30개로 늘어도 안 깨져야 한다.
5. 인쇄 대응: `@media print`에서 카드 `break-inside: avoid`.

## 7. 문서 골격 (이 순서로)

```
① 헤더        — Eyebrow(포맷·컷수) + 제목 + 메타박스(PROJECT / DURATION / CUTS / FRAME)
② 톤 한 줄
③ 레퍼런스 카드 2~4장 (출처 URL)
④ 연출 방향 5항목
⑤ 타임라인 바   — 15·30초 필수, 60초 이상 권장
⑥ 컷 그리드     — 60초 이상은 시퀀스 헤더로 분절
⑦ 부록          — 자막 원고 / 사운드 큐시트 / 소스 리스트 (필요할 때만)
```

### 메타박스
4필드 고정, 각 라벨 아래 액센트 밑줄 2px.
`PROJECT` / `DURATION`(30초) / `CUTS`(13 cuts) / `FRAME`(16:9)

### 타임라인 바
컷별 초수를 가로 폭으로 환산한 막대 한 줄. 컷 번호를 막대 안에 넣는다.
엔드카드 구간은 `--muted` 채움으로 구분한다. **컷 리듬이 눈으로 보이는 게 목적**이라, 30초 13컷이면 막대 13개 폭이 다 달라야 한다.

## 7-1. 글 쓰는 기준 (템플릿 안내문 포함)

이 템플릿은 **처음 쓰는 사람이 혼자 채울 수 있어야 한다.** 두 템플릿 상단에 안내 박스가 있고,
완성본에서는 지운다고 적혀 있다. 안내문과 자리표시자는 아래 기준으로 쓴다.

- 중학교 2학년이 한 번 읽고 따라올 수 있는 난도
- 용어를 쓸 거면 바로 뜻을 붙인다. `ECU(아주 가깝게, 눈·손·물건 하나)`
- 자리표시자에 규칙만 적지 말고 **틀린 예와 맞는 예를 같이** 보여준다.
  `{눈에 보이는 것만 적는다. "쓸쓸하다" 말고 "창밖을 3초 본다"}`
- 줄표(—) 쓰지 않는다. 마침표·쉼표·콜론으로 끊는다

## 8. 스틸이 없을 때

플레이스홀더 규칙: 회색 `#E9ECEF` 박스 + 가운데 11px muted 텍스트로 **그 컷의 프롬프트 요약**을 넣는다.
`빈 박스 + "이미지"`로 두지 않는다. 프롬프트가 보이면 그대로 AI 생성으로 넘길 수 있다.

```html
<div class="ph">새벽 침실, 침대에 앉은 남자, 역광, 무채색</div>
```

## 10. 흔한 실수

- 길이를 안 정하고 컷부터 뽑음 → 초 배분이 무너진다. 프리셋 먼저.
- 90초 시네마틱을 시퀀스 없이 30컷 나열 → 리듬이 안 보인다. 3막으로 쪼갠다.
- 사운드 칸 비움 → 무음도 `SFX: 무음 (0.4초)`로 적는다.
- 대사에 화자 없음 → `NA:` `주인공:` 접두어 필수.
- 레퍼런스 출처 URL 누락 → 모르면 `출처 미확인`이라고 명시. 링크를 지어내지 않는다.
- 앵글을 "멋있게" 같은 감상으로 씀 → `MS · 로우앵글 · 달리 인` 형식으로 쓴다.
- 화면 설명에 감정 해석을 씀("쓸쓸함이 느껴진다") → 보이는 상태만("창밖을 3초간 본다").
- 표준 밖의 색을 새로 만듦 → 4색 고정. 이 덱은 검정 + 파랑(대사) + 주황(소리)만 쓴다.
- 엔드카드를 컷에서 뺌 → 로고·일정 고지도 컷 번호를 받는다.
- 세로 영상을 가로 템플릿으로 조판 → 카드가 700px을 넘어 스크롤이 감당 안 된다. `template-vertical.html`을 쓴다.
- 세로인데 안전 영역을 무시하고 얼굴을 위아래 끝에 배치 → 앱 버튼에 가린다.
- 세로인데 훅을 안 잡음 → 첫 3초를 비우면 나머지는 안 본다.
- 최대 컷 수를 넘김 → 30초 가로 14컷, 세로 18컷이 상한이다.
