# Quality Gate — 완료 게이트 (STEP 25)

DEEP 모드에서는 아래를 확인한 뒤 전략/HTML 단계로 넘어간다.
**막는 건 최소선(20개) 미달일 때만.** 목표(30개)에 못 미쳐도 20개 이상이면 진행하고, 못 채운 이유와 개수를 `12_sources.json`/`limitations`에 남긴다. 이유: 못 넘어가는 것보다 20개로라도 진행하는 게 낫다 — 리서치는 이후에도 보강할 수 있다.

| 개수 | 판정 |
|---|---|
| 30개 이상 | 목표 충족 — 그대로 진행 |
| 20~29개 | **조건부 통과** — 진행하되 부족분·이유를 산출물에 기록 |
| 20개 미만 | 게이트 미통과 — HTML 완성 처리하지 말고 추가 조사 |

## ① 프로젝트·브랜드
- [ ] 프로젝트 성격 정의됨
- [ ] 브랜드 팩트북 작성됨
- [ ] 타깃이 행동·욕구 기준으로 정의됨
- [ ] FACT·CLIENT CLAIM·INFERENCE·HYPOTHESIS·UNKNOWN 구분됨
- [ ] 현재 상태 vs 목표 상태 비교됨
- [ ] 진짜 해결 문제가 의사결정 질문으로 정의됨

## ② 경쟁 시장
- [ ] 경쟁·대체 브랜드 **20개 이상**(목표 30 — 미달 시 부족분·이유 기록)
- [ ] 모든 브랜드에 출처 존재
- [ ] 핵심 브랜드 2개 이상 출처 검증(T1 포함)
- [ ] 3~5개 카테고리로 군집
- [ ] 카테고리별 공통점·한계 존재
- [ ] 축 후보 3세트 이상
- [ ] 최종 축 선정 이유 존재
- [ ] XY 좌표 근거 존재
- [ ] 화이트스페이스가 기회/함정(4유형)으로 구분

## ③ 이종업계
- [ ] 이종업계 사례 **20개 이상**(목표 30 — 미달 시 부족분·이유 기록)
- [ ] 모든 사례에 출처 존재
- [ ] 프로젝트 문제와 연결 이유 존재
- [ ] 3~5개 카테고리로 군집
- [ ] 차용 원리 vs 모방 금지 요소 구분

## ④ 전략
- [ ] 브랜드 자산과 시장 기회 연결됨
- [ ] 전략 대안 2개 이상
- [ ] 추천 전략의 선택 이유 존재
- [ ] 선택하지 않은 방향 명시
- [ ] 리스크·검증 계획 존재
- [ ] 핵심 주장에 Evidence ID 연결

## ⑤ HTML
- [ ] 기존 HTML 디자인 문법 유지(현재 골든: `references/dashboard-golden-example.html`)
- [ ] 브랜드 팩트북 노출
- [ ] 경쟁사 20+ 실제 카드로 확인(목표 30)
- [ ] 이종업계 20+ 실제 카드로 확인(목표 30)
- [ ] 주요 3개 카테고리 카드로 노출
- [ ] 각 카드에서 출처 확인 가능
- [ ] XY맵·좌표 근거 확인 가능
- [ ] 화이트스페이스 기회·위험 함께 노출
- [ ] 리서치→전략 연결이 보임

## 판정 출력
```
GATE RESULT: PASS | CONDITIONAL PASS | HOLD
- 경쟁 N개(목표 30) · 이종업계 N개(목표 30)
- 부족분 이유: [있으면 기록, 30 채웠으면 생략]
- 미달 항목(20개 미만 또는 그 외 필수 항목): [영역/항목]
- 다음 액션: [PASS·CONDITIONAL PASS면 HTML 진행 / HOLD면 해당 스킬로 되돌림]
```
> 자동 점검 보조: 각 카드/사례 수는 `report-data.json`의 `*_count` 필드와 실제 카드 수를 대조한다.
