# Quality Gate — 완료 게이트 (STEP 25)

DEEP 모드에서는 아래를 **모두 충족하기 전** 전략/HTML 단계로 넘어가지 않는다.
미달 항목이 하나라도 있으면 `deck.html`을 완성 처리하지 말고 해당 단계로 되돌려 추가 조사한다.

## ① 프로젝트·브랜드
- [ ] 프로젝트 성격 정의됨
- [ ] 브랜드 팩트북 작성됨
- [ ] 타깃이 행동·욕구 기준으로 정의됨
- [ ] FACT·CLIENT CLAIM·INFERENCE·HYPOTHESIS·UNKNOWN 구분됨
- [ ] 현재 상태 vs 목표 상태 비교됨
- [ ] 진짜 해결 문제가 의사결정 질문으로 정의됨

## ② 경쟁 시장
- [ ] 경쟁·대체 브랜드 **30개 이상**
- [ ] 모든 브랜드에 출처 존재
- [ ] 핵심 브랜드 2개 이상 출처 검증(T1 포함)
- [ ] 3~5개 카테고리로 군집
- [ ] 카테고리별 공통점·한계 존재
- [ ] 축 후보 3세트 이상
- [ ] 최종 축 선정 이유 존재
- [ ] XY 좌표 근거 존재
- [ ] 화이트스페이스가 기회/함정(4유형)으로 구분

## ③ 이종업계
- [ ] 이종업계 사례 **30개 이상**
- [ ] 모든 사례에 출처 존재
- [ ] 프로젝트 문제와 연결 이유 존재
- [ ] 3~5개 카테고리로 군집
- [ ] 차용 원리 vs 모방 금지 요소 구분

## ④ 전략
- [ ] 브랜드 자산과 시장 기회 연결됨
- [ ] 전략 대안 2개 이상
- [ ] 추천 전략의 선택 이유 존재
- [ ] 선택하지 않은 방향 명시
- [ ] 리스크·검증 계획 존재
- [ ] 핵심 주장에 Evidence ID 연결

## ⑤ HTML
- [ ] 기존 HTML 디자인 문법 유지
- [ ] 브랜드 팩트북 노출
- [ ] 경쟁사 30+ 실제 카드로 확인
- [ ] 이종업계 30+ 실제 카드로 확인
- [ ] 주요 3개 카테고리 카드로 노출
- [ ] 각 카드에서 출처 확인 가능
- [ ] XY맵·좌표 근거 확인 가능
- [ ] 화이트스페이스 기회·위험 함께 노출
- [ ] 리서치→전략 연결이 보임

## 판정 출력
```
GATE RESULT: PASS | HOLD
- 미달 항목: [영역/항목]
- 필요한 추가 조사: [무엇을 몇 개 더]
- 다음 액션: [해당 스킬로 되돌림]
```
> 자동 점검 보조: 각 카드/사례 수는 `report-data.json`의 `*_count` 필드와 실제 카드 수를 대조한다.
