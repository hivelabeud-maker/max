# Insight & Strategy — 인사이트·키워드·전략 (STEP 6~7)

산출: `outputs/10_insights.md` · `outputs/11_strategy.md`(브랜드 밸류 키워드 포함).
리서치(04~09)를 근거로 삼는다. 모든 핵심 주장에 `Evidence ID`(EV-C…, EV-X…) 연결.

---

## STEP 6 — 핵심 인사이트 → `10_insights.md`
**정보 요약 ≠ 인사이트.** 각 인사이트 구조:
- 관찰된 현상 · 연결된 근거(Evidence ID) · 현상이 발생한 이유 · 고객/시장의 긴장 ·
  아직 해결되지 않은 욕구 · 브랜드가 개입할 기회 · 전략적 의미 · 확신도.

"경쟁사가 AI를 많이 쓴다" 수준으로 끝내지 않는다. 관찰 → 패턴 → 긴장 → 인사이트로 전개.
```
관찰 → 패턴 → 긴장(고객이 겪는 진짜 불편) → 인사이트(새 차별 가치)
```

## STEP 6.5 — 브랜드 밸류 키워드 → `11_strategy.md` 상단
전략 대안을 만들기 전, 인사이트를 **감각 언어 3갈래(A/B/C)**로 먼저 번역한다.
숫자·구조가 아니라 **몸으로 느끼는 톤**을 잡는 단계다(Manus-1 "전략 키워드 10→5→3"의 후속).

각 클러스터:
- **2행 타이틀**: 형용사/감각어 — 오브젝트·모티프 (예: `SLOW — JELLY WOBBLE`). 영문 대문자로 쓰면 감각이 잘 살지만, 한글로 써도 된다.
- **키워드 태그 3개**: 그 감각을 구성하는 하위 단어(예: 웨블링·머뭇거림·말랑함)
- **설명 한 문단**: 왜 이 감각인지, 무엇을 배신/증명하는지 — 추상어 나열이 아니라 장면으로.
- **그래픽 모티프·사운드**: 이 감각을 시각·청각으로 옮기면 무엇이 되는지 한 줄(레퍼런스·크리에이티브 착수 시 바로 쓸 힌트).

**3갈래는 반드시 인사이트에서 나온다.** 근거 없이 감각적으로 지어내지 않는다 — 각 클러스터가 어떤 인사이트(`10_insights.md`)·화이트스페이스에서 왔는지 한 줄로 밝힌다.
클러스터 간 감각이 겹치면 안 된다(예: 세 개가 다 "프리미엄"이면 실패). 서로 다른 신체 감각·속도·질감으로 벌린다.

```json
"brand_value_keywords": [
  { "id": "A", "title_top": "SLOW", "title_bottom": "JELLY WOBBLE",
    "tags": ["웨블링", "머뭇거림", "말랑함"],
    "description": "…",
    "sensory_label": "그래픽 모티프·사운드", "sensory_note": "번트케이크 리브 텍스처 · 말랑한 저음 ASMR",
    "source_insight": "I2" }
]
```

## STEP 7 — 전략 대안·추천 전략 → `11_strategy.md`
**최소 2개, 권장 3개** 대안. 각 대안:
전략명 · 전략 한 문장 · 해결하는 문제 · 핵심 타깃 · 제공 가치 · 차별화 논리 ·
**활용하는 브랜드 자산** · **연결된 시장 기회** · 이종업계 차용 원리 · 실행 방식 · 기대 효과 ·
리스크 · 필요 조건 · **선택 시 포기해야 할 것** · 연결 Evidence ID.

**전략 비교 기준**: 고객 가치 · 브랜드 적합성 · 차별성 · 실행 가능성 · 시장 지속성 · 사업 확장성 · 근거 강도.

**최종 추천 전략**: 추천 이유 · 선택하지 않은 전략 · 선택 안 한 이유 · 핵심 전략 원칙 ·
실행 우선순위 · 리스크 · 추가 검증 계획 · 성공 기준.

> 전략은 디자인 키워드가 아니라 **선택과 포기의 논리**다. 브랜드 자산(팩트북)과 시장 기회(화이트스페이스)를 반드시 연결한다.
