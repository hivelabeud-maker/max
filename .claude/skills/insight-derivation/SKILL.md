# 인사이트 도출

리서치와 제안 사이의 다리다. `marketer` CH1(팩트) 다음, CH2·CH3(진단·문제 정의) 안에서 돌린다.
결과는 `pyramid-principle`의 키라인 재료가 된다.

사실을 나열하면 보고서고, 사실에서 긴장을 찾아내면 제안이다.

## 5단 사다리
아래로 내려가지 말고 한 칸씩 올라간다. 칸을 건너뛰면 근거 없는 주장이 된다.

| 층 | 무엇 | 예 |
|---|---|---|
| 1 사실 | 검증된 숫자·기록. 출처와 티어가 붙는다 | "20대 비보조 인지도 8%, 30대 31%" |
| 2 관찰 | 사실들을 나란히 놓았을 때 보이는 것 | "인지도는 낮은데 구매 후 만족도는 전 연령 1위" |
| 3 긴장 | 서로 안 맞는 두 사실. 여기가 인사이트의 원료다 | "제품은 좋은데 20대는 존재를 모른다 — 광고비는 20대에 가장 많이 썼다" |
| 4 인사이트 | 긴장의 원인에 대한 판단. 반대 주장이 성립해야 한다 | "20대에게 이 브랜드는 안 보이는 게 아니라, 봐도 무엇인지 이해되지 않는다" |
| 5 함의 | 그래서 무엇을 바꾸는가 | "노출량이 아니라 첫 3초의 이해도를 KPI로 바꾼다" |

3층(긴장)이 비면 인사이트는 나오지 않는다. 사실만 많고 인사이트가 안 나올 때는 대개 서로 충돌하는 사실 쌍을 안 찾은 것이다.

## UX·행동 관점 통과 (필수)
4층으로 올라가기 전에 아래 다섯 질문을 반드시 한 번 거친다. 이 통과가 인사이트를 "느낌"에서 "설계 근거"로 바꾼다.

1. **누가, 어느 순간에** — 이 사실은 사용자 여정의 어느 지점에서 발생하는가 (인지 / 탐색 / 비교 / 결정 / 사용 / 재구매)
2. **무엇을 하려다 막혔나** — 사용자가 달성하려던 일(job)은 무엇이고 무엇이 막았는가
3. **어떤 정보가 없었나** — 결정에 필요한데 화면·소재에 없던 정보는 무엇인가
4. **무엇으로 대체했나** — 우리 대신 무엇을 썼는가. 경쟁 제품일 수도, 아무것도 안 하는 것일 수도 있다
5. **다시 하라면 어디서 바뀌나** — 한 지점만 바꿔서 결과를 뒤집을 수 있는 곳은 어디인가

이 다섯 답이 그대로 제안의 명분 문장이 된다.

## 명분(rationale) 만들기
제안 한 건마다 아래 네 줄이 붙어야 한다. 네 줄이 없으면 그 제안은 취향이다.

```
근거: {1층 사실 + 출처 티어}
관찰: {2~3층에서 찾은 긴장}
판단: {4층 인사이트}
그래서: {이 제안이 그 긴장을 어디서 끊는가}
```

## 절차
1. `source-grading`을 통과한 사실만 1층에 올린다. 미확인 사실은 회색으로 두고 명분에 쓰지 않는다
2. 사실을 2~4개씩 묶어 관찰을 만든다
3. 관찰 중 서로 충돌하는 쌍을 찾는다. 충돌이 없으면 사실이 부족하거나 조사 축이 하나뿐이다
4. UX 5질문을 통과시킨다
5. 인사이트를 쓴다. 반대 주장이 성립하는지 확인한다
6. 함의를 쓴다. 무엇을 바꿀지가 나와야 한다
7. 인사이트 개수를 세지 말고 남길 것만 남긴다. 2개면 2개다

## 출력 템플릿

```markdown
## 인사이트 카드
### INS-01. {인사이트 한 문장}
| 층 | 내용 |
|---|---|
| 사실 | {수치} · 출처 {T?} |
| 사실 | {수치} · 출처 {T?} |
| 관찰 | |
| 긴장 | A는 이런데 B는 저렇다 |
| UX 지점 | 여정 단계: / 막힌 일: / 없던 정보: / 대체한 것: |
| 인사이트 | |
| 반대 주장 | {성립하는 반대 주장 — 없으면 인사이트가 아니라 사실 요약} |
| 함의 | |
| 연결되는 제안 | |

## 명분 매핑
| 제안 항목 | 근거 인사이트 | 근거 티어 | 미확인 여부 |
|---|---|---|---|
```

## 품질 게이트
- 인사이트마다 충돌하는 사실 쌍이 있는가
- 반대 주장이 성립하는가
- UX 5질문을 통과했는가
- 제안 항목 중 근거 인사이트가 없는 것이 있는가
- 미확인 사실을 명분으로 쓰지 않았는가

## 자주 나오는 실패
- **사실 요약을 인사이트라고 부름** — "20대 인지도가 낮다"는 사실이지 인사이트가 아니다
- **긴장 없이 결론으로 점프** — 근거는 있는데 왜 그 결론인지 설명이 없다
- **모두가 아는 얘기** — 클라이언트가 이미 아는 것을 인사이트로 내면 제안이 약해진다. 4층에서 "이건 저쪽도 아나?"를 한 번 묻는다
