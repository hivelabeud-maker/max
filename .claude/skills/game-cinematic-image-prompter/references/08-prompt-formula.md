# 프롬프트 생성 공식 (Gate 4부터 사용)

## 기본 공식

`연속성 잠금 + 장면 기능 + 구도/배치 + 카메라 + 디자인 문법 + 재질 + 시간/조명 + 공간 깊이/스케일 + 렌더 품질 + 금지 요소`

이 순서를 매번 지킨다. 순서를 바꾸면 모델이 뒤쪽 조건(금지 요소, 렌더 품질)에 과도한 가중치를 주는 경향이 있다.

## 품질 문장 — 관찰 가능한 조건으로 쓴다

`Ultra photorealistic, 8K, masterpiece` 같은 품질 태그는 보조일 뿐이다. 아래를 관찰 가능한 조건으로 구체화한다.

- 입체감: 전면 장식 뒤에 실제 구조 깊이, 측면 벽체, 후면 구조, 내부 암부
- 재질: 서로 다른 재질군의 거칠기·반사·모서리 반응 차이
- 스케일: 작은 인물·오브젝트·반복 구조 같은 비교 척도
- 카메라: 높이, 렌즈, 축, 소실점, 피사체 점유율
- 조명: 광원 위치, 밝기 비율, 하이라이트 보존, 그림자 정보

## 품질 문장 예시 (프로젝트에 맞게 선택적으로 조정)

> 최고급 AAA 게임 시네마틱 환경 렌더. 물리 기반 조명과 재질 표현, 초고밀도 지오메트리, 자연스러운 간접광과 접촉 그림자. 재질의 미세한 결정 입자와 절삭 흔적, 모서리의 절제된 마모, 재질 간 거칠기 차이와 반사, 구조 사이의 실제 깊이와 차폐 그림자, 다층 대기 원근을 선명하게 표현한다. 전경·중경·원경을 분리하고 원경까지 형태가 뭉개지지 않는 고해상도 시네마틱 배경 플레이트, HDR 명암 범위, 절제된 블룸, 안정된 선명도.

## 편집 프롬프트 고정 문장

### 첫 문장(모든 편집 프롬프트에 포함)

> "현재 승인된 이미지를 유일한 구조 기준으로 사용한다. 전체 실루엣, 중앙축, 높이와 폭의 비례, 문과 계단의 위치, 좌우 건축 배치, 지형, 시간대, 날씨, 색상 팔레트와 주광 방향을 변경하지 않는다. 이번 패스에서는 지정된 편집 변수 하나만 변경한다."

이 문장은 `references/13-approval-gates.md`에 있는 것과 정확히 같다. 둘 중 하나를 고칠 때는 반드시 다른 쪽도 같이 고친다.

### 끝 문장(모든 편집 프롬프트에 포함)

> 현재 구도와 기본 조형을 변경하지 않는다. 새로운 구조물, 인물, 생물, 문양 체계, 시간대, 광원을 추가하지 않는다. 중앙 구조 왜곡, 좌우 비대칭, 문양 뭉개짐, 과도한 샤프닝, 가짜 HDR, 네온 발광, 과도한 블룸, 검게 뭉개진 암부, 흰색으로 날아간 하이라이트, 글자와 로고를 생성하지 않는다.

이 두 문장은 프로젝트마다 고유명사만 바꾸고 구조는 그대로 쓴다.
