# SB 분석 기준 (Gate 1)

## 먼저 읽을 것

프롬프트보다 먼저 SB가 말하는 변화를 해석한다. 원본 SB 전체를 먼저 분석한다. 사실과 추론을 분리한다 — "SB에 명시됨"과 "화면 구성으로 미루어 추정함"을 다른 줄에 쓴다.

## 장면별 표 — 12개 항목

각 장면에서 아래를 기록한다.

| 항목 | 질문 |
|---|---|
| 장면 번호·러닝타임 | 몇 번 장면이고 몇 초인가 |
| 서사적 기능 | 이 장면이 전체 이야기에서 하는 역할은 무엇인가 |
| 전달해야 할 감정 | 이 장면이 관객에게 남길 감정은 무엇인가 |
| 핵심 공간과 주요 피사체 | 어디이고 무엇을 보여주는가 |
| 캐릭터 수와 배치 예정 영역 | 몇 명이 화면 어디에 서는가 |
| 카메라 거리·높이·렌즈·앵글·움직임 | 촬영 조건 전체 |
| 전경·중경·원경·하늘의 공간 구조 | 네 층이 각각 무엇으로 채워지는가 |
| 이전·다음 장면과 연결하는 시각적 전환 | 컷과 컷 사이에서 무엇이 이어지는가 |
| 반드시 유지할 요소 | 이 장면에서 절대 바뀌면 안 되는 것 |
| 변화하는 요소 | 이 장면 안에서 실제로 바뀌는 것 |
| 예상되는 AI 생성 오류 | 이 장면을 생성할 때 모델이 흔히 틀리는 지점(예: 좌우 비대칭, 문양 뭉개짐, 근거 없는 발광) |
| 필요한 배경 클린 플레이트 | 인물·FX 없이 먼저 확보해야 할 배경 |

## 전체 요약

장면별 표가 끝나면 SB 전체를 관통하는 **공간 이동 경로**(어디에서 시작해 어디로 이동하는가)와 **감정 곡선**(감정이 장면마다 어떻게 오르내리는가)을 각각 한 단락으로 요약한다.

## 출력 규칙

- 확인 질문은 최대 5개로 제한한다. 답이 없으면 안전한 기본 가정을 별도 항목으로 표시하고 진행한다.
- 사용자의 승인 전에는 이미지 프롬프트를 쓰지 않는다.

## 주의

이 표는 매 프로젝트마다 새로 작성한다. 이전 프로젝트의 SB 해석 내용을 이번 표의 기본값으로 가져오지 않는다 — 세계관과 사건 구조가 다르면 해석 기준도 다시 세운다. 실제 채워진 표는 이 파일이 아니라 해당 프로젝트 폴더의 `01-sb-analysis-output.md`에 쓴다.
