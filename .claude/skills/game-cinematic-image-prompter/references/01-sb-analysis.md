# SB 분석 기준 (Gate 1)

## 먼저 읽을 것

프롬프트보다 먼저 SB가 말하는 변화를 해석한다. 각 컷에서 아래를 기록한다.

| 항목 | 질문 |
|---|---|
| 시간 | 몇 초이며 앞뒤 컷과 어떻게 이어지는가 |
| 사건 | 화면 안에서 실제로 무엇이 변하는가 |
| 의미 | 이 변화가 서사에서 무엇을 뜻하는가 |
| 공간 기능 | 이 컷의 공간이 하는 역할은 무엇인가(접근·관문·이동·대치·상승 등) |
| 감정 | 이 컷이 전달하는 감정 상태는 무엇인가 |
| 카메라 | 거리, 높이, 축, 움직임은 무엇인가 |
| 합성 | 캐릭터·오브젝트·FX가 들어갈 여백은 어디인가 |
| 연속성 | 유지되어야 할 장소·시간·날씨·빛은 무엇인가 |

## 출력 규칙

- 사실과 추론을 분리한다. "SB에 명시됨"과 "화면 구성으로 미루어 추정함"을 다른 줄에 쓴다.
- 컷별 핵심 문장을 한 줄로 쓴다.
- 필요한 무인 배경 플레이트를 컷마다 명시한다(예: "외부 원경 1장, 문 디테일 1장").
- 확인 질문은 최대 5개로 제한한다. 답이 없으면 안전한 기본 가정을 별도 항목으로 표시하고 진행한다.
- 사용자의 승인 전에는 이미지 프롬프트를 쓰지 않는다.

## 주의

이 표는 매 프로젝트마다 새로 작성한다. 이전 프로젝트의 SB 해석 내용을 이번 표의 기본값으로 가져오지 않는다 — 세계관과 사건 구조가 다르면 해석 기준도 다시 세운다. 실제 채워진 표는 이 파일이 아니라 해당 프로젝트 폴더의 `01-sb-analysis-output.md`에 쓴다.
