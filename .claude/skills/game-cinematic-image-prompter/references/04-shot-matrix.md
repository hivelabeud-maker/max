# Shot Matrix (Gate 3)

Visual Bible이 승인된 후 각 장면의 Shot Matrix를 작성한다.

## 숏별 12개 항목

| 항목 | 내용 |
|---|---|
| 숏의 역할 | 이 숏이 시퀀스에서 하는 일 |
| 카메라 좌표와 높이 | 공간 안에서의 위치와 눈높이 |
| 렌즈 | mm |
| 앵글과 틸트 | 수평/로우/하이, 틸트 각도 |
| 피사체의 화면 점유율 | 대략 몇 %를 차지하는가 |
| 캐릭터 합성 영역 | 인물이 들어갈 자리 |
| 전경·중경·원경 배치 | 세 층에 각각 무엇이 있는가 |
| 네거티브 스페이스 | 로고·카피·FX용으로 비워둘 자리 |
| 카메라 움직임 | 고정/돌리/크레인/틸트업 등 |
| 시작 프레임과 종료 프레임 | 움직이는 숏이라면 처음과 끝 구도 |
| 이전 숏에서 반드시 이어져야 할 요소 | 연속성 유지 항목 |
| 사용할 이미지 모델과 선택 이유 | `11-tool-routing.md` 기준으로 어떤 도구를 왜 쓰는가 |

## 이미지 제작 순서와 영상 편집 순서를 구분한다

실제 완성 영상에서 숏이 재생되는 순서와, 이미지를 만드는 순서는 다르다. 두 순서를 같은 문서에 각각 명시한다.

**이미지 제작 순서(구조에서 바깥으로)**

정면 미드와이드 구조 마스터 → 문과 계단의 디테일 확정 → 캐릭터 배치용 광장 → 원경 → 초원경·드론 → 좌우 앵글 → 상공 클린 플레이트.

이 순서를 쓰는 이유: 구조를 먼저 확정해야 이후 모든 파생 숏이 같은 기준을 공유한다. 디테일과 광장을 원경보다 먼저 확정하면, 원경에서 그 디테일이 실제로 어떻게 축약되는지 검증할 수 있다.

**영상 편집 순서(필요에 따라 반대로 구성 가능)**

예: 드론 원경 → 성 접근 → 광장 진입 → 로우앵글 → 문 클로즈업.

편집 순서는 서사 전달을 위한 것이라 제작 순서와 다를 수 있다. 제작이 끝난 뒤 편집 단계에서 재배열한다.
