# 씬 생성 규칙 (Gate 4-a)

## 기본 경로 — 1샷 생성

기본값은 후보 여러 장을 비교하는 것이 아니라, 레퍼런스와 설계를 먼저 정확히 잡고 한 장을 만드는 것이다.

1. **레퍼런스 정리** — `02-reference-role-audit.md` 기준으로 Structure/Design/Tone/Shot 역할을 확정한다.
2. **프롬프트 설계** — `08-prompt-formula.md`의 10단계 순서로 프롬프트를 쓴다. Visual Bible(Gate 2)과 Shot Matrix(Gate 3)에서 확정된 값을 그대로 가져온다.
3. **생성** — 한 장을 만든다.
4. **검토** — 사용자에게 제출하고 승인을 받는다.
   - **승인** → Gate 4-b(Structure Master 잠금)로 진행한다.
   - **불만족** → 처음부터 다시 만들지 않는다. 무엇이 안 맞는지 먼저 진단하고(레퍼런스 문제인지, 프롬프트 문제인지, 설계 자체 문제인지), 그 원인만 고쳐서 다시 생성한다. 두 가지 이상을 동시에 바꾸지 않는다.

이 경로에서는 캐릭터·FX 없는 무인 배경만 만든다.

## 선택 경로 — 마스터 시안 3안 비교

사용자가 "3안 비교해줘", "여러 방향으로 비교하고 싶다" 등으로 **명시적으로 요청할 때만** 쓴다. 기본 경로보다 시간·비용이 3배 들기 때문에, 요청 없이 먼저 3안을 만들지 않는다.

### 왜 3안이 필요할 때가 있는가

첫 이미지부터 한 방향으로 고정하면 SB 충실도·게임 고유성·시네마틱 임팩트 중 하나를 놓치기 쉽다. 방향이 불확실하거나 이해관계자 설득이 필요한 공간일 때, 같은 장소·같은 세계관·같은 시간대 안에서 해석 강도만 다른 3안을 만들어 비교한다.

### 3안 정의

**A안 — SB 충실형**: SB의 중앙축, 행동 공간, 정면 구도를 가장 강하게 보존한다. 새로운 환경 요소를 최소화한다. 후속 캐릭터 합성과 편집 안정성이 가장 높다.

**B안 — 게임 고유 양식 확장형**: 실제 게임 리소스·세계관의 조형 문법(건축 언어, 문양, 상징물 등)을 강화한다. SB의 장면 기능은 유지한다.

**C안 — 시네마틱 스케일 극대화형**: 고도차, 다층 구조, 대기 원근, 비교 척도를 적극 사용해 규모를 극대화한다. B안과 같은 중심 구조물을 유지한다.

세 안 모두 캐릭터와 FX 없이 무인 배경으로만 만든다.

### 평가표

| 평가축 | 질문 |
|---|---|
| SB 충실도 | 원래 사건과 화면 기능이 즉시 읽히는가 |
| 게임 고유성 | 일반 판타지·SF가 아니라 이 게임의 조형 문법이 보이는가 |
| 시네마틱 임팩트 | 규모, 깊이, 빛, 실루엣이 압도적인가 |
| 합성성 | 캐릭터·오브젝트·FX를 넣을 여백이 있는가 |
| 연속 제작성 | 원경·근경·내부·상공으로 파생 가능한가 |

### 출력 양식

| 안 | 방향 | SB 충실도 | 게임 고유성 | 시네마틱 임팩트 | 합성성 | 연속 제작성 | 합계 |
|---|---|---:|---:|---:|---:|---:|---:|
| A | SB 충실형 | | | | | | |
| B | 게임 고유 양식 확장형 | | | | | | |
| C | 시네마틱 스케일 극대화형 | | | | | | |

추천안과 이유를 표 아래에 서술하고, 최종 선택은 사용자 승인으로 확정한다. 승인 즉시 Gate 4-b로 넘어간다.
