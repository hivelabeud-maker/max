# 세션 재개 프로토콜

Claude Code 세션은 컨테이너 단위로 초기화된다. 이전 세션에서 진행하던 프로젝트로 돌아왔을 때, Gate 1부터 다시 시작하지 않도록 아래 순서로 상태를 복원한다.

## 복원 순서

1. `.claude/projects/`에서 해당 프로젝트 폴더를 찾는다. 폴더명이 기억나지 않으면 `.claude/projects/_index.md`에서 찾는다.
2. `00-note.md`의 **요약 섹션**을 읽는다 — 현재 승인된 게이트 단계와 잠긴 마스터 이름이 여기 있어야 한다.
3. 요약에 적힌 현재 게이트에 해당하는 번호 파일(`0X-....md`)을 읽어 마지막으로 제출된 내용을 확인한다.
4. `06-master-lock-record.md`가 존재하면 반드시 읽는다 — 이후 모든 작업은 이 잠금 내용을 전제로 한다.
5. 복원한 상태를 한 줄로 요약해 사용자에게 확인받은 뒤 다음 작업을 진행한다. 확인 없이 임의로 다음 게이트를 시작하지 않는다.

## 상태 파일이 없거나 불완전할 때

- `00-note.md` 자체가 없으면 새 프로젝트로 간주하고 `assets/project-template/`를 복제하는 것부터 시작한다.
- 요약 섹션은 있는데 해당 게이트의 번호 파일이 비어 있으면, 요약을 신뢰하지 말고 사용자에게 "어느 게이트까지 실제로 승인됐는지" 직접 확인한다. 파일 소실 가능성을 함께 알린다.
- Master Lock 이후 단계인데 `06-master-lock-record.md`가 비어 있으면 절대 Gate 6 작업을 진행하지 않는다. 먼저 Gate 5A를 다시 확인한다.

## 재개 후 첫 응답 형식

```
■ [프로젝트명] 재개
마지막 확인된 상태: Gate [번호] — [상태]
잠긴 마스터: [있음/없음, 있다면 이름]
다음 작업 제안: [무엇을 이어서 할지]

이대로 이어가도 될까요?
```
