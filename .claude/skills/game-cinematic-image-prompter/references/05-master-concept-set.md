# Master Concept Set 3안 생성 규칙 (Gate 4-a)

## 왜 3안인가

첫 이미지부터 한 방향으로 고정하면 SB 충실도·게임 고유성·시네마틱 임팩트 중 하나를 놓치기 쉽다. 그래서 **같은 장소, 같은 세계관, 같은 시간대** 안에서 해석 강도만 다른 3안을 만든다. 서로 다른 장소를 3개 만드는 것이 아니다.

## 3안 정의

### A안 — SB 충실형

- SB의 중앙축, 행동 공간, 정면 구도를 가장 강하게 보존한다.
- 새로운 환경 요소를 최소화한다.
- 후속 캐릭터 합성과 편집 안정성이 가장 높다.

### B안 — 게임 고유 양식 확장형

- 실제 게임 리소스·세계관의 조형 문법(건축 언어, 문양, 상징물 등)을 강화한다.
- SB의 장면 기능은 유지한다.
- 특별한 사유가 없으면 이 안을 기본 추천안으로 둔다.

### C안 — 시네마틱 스케일 극대화형

- 고도차, 다층 구조, 대기 원근, 비교 척도를 적극 사용해 규모를 극대화한다.
- 구조가 과도하게 바뀌지 않도록 B안과 같은 중심 구조물을 유지한다.
- 극원경·드론·키비주얼 후보로 쓴다.

세 안 모두 캐릭터와 FX 없이 무인 배경으로만 만든다. Gate 4 이전에는 프롬프트를 쓰지 않았지만, 이 게이트에서는 3안 각각의 프롬프트·네거티브·도구 설정까지 제출한다.

## 평가표

각 안을 5개 축으로 1–5점 평가하고 추천 이유를 쓴다.

| 평가축 | 질문 |
|---|---|
| SB 충실도 | 원래 사건과 화면 기능이 즉시 읽히는가 |
| 게임 고유성 | 일반 판타지·SF가 아니라 이 게임의 조형 문법이 보이는가 |
| 시네마틱 임팩트 | 규모, 깊이, 빛, 실루엣이 압도적인가 |
| 합성성 | 캐릭터·오브젝트·FX를 넣을 여백이 있는가 |
| 연속 제작성 | 원경·근경·내부·상공으로 파생 가능한가 |
