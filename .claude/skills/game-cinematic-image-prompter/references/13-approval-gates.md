# 승인 게이트 상세 — 이 파일이 게이트 정의의 유일한 정본이다

다른 문서(SKILL.md, Claude Project Instructions 등)는 게이트 순서를 여기서 참조만 하고 재서술하지 않는다. 게이트 규칙을 바꿀 때는 이 파일 하나만 고친다.

## Gate 0 — 프로젝트 준비

제출물: 프로젝트 브리프 확인 결과, 부족한 항목 목록.
금지: 이미지 프롬프트.

## Gate 1 — SB 분석

제출물: 컷별 사건·의미·감정·공간 기능, 카메라 의도와 전환, 필요한 클린 플레이트 목록, 확인 질문(최대 5개).
금지: 이미지 프롬프트, 모델 설정, 업스케일 설정.

## Gate 2 — Visual Bible

제출물: 세계 정의, 조형 계층, 재질·색·빛·시간·날씨, 레퍼런스 역할표, 유지·변경·금지 목록.
금지: 샷별 장문 프롬프트.

## Gate 3 — Shot Matrix

제출물: 샷 번호와 기능, 화면 크기·카메라 높이·렌즈·축·움직임, 캐릭터·FX 합성 여백, 마스터와 파생 관계.

## Gate 4 — Master Concept Set

제출물: 무인 중원경 정면 마스터 시안 3안(A: SB 충실형, B: 게임 고유 양식 확장형, C: 시네마틱 스케일 극대화형), 각 안의 구도 설명·프롬프트·네거티브·도구 설정, 5축 평가표와 추천안.

## Gate 5A — Master Lock

제출물: 선택된 마스터의 연속성 잠금 문장 전체(`06-master-lock.md` 형식).
전제: Gate 4에서 하나의 안이 사용자 승인으로 확정되어야 시작한다.

## Gate 5B — Scene Gap Analysis

제출물: SB 샷과 확보된 이미지 대조표, 6개 카테고리별 공백 목록, 필수/권장/선택 분류, 각 추가 씬의 목적·부모 마스터·카메라·합성 여백·추천 도구·난이도.
금지: 이 단계에서는 추가 씬의 목적과 목록만 승인받는다. 장문 프롬프트는 아직 쓰지 않는다.

## Gate 6 — 파생 제작

각 요청마다 다음 중 하나만 제출: 리프레임 / 부분 수정 / 시간 변형 / 클린 배경 / FX 플레이트 / 캐릭터 합성용 플레이트.

## Gate 7 — Finish

제출물: 업스케일 설정, 영상화 설정, 해상도·프레임레이트·샷 길이, QC 체크 결과, 원본·승인 마스터·편집본·업스케일본의 버전명(`10-delivery-manifest.md` 형식).

## 모든 게이트 공통 규칙

- 각 게이트 제출은 `승인할 항목 / 수정 가능한 항목 / 다음 Gate에서 할 일`로 끝낸다.
- 사용자의 명시적 승인 없이 다음 게이트로 진행하지 않는다.
- 부분승인·반려가 발생하면 `16-revision-protocol.md`를 따른다.
