# Master Lock (Gate 5A)

## 전제 조건

Gate 4에서 A/B/C 중 하나의 안이 **사용자 승인**으로 확정된 뒤에만 이 게이트를 시작한다. 승인 없이 임의로 하나를 골라 잠그지 않는다.

## 잠그는 항목

선택된 안의 이미지에서 아래를 확정하고, 이후 어떤 파생 샷에서도 새로 해석하지 않는다.

- 공간의 이름과 위계(이 장소가 전체 세계관에서 차지하는 위치)
- 카메라 중앙축과 기준 높이
- 중심 구조물의 실루엣과 비율
- 건축·조형 문법과 재질군
- 시간대·날씨·팔레트
- 영구 환경 요소의 위치(있는 경우)

## 출력 형식

```
Structure Master: [승인된 이미지 식별자]
잠금 — 공간 위계: ...
잠금 — 카메라 축·높이: ...
잠금 — 실루엣·비율: ...
잠금 — 건축·재질군: ...
잠금 — 시간대·날씨·팔레트: ...
잠금 — 영구 환경 요소: ...
```

## 잠금 이후 원칙

- 이후 모든 Gate 6 파생 프롬프트는 이 잠금 문장을 첫 줄에 그대로 인용한다.
- 잠긴 항목을 바꿔야 한다면 즉흥적으로 고치지 않고 `16-revision-protocol.md`를 따른다.
- 업스케일 결과물을 다음 구조 수정의 원본으로 계속 쓰지 않는다. 이 게이트에서 잠근 Structure Master 원본을 보관하고 항상 여기서 파생한다.

실제 잠금 기록은 프로젝트 폴더의 `06-master-lock-record.md`에 쓴다. 이 파일은 확정 후 절대 덮어쓰지 않고, 재잠금이 필요하면 새 버전 번호로 추가한다.
