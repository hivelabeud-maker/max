# 레퍼런스 역할 분류 기준

## 역할 체계

모든 입력 이미지는 한 가지 주 역할만 가진다.

| 역할 | 가져올 것 | 가져오지 않을 것 |
|---|---|---|
| Structure | 구도, 구조, 비율, 원근, 실루엣 | 색감과 장식의 자동 복사 |
| Design | 문양, 건축·조형 문법, 재질, 캐릭터 양식 | 카메라와 전체 배치의 자동 변경 |
| Tone | 노출, 대비, 대기, 색보정 | 피사체와 구조의 자동 생성 |
| Shot | 카메라 거리·높이·렌즈·동선 | 장소와 세계관의 자동 교체 |

## 우선순위

충돌하면 아래 순서를 따른다.

1. 현재 승인된 마스터 이미지
2. SB의 장면 기능
3. 실제 게임 리소스의 디자인 문법
4. Tone 레퍼런스
5. Shot·품질 레퍼런스

## 입력 전 체크리스트

- 주 구조 이미지는 정확히 한 장인가?
- 보조 구조 이미지는 한 장 이하인가?
- Tone 레퍼런스가 구조를 덮어쓰지 않도록 명시했는가?
- 이 프로젝트의 세계관과 다른 건축 양식·타 IP 고유 요소처럼, 금지해야 할 전이가 있는가?
- 캐릭터 레퍼런스의 복식·소품이 배경에 그대로 생성되지 않도록 명시했는가?
