# 납품 전 QC 체크리스트 (Gate 7)

각 항목을 `통과 / 수정 / 재생성`으로 표시한다. 판정 이후 처리는 아래 "판정별 처리"를 따른다.

## 구조

- 중앙축과 소실점이 안정적인가?
- 구조물이 얇은 파사드가 아니라 실제 점유 공간과 깊이를 가지는가?
- 곡선·직선 요소가 비정상적으로 휘지 않았는가?
- 반복 단(계단·층 등)의 단차와 폭이 일관적인가?
- 개폐 상태가 컷 의도와 맞는가?

## 디자인

- 이 프로젝트 고유의 조형 문법이 보이는가, 아니면 일반적인 판타지/SF로 뭉개졌는가?
- 세력·진영이 있는 세계관이라면, 화면이 좌우로 분리되지 않았는가?
- Visual Bible의 팔레트가 한 구조 안에서 통합되는가?
- 문양이 지나치게 단순화되지 않았는가?

## 카메라

- 렌즈와 카메라 높이가 샷 목적에 맞는가?
- 광각 왜곡, 어안, 휘어진 수평선이 없는가?
- 캐릭터·오브젝트 합성 공간이 충분한가?
- 극원경에서 큰 실루엣과 층위가 읽히는가?

## 재질·빛

- 서로 다른 재질(석재·금속·유기물·물 등)이 서로 다른 반응을 보이는가?
- 접촉 그림자와 구조 차폐가 살아 있는가?
- 암부가 검게 뭉개지지 않았는가?
- 하이라이트가 날아가지 않았는가?
- 발광이 설정상 존재하는 곳에만 있는가?

## 배경 플레이트

- 클린 플레이트에 의도하지 않은 인물·생물·군중·글자·로고가 없는가?
- 캐릭터 합성 공간을 다른 오브젝트가 막지 않는가?
- 하늘 플레이트에 의도하지 않은 구조물이 없는가?

## 기술 결함

- 반복 패턴, 녹은 장식, 잘못된 대칭이 없는가?
- 과도한 샤프닝, 가짜 HDR, 색번짐, 블룸이 없는가?
- 업스케일 과정에서 새로운 문양·구조가 생기지 않았는가?

## 판정별 처리

- **통과**: 다음 샷으로 진행.
- **수정**: 어떤 영역을 어떻게 고칠지 `09-continuity-lock-and-local-edit.md`의 4영역(유지/수정/보호/금지)으로 지정해 같은 도구에서 국소 수정.
- **재생성**: 원인을 먼저 판정한다. 잠금 항목(`06-master-lock.md`) 자체가 잘못됐다면 Gate 4로 돌아가 마스터를 재검토한다. 파생 샷의 실행 오류라면 Gate 6에서 해당 샷만 다시 만든다. `16-revision-protocol.md`를 따른다.
