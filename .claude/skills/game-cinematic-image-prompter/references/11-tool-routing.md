# 도구별 역할과 권장 설정

도구 UI와 모델명은 자주 바뀐다. 아래 역할 분리는 유지하되, 실제 수치는 사용 시점의 화면에서 다시 확인한다.

**최종 확인일**: (이 값을 채운 사람이 실제 UI를 확인한 날짜를 적는다. 이 값이 3개월 이상 지났다면 아래 수치를 그대로 믿지 말고 먼저 실제 도구에서 현재 옵션을 확인한다.)

## 역할 라우팅

| 도구·모델 | 주 역할 | 피해야 할 사용 |
|---|---|---|
| Seedream 5.0 Pro | 신규 마스터 공간, 복잡한 레이아웃과 구조 탐색 | 승인 마스터의 정밀 보존 편집 |
| Nano Banana Pro | 기존 이미지 유지, 국소 편집, 리프레임, 시간 변형 | 구조가 없는 상태에서 무한 재설계 |
| Higgsfield Image | 스틸 베리에이션과 레퍼런스 조합 | 한 번에 여러 레퍼런스의 무차별 혼합 |
| Higgsfield Cinema Studio | 카메라 이동과 영상화 | 구조 확정 전 영상 생성 |
| Magnific Precision V2 | 최종 업스케일과 재질 회복 | 구조·문양 재설계 |
| Magnific Creative | 마스크된 영역의 제한적 디테일 보강 | 전체 이미지에 높은 창의성 적용 |

## 스틸 마스터

- 16:9 기준, 약 2048×1152 이상의 2K 탐색
- 후보 2–4장
- 승인 마스터는 가능하면 4K로 출력하거나 2배 업스케일 후 4K에서 검수
- 최종 납품이 1080p라도 4K 마스터를 다운스케일하면 원경의 큰 형태와 재질이 더 단단해진다.

## Magnific Precision V2 시작점

- Scale: 2×
- Preset: 사실적 3D 환경에 가장 가까운 프리셋
- Creativity: -5 ~ -3
- Resemblance: +6 ~ +8
- HDR: +1 ~ +3
- Fractality: -2 ~ 0
- Grain: 최소
- Sharpness: 낮음~중간

먼저 2×를 한 번만 수행한다. 구조가 바뀌면 Resemblance를 높이고 Creativity를 낮춘다. 문양이 인위적으로 매끈해지면 HDR과 Sharpness를 낮춘다.

## Higgsfield Cinema Studio 시작점

- 테스트: 720p, 최종: 1080p 이상, 24fps
- 한 샷 4–6초
- Look: 절제된 시네마 톤(과도한 필터 프리셋 지양)
- 심도: f/5.6–8 상당
- 움직임: 느린 dolly-in, crane, tilt-up 중 하나만 선택

## 반복 규칙

1. 생성 모델에서 구조를 확정한다.
2. 편집 모델에서 한 가지 수정만 한다.
3. Magnific은 마지막에만 쓴다.
4. 업스케일 결과를 다음 구조 수정의 원본으로 계속 쓰지 않는다. `06-master-lock.md`에서 잠근 Structure Master 원본을 보관하고 항상 거기서 파생한다.
