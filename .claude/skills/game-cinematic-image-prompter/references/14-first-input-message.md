# 새로운 SB를 받았을 때 사용하는 첫 입력 메시지

새 프로젝트를 시작하거나, 기존 프로젝트에 새 SB 시퀀스를 추가할 때 아래 템플릿을 채워 첫 메시지로 보낸다. Claude Project와 Claude Code 모두 같은 템플릿을 쓴다.

## 템플릿

```
첨부한 [프로젝트명] SB와 게임 리소스, [캐릭터/건축/톤 등] 레퍼런스를
game-cinematic-image-prompter 기준으로 분석해줘.

지금은 이미지 생성 프롬프트를 만들지 말고 Gate 1 — SB 분석만 수행해.
각 SB 컷의 시간 구간, 내러티브 목적, 공간 기능, 감정 변화, 카메라 의도,
전환, 필요한 무인 배경 플레이트와 캐릭터 합성 공간을 표로 정리해줘.

그 다음 레퍼런스를 Structure / Design / Tone / Shot 중 하나의 주 역할로
분류하고, 서로 충돌하는 부분과 유지해야 할 이 프로젝트 고유 조형을
지적해줘.

[이 프로젝트에서 특히 지켜야 할 세계관 규칙이 있다면 여기 한 문단으로
명시한다. 예: 세력 간 색상 진영 분리 금지, 특정 시대·문명 혼입 금지 등.
프로젝트 브리프 00-project-brief.md에 이미 적었다면 "브리프 참조"라고만
써도 된다.]

제공된 사실과 네 추론을 구분하고, 반드시 확인이 필요한 질문은 최대 5개만
해줘. 마지막에는 승인할 항목, 수정 가능한 항목, 다음 Gate에서 할 일을
적고 내 승인을 기다려.
```

## 사용 전 준비

1. 프로젝트 폴더의 `00-project-brief.md`를 먼저 채운다. 비어 있으면 Claude가 Gate 1 전에 먼저 요청한다.
2. SB 이미지, 게임 캡처, 참고 레퍼런스에 역할이 드러나는 파일명을 붙인다(예: `SB_01.png`, `REF_STRUCTURE_MASTER.png`, `REF_TONE.png`). 파일명에 역할을 명시하면 서로 다른 레퍼런스의 조형이 뒤섞이는 문제가 크게 줄어든다.
3. Claude Project라면 이 파일들을 Project Knowledge에, Claude Code라면 프로젝트 폴더 또는 세션에 첨부한다.
