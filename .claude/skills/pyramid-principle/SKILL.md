# 피라미드 원칙 (Minto Pyramid)

모든 산출물의 **마지막 구조화 단계**다. 리서치·발산·분석이 끝나고 문서로 만들기 직전에 이걸 통과시킨다.
`mx-deck-design`·`mx-research-dashboard-design`으로 조판하기 전에 먼저 여기서 목차를 확정한다.

3층 구조:
1. **지배 메시지(governing thought)** — 질문에 답하는 선언문 한 문장
2. **키라인(key line)** — 지배 메시지를 떠받치는 근거 주장 2~4개, 서로 겹치지 않게
3. **근거** — 키라인마다 붙는 숫자·사례·출처

## 언제 쓰나
- 리서치 결과를 제안서 목차로 옮길 때
- 슬라이드 제목이 "시장 분석", "경쟁사 현황" 같은 주제 라벨로 채워져 있을 때
- 회신 메일이 길어져 요점이 안 보일 때
- 클라이언트가 "그래서 결론이 뭐냐"고 물었을 때

## 언제 안 쓰나
- 아직 발산 중이고 결론이 없을 때 → `brainstormer`
- 근거 자체를 못 믿겠을 때 → `source-grading` 먼저
- 문제 구조를 아직 못 쪼갰을 때 → `mece-issue-tree` 먼저

## 절차

### 1. 질문을 먼저 쓴다
독자가 이 문서를 읽고 답을 얻어야 할 질문 하나를 적는다. 질문이 흐리면 답도 흐려진다.
예: "코웨이 BEREX의 20~30대 인지도를 어떻게 올릴 것인가"

### 2. 지배 메시지 한 문장
질문에 직접 답하는 선언문을 쓴다. 세 가지 시험을 통과해야 한다.

| 시험 | 통과 기준 |
|---|---|
| 주장인가 | 주제가 아니라 판단이다. "브랜드 인지도" ✗ / "인지도 문제는 노출량이 아니라 첫 3초의 이해도다" ✓ |
| 반대도 성립하나 | 반대 주장이 말이 되어야 진짜 주장이다. 아무도 반대 못 할 문장은 정보가 없다 |
| 행동이 나오나 | 읽고 나서 무엇을 할지 정해지는가 |

하나라도 실패하면 다시 쓴다. 이 문장이 덱 표지 다음 장의 제목이 된다.

### 3. 키라인 2~4개
지배 메시지를 지탱하는 이유를 뽑는다. 개수는 내용이 정한다 — 2개면 2개, 4개면 4개로 둔다. 억지로 3개로 맞추지 않는다.
각 키라인도 주장 형태로 쓴다. "시장 규모" ✗ / "시장은 40% 컸는데 우리 매출은 5% 줄었다" ✓

### 4. 논리 방식을 고른다
- **연역** — A이므로 B, 따라서 C. 순서를 바꾸면 무너진다. 전략 제안·설득에 쓴다
- **귀납** — 독립된 이유 여러 개가 같은 결론을 가리킨다. 순서를 바꿔도 된다. 진단·현황 보고에 쓴다

한 문서 안에서 섞지 않는다.

### 5. MECE 점검
키라인끼리 겹치는 곳, 비는 곳을 본다. 겹치면 합치고, 비면 채운다. 판단이 어려우면 `mece-issue-tree`로 넘긴다.

### 6. 근거를 붙인다
키라인마다 숫자·사례·출처를 단다. 근거 없는 키라인은 키라인이 아니라 의견이다. 출처 티어(T1~T4)는 `source-grading` 규칙을 따른다.

## 출력 템플릿

```markdown
## 질문
{독자가 답을 얻어야 할 질문 한 문장}

## 지배 메시지
{선언문 한 문장}
- 주장 시험: 통과 / 실패(사유)
- 반대 성립: 통과 / 실패(사유)
- 행동 함의: {읽고 나서 할 일}

## 키라인
| # | 키라인(주장 형태) | 논리 | 근거 요약 | 출처 티어 |
|---|---|---|---|---|
| 1 |  | 연역/귀납 |  | T? |
| 2 |  |  |  |  |

## 근거 상세
### 키라인 1
- 근거:
- 출처:
- 반증 가능성:

## 목차 변환
| 장 | 슬라이드 제목(= 메시지) | 담을 내용 |
|---|---|---|
| 1 |  |  |
```

## 품질 게이트
- 슬라이드 제목만 순서대로 읽었을 때 이야기가 되는가
- 지배 메시지가 표지 다음 장에 있는가
- 근거 없는 키라인이 있는가
- 키라인 개수를 내용이 아니라 습관으로 정하지 않았는가

## 자주 나오는 실패
- **주제 라벨** — "경쟁사 분석"은 제목이 아니라 폴더 이름이다
- **결론 뒤로 미루기** — 클라이언트는 8페이지까지 기다려주지 않는다
- **키라인이 실행 항목** — "SNS 광고 집행"은 이유가 아니라 액션이다. 액션은 마지막 장에 모은다
