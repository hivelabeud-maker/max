# 출처 등급 · 교차 확인

`marketer` v8.1의 T1~T4 티어를 판단 근거까지 남기도록 확장한 스킬이다. `fact-checker` 앞단에서 돌린다.

핵심 원칙 두 개.
1. **출처가 좋은 것과 정보가 확인된 것은 다른 문제다.** 신뢰도 높은 언론이 미확인 소문을 실으면 B2다. 익명 게시물이 확인된 사실을 전하면 F1이다. 하나로 뭉친 점수는 평판이 미검증 주장을 세탁하게 만든다.
2. **개수가 아니라 독립성이 근거를 만든다.** 같은 보도자료를 받아쓴 기사 5건은 확인 5건이 아니라 1건이다.

## 축 1 — 출처 신뢰도 (A~F)
과거 이력만 본다. 이번 주장이 마음에 드는지는 보지 않는다.

| 등급 | 뜻 | 예 | 우리 티어 |
|---|---|---|---|
| A | 의심 없음 | 정부·공공기관 통계, 기업 공시·IR, 특허, 학술지 | T1 |
| B | 대체로 신뢰 | 편집 기준이 있는 주요 언론, 대형 조사기관 리포트 | T1~T2 |
| C | 보통 | 업계지, 벤더 마케팅 자료, 위키피디아 | T2~T3 |
| D | 대체로 부족 | 편집 없는 큐레이션 매체, 개인 블로그, 링크드인 글 | T3 |
| E | 신뢰 못 함 | 오정보 이력, 순수 의견 | T4 |
| F | 판단 불가 | 신생 매체, 익명 게시물 | T4 |

F는 "못 믿겠다"가 아니라 "판단할 근거가 없다"는 뜻이다.

## 축 2 — 정보 신빙성 (1~6)
출처를 빼고 정보 자체만 본다.

| 등급 | 뜻 |
|---|---|
| 1 | 독립 출처로 확인됨 |
| 2 | 미확인이지만 논리적이고 다른 정보와 일치 |
| 3 | 미확인, 일부 정보와만 일치 |
| 4 | 의심스러움. 다른 정보 없음 |
| 5 | 개연성 낮음. 다른 정보와 충돌 |
| 6 | 판단 불가 |

두 축을 붙여 `B2`, `A1`, `F6`처럼 쓰고, **한 문장짜리 근거를 반드시 단다.** 근거 없는 등급은 등급이 아니다.

## 교차 확인 절차

### 1. 주장을 한 문장으로 특정한다
주어·수치·단위·시점을 다 넣는다. "시장이 크다" ✗ / "국내 정수기 렌털 시장은 2025년 기준 3.2조 원" ✓

### 2. 후보 출처 3~5개를 모은다
가능하면 성격을 섞는다 — 1차 기록(공시·통계), 당사자 발표, 독립 보도, 학술·전문 문헌

### 3. 각각 등급을 매긴다

### 4. 독립성 4개 시험
넷 다 통과해야 독립된 출처다. 하나라도 실패하면 같은 출처의 다른 옷이다.

| 시험 | 독립인 경우 | 접히는 경우 |
|---|---|---|
| 발신자가 다른가 | 다른 필자·매체·조직 | 한쪽이 다른 쪽을 인용·전재 |
| 1차 뿌리가 다른가 | 각자 다른 원자료를 짚는다 | 같은 보도자료·같은 데이터셋 |
| 발행 사건이 다른가 | 각자 새 관찰을 더했다 | 재게시·업데이트뿐 |
| 이해관계가 다른가 | 자금·소유·이익이 다르다 | 둘 다 당사자가 돈을 댔다 |

접히는 묶음은 그 안에서 등급이 가장 높은 하나만 남기고, **무엇을 왜 접었는지 기록한다.** 이 기록이 검증 가능성을 만든다.

### 5. 판정
- 독립 출처 2개 이상 일치 → **확인됨**
- 1개 → **단일 출처**. 그대로 표기하고 본문에서 단정하지 않는다
- 0개 → **DATA GAP**
- 남은 출처끼리 충돌 → **쟁점**. 양쪽을 다 쓰고 어느 쪽이 더 원본이고 더 최신인지 밝힌다. 평균 내지 않는다

## 출력 템플릿

```markdown
## 주장
{주어·수치·단위·시점을 넣은 한 문장}

## 출처
| 출처 | 등급 | 성격 | 등급 근거(한 문장) |
|---|---|---|---|
|  | B2 | 독립 보도 |  |

## 접은 출처
| 접힌 출처 | 남긴 출처 | 실패한 시험 |
|---|---|---|

## 판정
독립 출처 수: N
판정: 확인됨 / 단일 출처 / DATA GAP / 쟁점
본문 사용 가능: 예 / 아니오
표기 티어: T?
```

## 품질 게이트
- T4를 본문에 썼는가 (금지)
- 핵심 수치에 독립 출처 2건이 붙었는가
- 등급마다 한 문장 근거가 있는가
- DATA GAP을 숨기지 않고 표시했는가
