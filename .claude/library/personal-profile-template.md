# 개인 프로필 템플릿 — `~/.claude/CLAUDE.md`로 복사해 쓴다

> **왜 따로 두나**: 저장소 루트 `CLAUDE.md`는 팀 전원이 공유하는 기준선이다.
> 거기에 개인 직책·경력·말투를 쓰면 다른 팀원의 답변까지 그 사람 기준으로 나온다.
> 개인 설정은 각자 컴퓨터의 `~/.claude/CLAUDE.md`에 두면 **자기 세션에만** 적용된다.

## 쓰는 법 (2분)
1. 아래 블록을 복사한다.
2. 자기 컴퓨터에서 `~/.claude/CLAUDE.md` 파일을 만들고 붙여넣는다.
   - macOS·Linux: `mkdir -p ~/.claude && nano ~/.claude/CLAUDE.md`
   - Windows: `%USERPROFILE%\.claude\CLAUDE.md`
3. 대괄호 안을 자기 값으로 바꾼다.
4. 저장하고 Claude Code를 새로 연다. 이 파일은 **저장소에 커밋되지 않는다** (개인 컴퓨터에만 있다).

## 우선순위
`~/.claude/CLAUDE.md`(개인) 와 저장소 `CLAUDE.md`(팀) 는 **둘 다 읽힌다.**
충돌하면 더 구체적인 쪽이 이긴다. 팀 규칙을 개인 파일로 무력화하지 않는다 — 특히 민감정보 규칙.

---

## 복사할 블록

```markdown
# 개인 프로필

## 나
- **직책**: [예: 시니어 비주얼 디자이너 / 8년차]
- **담당**: [예: 게임 UI · 상세페이지]
- **주 클라이언트**: [예: 넷마블, 삼양]

## 내가 받고 싶은 답 모양
- 길이: [예: 표 위주, 서술 3줄 이내]
- 먼저 물어봐야 할 것: [예: 레퍼런스 없으면 먼저 물어봐 줘]
- 안 해도 되는 것: [예: 실행 코드 설명은 생략]

## 자주 쓰는 흐름
- [예: 시안 올리면 design-critique 먼저 돌린다]
- [예: 메일 초안은 tone-guardian 거쳐서 준다]
```

---

## 여기 쓰면 안 되는 것
- 팀 전원이 따라야 할 규칙 → 저장소 `CLAUDE.md`에 PR로 넣는다
- 단가·견적·클라이언트 기밀 → 어디에도 쓰지 않는다
- 남의 개인정보 → 쓰지 않는다
