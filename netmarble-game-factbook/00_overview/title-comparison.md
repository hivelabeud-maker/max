## 2. 혼동 방지 — 반드시 갈라야 할 조합

### ⚠️ 조합 1. 일곱 개의 대죄 GRAND CROSS ↔ Origin
같은 원작, 같은 개발사(넷마블F&C), 비슷한 이름. **제작 단계에서 소재를 물리적으로 분리해야 한다.**

| | GRAND CROSS | Origin |
|---|---|---|
| 성격 | **보는 게임** | **걷는 게임** |
| 장르 | 수집형 카드배틀 | 오픈월드 액션 |
| 플랫폼 | 모바일 | PS5·Steam·모바일 |
| 시점 | 원작 본편 재현 | 「7대죄」 완결 이후 ~ 「묵시록의 4기사」 이전 |
| 주인공 | 멜리오다스 세대 | 트리스탄 (아들 세대) |
| 축 | **재현** | **확장** |

**화면에서 가르는 법** — GC는 카드 UI를 반드시 넣고, Origin은 원경·이동을 반드시 넣는다.

### ⚠️ 조합 2. 몬길: STAR DIVE ↔ 스톤에이지 키우기
둘 다 "생물을 모으는 게임"이라 수집 장면만 보면 구분이 안 된다. **조작량이 정반대다.**

| | 몬길 | 스톤에이지 키우기 |
|---|---|---|
| 조작 | **실시간 액션** — 계속 화면을 본다 | **방치형** — 하루 5분이 정상 |
| 시그니처 | 3인 태그 전환 | 펫 탑승 |
| 타깃 | 20후~30 | 30~45 |

**화면에서 가르는 법** — 몬길은 태그 전환, 스톤에이지는 자동 진행·누적 보상을 반드시 넣는다.

### ⚠️ 조합 3. 스톤에이지 키우기 ↔ KOF AFK
같은 방치형, 같은 "IP 향수 + 낮은 부담" 구조.

**화면에서 가르는 법** — KOF는 도트 그래픽, 스톤에이지는 펫 탑승. 비주얼이 완전히 다르므로 이것만 지키면 갈린다.

### ⚠️ 조합 4. MMORPG 4종
넷 다 MMORPG지만 파는 감정이 전부 다르다.

| 타이틀 | 시그니처 오브젝트 | 파는 욕망 |
|---|---|---|
| 레이븐2 | 헤븐스톤 | 강해지고 싶다 |
| 뱀피르 | 흡혈 장면 | 뱀파이어가 되고 싶다 |
| RF 온라인 | 삼각 구도 + 신기 | 우리 편이 이기고 싶다 |
| SOL: enchant | 빈 옥좌 | 지배하고 싶다 |

**화면에서 가르는 법** — 각 타이틀의 시그니처 오브젝트를 반드시 넣는다.

## 3. 톤 지도 — 밝기로 먼저 갈린다

### 어두운 톤 (5)
저채도 · 단일 광원 · 고콘트라스트

| 타이틀 | 어둠의 질감 |
|---|---|
| 뱀피르 | **우아하고 관능적** — 검정·심홍·창백 3색 |
| 레이븐2 | **거칠고 절망적** — 강철회색 + 헤븐스톤 발광 |
| 나 혼자만 레벨업 | **현대 도시가 반드시 섞인다** — 게이트 푸른빛, 그림자 보라 |
| SOL: enchant | **신화적이고 장엄** — 침식의 어둠 위 금빛 |
| RF 온라인 넥스트 | **웅장하고 건조** — 금속과 인공광. 유일한 SF |

### 밝은 톤 (5)
고채도 · 자연광 · 얕은 그림자

| 타이틀 | 밝음의 질감 |
|---|---|
| 일곱 개의 대죄 GC | 셀 애니 원색. **사내 유머 허용치 최상위권** |
| 일곱 개의 대죄 Origin | 초원 녹색·하늘 청색. **원경 우선** |
| 세븐나이츠 리버스 | 영웅별 상징색. **배경보다 얼굴** |
| 몬길: STAR DIVE | 다색. **지역별로 팔레트가 갈린다** |
| 스톤에이지 키우기 | 초록·흙색·하늘색. **긴박함을 만들지 않는 것이 장르 정체성** |

### 별도 계열 (2)
| 타이틀 | 특징 |
|---|---|
| KOF AFK | **고채도 아케이드 도트** — 밝지만 1990년대 픽셀 팔레트 |
| 왕좌의 게임: 킹스로드 | **저채도 실사 저판타지** — 어둡지만 판타지 어둠이 아닌 드라마 색보정 |

> **핵심**: 왕좌의 게임을 레이븐2·뱀피르와 같은 어두운 판타지로 묶으면 안 된다. 하이 판타지와 저판타지는 다른 세계다.

## 5. 과금 커뮤니케이션 — 유일한 예외

**11개 타이틀은 과금 구조를 광고에서 감춰야 한다.** 국내 MMORPG·수집형 RPG 공통으로 가장 민감한 지점이다.

**왕좌의 게임: 킹스로드만 반대다.** 유료 뽑기가 없고 100% 수동 전투라, **드러내는 것이 이득**이다. 사내에서 이 카드를 쓸 수 있는 유일한 타이틀.

> ⚠️ 단, 출시 직후 과금 논란이 실제로 발생해 개발사가 EXP팩을 무료로 전환한 이력이 있다. **현행 상품 구성을 확인한 뒤 문구를 확정해야 한다.**
