# AI 자산화 전략 — 3계층 구조

**작성일** 2026.08.04 · 12개 타이틀 팩트북 분석 기반
> 목적: 여러 타이틀에 반복 활용할 수 있는 AI 제작 자산 체계를 세우되, **각 게임의 고유 세계관과 캐릭터가 획일화되지 않게** 계층을 나눈다.

---

## 0. 전제 — 12개 팩트북에서 예외 없이 반복된 두 가지

이 전략의 근거다. 장르도 세계관도 다른 12개를 나란히 놓았을 때, 아래 두 판단만은 모든 타이틀에서 같았다.

| | 영역 | 판정 | 이유 |
|---|---|---|---|
| ✅ | **배경 · 세계관 확장 장면** | **12/12 적합도 상** | 캐릭터가 없으니 정확도 부담이 없다. 세계관 톤만 맞추면 된다 |
| ⛔ | **캐릭터 · 몬스터 · 시그니처 병기** | **10/12 적합도 하 또는 금지** | 얼굴·무기·의상·문양이 조금만 틀려도 팬이 즉시 식별한다 |

**따라서 AI 이미지 작업의 기본 착수 지점은 배경이다.** 캐릭터가 필요하면 인게임 에셋과 공식 아트로 간다.

### 캐릭터 생성 금지 강도

| 강도 | 타이틀 | 사유 |
|---|---|---|
| **절대 금지** | 왕좌의 게임: 킹스로드 | 드라마 **배우 초상권**. 실사화도 금지 |
| **금지 권장** | 나 혼자만 레벨업 · 7DS GC · 7DS Origin | 원작자 검수 IP |
| **금지 권장** | KOF AFK | 캐릭터가 IP 자산의 전부. 도트 한 칸도 팬이 식별 |
| **금지 권장** | 스톤에이지 키우기 · 몬길 | 펫·몬스터가 핵심 자산. 가짜가 유통되면 IP 혼선 |
| **비권장(실루엣만 허용)** | 레이븐2 · 뱀피르 · RF · SOL · 세븐나이츠 | 자체 IP지만 코어 유저 인지도가 높다 |

## 1계층 — 공통 자산 (12개 타이틀 공유)

세계관과 무관하게 **제작 프로세스 자체를 표준화**하는 자산. 한 번 만들어 전 타이틀에 쓴다.

### 1-1. IP 오류 검수 체크리스트 ⭐ 최우선
AI 생성물을 실무에 쓰기 전 통과시키는 단일 관문. 팩트북 12종의 "피해야 할 것"에서 공통 항목을 뽑았다.

```
□ 시대성  — 세계관에 없는 시대의 요소가 들어갔는가 (현대·SF·중세 혼입)
□ 캐릭터  — 얼굴·헤어·의상·무기·문양이 공식 아트와 일치하는가
□ 색      — 타이틀 지정 팔레트를 벗어났는가
□ 톤      — 밝기·질감이 해당 타이틀 계열과 맞는가 (§클러스터 참조)
□ 장르    — 실제 게임과 다른 장르로 오인될 화면인가
□ 자매작  — 같은 IP·같은 사내 타이틀과 혼동될 요소가 있는가
□ 문화    — 종교·유혈·사행성 등 국가별 심의 리스크가 있는가
□ 출처    — 인게임에 실제로 존재하는 장면인가
```

### 1-2. 6초 · 15초 · 30초 영상 구성 템플릿
전 타이틀 공통. 클러스터별로 내용만 바꿔 넣는다.

| 길이 | 구조 | 용도 |
|---|---|---|
| **6초** | 단일 동작 반복 (시그니처 1개만) | 차별점 각인 |
| **15초** | 훅 → 시그니처 → 혜택 | UA 주력 |
| **30초** | 세계관 → 갈등 → 플레이 → CTA | 브랜드 필름 |

### 1-3. 스타일 가이드 3종 분류
**실사형 / 인게임형 / 시네마틱형** 중 각 타이틀이 어디에 속하는지 사전 지정. 섞이면 과장 광고 논란이 난다.

- **인게임형이 기본** — 이 장르 유저는 인게임과 다른 연출에 반감이 크다
- 시네마틱 사용 시 **인게임 컷을 반드시 병기**
- **실사형은 왕좌의 게임 외 전 타이틀 비권장** (그리고 킹스로드는 IP상 금지)

### 1-4. 캐릭터 없는 무드 라이브러리
날씨·시간대·기상 변주. 12개 타이틀 전부에서 안전하게 쓰이는 유일한 이미지 카테고리.
`일출 / 정오 / 석양 / 밤 / 비 / 안개 / 눈`

### 1-5. 금칙어 사전
팩트북에서 확인된 **팬덤 비판어**. 공식 채널에서 사용 금지.

| 타이틀 | 금칙어 |
|---|---|
| 레이븐2 | 말뚝딜 · 리니지라이크 |
| 뱀피르 · SOL | 리니지라이크 |
| 나 혼자만 레벨업 | 억까 |
| 세븐나이츠 리버스 | (노가다 강요 프레임) |
| 스톤에이지 키우기 | IP 남용 |

## 2계층 — 클러스터별 자산 (2~4개 타이틀 공유)

같은 클러스터 안에서만 재사용한다. 클러스터를 넘어가면 톤이 무너진다.

### A. 하드코어 MMORPG (레이븐2 · 뱀피르 · RF · SOL)
| 자산 | 내용 | 예외 |
|---|---|---|
| **저광량 조명 프리셋** | 단일 광원, 깊은 그림자, 고콘트라스트 | — |
| **스케일 대비 카메라 프리셋** | 로우앵글 와이드, 거대한 것 아래 작은 인간 | — |
| **대규모 군중 실루엣** | 개별 디테일 불필요. AI 효율 높음 | — |
| **어두운 배경 라이브러리** | 폐허·성채·지하 공간 | ⚠️ **RF는 SF라 제외** — 별도 라이브러리 |
| **장엄 사운드 레퍼런스** | 저역 현악·합창·금속음 | — |

### B. 라이선스 IP (나혼렙 · 7DS GC · 7DS Origin · 킹스로드)
| 자산 | 내용 |
|---|---|
| **IP 가이드 색인** | 4개 IP사별 표현 허용 범위를 한 문서로 정리 (⭐ 최우선 · `내부 자료 필요`) |
| **캐릭터 공식 아트 아카이브** | AI 생성을 금지하는 대신 쓸 대체 자산 |
| **원작 인지 훅 템플릿** | 첫 3초를 IP 인지로 시작하는 구성 |
| **배경 전용 생성 규칙** | 캐릭터 미포함 조건을 프롬프트에 고정 |

> ⚠️ 이 클러스터는 **공유 자산이 가장 적다.** 원작 톤이 IP마다 완전히 달라서(7DS=밝은 애니 / 킹스로드=저판타지 실사) 비주얼 자산을 공유할 수 없다. 공유되는 것은 **제작 규칙**뿐이다.

### C. 자체 IP 리콜 (세븐나이츠 리버스 · 몬길)
| 자산 | 내용 |
|---|---|
| **밝은 판타지 배경 라이브러리** | 대륙·영지·마을 |
| **소품 아카이브 포맷** | 캐릭터 없이 캐릭터를 이야기하는 구조. 이 클러스터에서 가장 안전한 AI 활용 |
| **전작 → 현재 대비 템플릿** | ⚠️ 전작 에셋 사용권 확인 필수 |
| **리콜 채널 리스트** | 게임 매체가 아닌 도달 경로 (`내부 자료 필요`) |

### D. 방치형 향수 (스톤에이지 · KOF AFK)
| 자산 | 내용 |
|---|---|
| **"자는 동안" 영상 템플릿** ⭐ | 잠든 유저 / 계속 도는 게임 / 아침의 보상. **두 타이틀 공통 최고 효율** |
| **밈 포맷 세트** | "나: 아무것도 안 함 / 게임: ..." 구조. **사내 12개 중 AI 밈 효율 최상** |
| **일상 배경 라이브러리** | 침실·출퇴근·사무실 등 현실 공간 |
| **누적 보상 연출 프리셋** | 쌓인 보상 수령 화면 |

## 3계층 — 개별 타이틀 전용 (공유 금지)

각 게임의 정체성이다. **다른 타이틀에 절대 쓰지 않는다.**

| 타이틀 | 전용 고정 자산 |
|---|---|
| **레이븐2** | 헤븐스톤 형태·발광색 · 클래스 7종 무기 |
| **뱀피르** | 3색 팔레트(검정·심홍·창백) · 흡혈 모션 · 클래스 4종 무기(특히 카니지 총기) |
| **RF 온라인 넥스트** | 종족별 아트 디렉션(기계/연합/신성) · 신기 3종(MAU·런처·애니머스) · 바이오슈트 7종 |
| **SOL: enchant** | 빈 옥좌 · 신권 4종 이펙트 · 신갑 · 위계 구도 |
| **세븐나이츠 리버스** | 영웅별 상징색 · 스킬 컷인 · 실베스타의 목걸이 등 서사 소품 |
| **몬길: STAR DIVE** | 몬스터 도감 · 3인 태그 전환 · 야옹이 · 두 대륙 팔레트 |
| **스톤에이지 키우기** | 펫(공룡) 디자인 · 펫 탑승 구도 · 24칸 덱 |
| **KOF AFK** | 도트 스프라이트 · 필살기 이펙트 · 아케이드 팔레트 |
| **나 혼자만 레벨업** | 그림자 군단 · 게이트(푸른 균열) · "일어나라"(성진우 전용) |
| **7DS GRAND CROSS** | 일곱 대죄 문장 · 카드 랭크업 연출 |
| **7DS Origin** | 별의 서 · 찢어진 하늘 · 생활 콘텐츠(요리·낚시) |
| **왕좌의 게임: 킹스로드** | 티레 가문 문장 · 웨스테로스 지형 · 저판타지 실사 톤 |

## 제작 착수 순서

```
1. IP 가이드 확인          ← B클러스터는 이게 없으면 시작 불가
2. 1계층 공통 규칙 적용     ← 검수 체크리스트·스타일 분류
3. 2계층 클러스터 자산 활용  ← 조명·카메라·배경 프리셋
4. 3계층 전용 자산 삽입     ← 시그니처 오브젝트
5. 검수 체크리스트 통과      ← 8개 항목
```

## 지금 확보해야 할 내부 자료 (우선순위)

| 순위 | 자료 | 없으면 막히는 것 |
|---|---|---|
| 1 | **4개 라이선스 IP사 가이드** (HBO · 웹소설사 · 만화사 · SNK) | B클러스터 전체 제작 |
| 2 | **각 타이틀 시그니처 오브젝트 공식 아트** | 3계층 전체 |
| 3 | **타이틀별 정확한 컬러값** | 1·2계층 팔레트 고정 |
| 4 | **인게임 영상 사용 권한 범위** | 인게임형 소재 전체 |
| 5 | **국가별 심의 기준** (종교·유혈·사행성) | 뱀피르·SOL·글로벌 캠페인 |
| 6 | **전작 에셋 사용 가능 범위** | C클러스터 대비 구조 |
| 7 | **타이틀별 유저 데이터** | 전 타이틀 타깃 검증 |

> 1~2번이 없으면 AI 자산화는 배경 생성 수준에서 멈춘다. 캐릭터가 들어가는 순간 전부 승인 대기가 된다.
