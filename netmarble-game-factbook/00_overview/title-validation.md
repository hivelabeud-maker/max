## 5. 결론 — 즉시 판단이 필요한 항목

### 🔴 내부 자료 없이는 팩트북 작성 불가
1. **프로젝트 옥토퍼스** — 정식명·출시일·플랫폼·게임플레이 모두 미공개. 퍼블리싱 계약 발표(2025.11)와 짧은 프리뷰 기사가 전부. 현 상태로 작성하면 추측 문서가 된다
2. **샹그릴라 프론티어** — 일본 티저만 존재. 원작 만화 정보는 풍부하나 **게임 고유 정보는 거의 없음**. 원작 팩트북과 게임 팩트북을 혼동하지 않도록 범위 합의 필요

### 🟡 명칭·범위 확인 필요
3. **뱀피르 "일본"** — 별도 타이틀이 아니라 서비스 권역. 일본 버전 특화 팩트북인지, 글로벌 대비 차이 분석인지 범위 확인 필요
4. **나 혼자만 레벨업** — 「어라이즈」와 「어라이즈 오버드라이브」 중 대상 확정 필요
5. **왕좌의 게임 / RF 온라인 / 솔 인챈트** — 공식 명칭으로 표기 통일 필요

### 🟢 즉시 진행 가능
나머지 9개 타이틀은 공개 정보만으로 팩트북 작성 가능.
