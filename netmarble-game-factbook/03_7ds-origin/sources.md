## 검증 처리 원칙

### 원작 정보와 게임 정보의 분리
- **원작 영역**: 브리타니아 세계관, 트리스탄의 혈통(네피림), 부모 세대 설정, 「묵시록의 4기사」와의 계보
- **게임 고유 영역**: 오픈월드 구조, 별의 서 폭주 스토리(**게임 오리지널**), 낚시·요리 생활 콘텐츠, 크로스플랫폼 서비스

두 영역을 팩트북 내에서 구분 표기했다. 트리스탄의 설정 1차 출처가 위키(비공식)이므로 **캐릭터 표현 크리에이티브는 사내 IP 가이드로 재확인 필요**.

### 채택하지 않은 정보
| 항목 | 사유 |
|---|---|
| 플레이어블 캐릭터 전체 목록 | 1차 출처(공식 페이지) 직접 확인 불가(403), 가이드 사이트 단독 → `공식 확인 필요` |
| 멜리오다스·엘리자베스의 게임 내 등장 비중 | 미확인. **IP상 민감 영역이므로 추정 기술하지 않음** |
| 트리스탄의 무기·능력 상세 | 미확인 |
| 커뮤니티 반응·평가 | 출시 5개월차로 축적 데이터 부족. 추정으로만 표기하고 `내부 자료 필요` |
| 결제 구조·수익 모델 | 미확인 |
| 신규 영웅 '고서' 상세 | 매체 언급만 확인, 설정 미상 |

### 미해결 확인 항목
1. **동료 캐릭터 구성** — 트리스탄과 함께 탐험하는 인물들
2. **부모 세대 등장 범위** — 크리에이티브에서 사용 가능한 선을 정하는 데 필수
3. **게임 내 실제 지역 구성** — "브리타니아 종주"·"여행 포스터" 아이디어 실행에 필요
4. **크로스플랫폼 계정 연동 사양** — "어디서든 이어서" 아이디어의 사실 근거
5. **트리스탄 13세 시점** — 위키 단독 출처, 공식 확인 필요
6. **출시 후 유저 반응** — 커뮤니티·리뷰 데이터 → `내부 자료 필요`

### 기술적 제약 메모
넷마블 공식 도메인·나무위키·BlueStacks 모두 자동 크롤링 차단(403). 검색 색인 요약과 매체 기사로 교차 검증했다. **공식 게임 소개 페이지 원문과 IP 가이드는 담당자 수동 확인 필수** — 특히 캐릭터 구성과 부모 세대 등장 범위.
