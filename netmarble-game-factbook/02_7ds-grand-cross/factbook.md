> 「일곱 개의 대죄」 원작 스토리를 **애니메이션 수준의 컷신으로 다시 보면서**, 캐릭터를 모아 **스킬 카드를 조합해 싸우는** 수집형 RPG.

**왜 이 한 줄인가** — 이 게임의 7년을 지탱한 힘은 액션이 아니라 **재현도**다. 애니메이션 품질의 컷신과 원작자 검수를 거친 캐릭터 구현이 팬을 붙잡았다. 크리에이티브도 "액션이 화려하다"가 아니라 **"원작이 여기 있다"**로 가야 한다.

## 1. IP와 히스토리

### 원작
- 스즈키 나카바의 만화 「일곱 개의 대죄」. 애니메이션화로 글로벌 팬덤 형성.
- 후속작 「묵시록의 4기사」로 세계관 확장 (→ 이 계보는 자매작 **Origin**이 다룬다. §7 참조)

### 게임
- 2019.06.04 한국·일본 출시 → 2020.03.03 글로벌. **7년차 장수 타이틀.**
- **전 세계 누적 매출 10억 달러 돌파.** 넷마블을 글로벌 모바일 퍼블리셔 매출 10위권에 올린 타이틀.
- 누적 다운로드 7,777만 이상 (7이라는 숫자를 브랜드 자산으로 활용 — '777 릴레이 캠페인' 등)
- **원작자와 교류가 활발하며 검수를 받는다.** 원작에 전투 묘사가 없던 캐릭터도 게임이 스킬을 새로 설계했다.

### 반드시 기억할 히스토리 3가지
1. **7년차 라이브 서비스** — 신규 획득보다 **기존 유저 유지**가 사업의 중심. 크리에이티브도 신규 소구와 리텐션 소구를 분리해야 한다.
2. **대형 IP 콜라보가 상시 축**  — 2026년만 해도 **Re:제로(4월)**, **가치아쿠타(6월)**, 파이어포스 등. 콜라보는 이 게임의 정기적 화제 유발 장치이자 신규 유입 창구.
3. **'7' 브랜딩** — 7,777만 다운로드, 777 릴레이 캠페인(2026.01~06). 숫자 7이 이 타이틀 고유의 상징 자산이다.

## 2. 세계관과 기본 서사

### 세계관 요약
**브리타니아 대륙.** 고대에 인간·여신족·마신족·요정족·거인족 **다섯 종족**이 존재했고, 3천 년 전 요정왕의 숲 위에 국가들이 세워졌다. 현재 왕국들은 **성기사(홀리 나이트)의 무력**으로 국력을 유지한다. 그 성기사들이 왕국을 장악하자, 리오네스 왕국 제3왕녀 **엘리자베스**가 과거 반역자로 몰려 흩어진 전설의 기사단 **'일곱 개의 대죄'**를 찾아 나선다.

### 핵심 갈등
| 구분 | 내용 |
|---|---|
| 주인공 | 멜리오다스 — '분노의 죄(드래곤 신)'를 짊어진 기사단장. 겉모습은 소년이나 최소 3,000살 이상 |
| 히로인 | 엘리자베스 — 리오네스 제3왕녀. **영겁의 윤회로 환생을 반복하는 존재** |
| 적대 | 왕국을 장악한 성기사, 이후 마신족 세력 |
| 근본 갈등 | **죄인으로 불린 자들이 실제로는 왕국을 지킨다.** 낙인과 진실의 역전 구조 |

> 멜리오다스와 엘리자베스의 관계는 **영겁의 윤회**라는 저주 위에 서 있다. 이 IP에서 가장 무거운 정서적 축이며, **팬이 가장 민감한 영역**이다.

### 세계관 시각 키워드
| 구분 | 내용 |
|---|---|
| 시대·공간 | 중세 유럽풍 판타지. 브리타니아 대륙, 왕국·주점·숲 |
| 건축·환경 | 석조 성채, 마을, 요정왕의 숲. **이동 주점 '보아 햇' `공식 확인 필요`** |
| 의상·장비 | 기사 갑옷 + 각 대죄의 문장. 캐릭터별 상징색 뚜렷 |
| 색채·조명 | 원작 애니 톤 — **채도 높고 밝다.** 다크 판타지 아님 |
| 주요 상징물 | **일곱 대죄의 문장(짐승 문양)**, 각 멤버의 전용 무기 |
| 금지·부적합 | 어둡고 무거운 다크 판타지 톤, 사실주의 리얼 렌더링, 현대·SF 요소 |

> ⚠️ **톤 주의**: 같은 사내 타이틀인 레이븐2·뱀피르와 정반대다. 7DS는 **밝고 채도 높은 소년만화 톤**이다. 다크 판타지 문법을 적용하면 IP가 훼손된다.

### 세계관을 한 장면으로 표현한다면
> 초록 언덕 위, 이동식 주점 앞. 소년처럼 보이는 남자가 부러진 검을 어깨에 걸치고 웃는다. 그의 등 뒤로 각기 다른 체구와 종족의 동료들이 하나씩 모여든다. 하늘은 밝고, 이제 막 싸움이 시작되려 한다.

## 3. 핵심 캐릭터

> ⚠️ 개별 캐릭터의 성격·관계는 **원작 영역**이며 팬 민감도가 매우 높다. 아래는 원작 기준 핵심만 정리한 것으로, **콘티 반영 전 원작·IP 가이드 대조 필수.**

| 캐릭터 | 역할 | 핵심 설정 | 팬이 반응하는 지점 | 주의할 표현 |
|---|---|---|---|---|
| **멜리오다스** | 기사단장 · 분노의 죄 | 소년 외형, 3,000살 이상. 마신족 | 가벼운 태도 ↔ 진심일 때의 압도적 격차 | 단순 개그 캐릭터로만 소비하면 안 됨 |
| **엘리자베스** | 리오네스 제3왕녀 | 영겁의 윤회로 환생 반복 | 멜리오다스와의 관계, 반복되는 비극 | **관계 각색 절대 금지** — 이 IP 최대 지뢰 |
| 그 외 대죄 멤버 6인 | 기사단 | 각자 다른 죄와 종족 | 종족·체구·능력의 다양성 | 개별 설정 `공식 확인 필요` |

### 캐릭터 관계 요약
- **멜리오다스 ↔ 엘리자베스**: 영겁의 윤회로 얽힌 관계. IP의 정서적 심장
- **일곱 개의 대죄 멤버 간**: 죄인으로 낙인찍혀 흩어졌다가 재집결하는 동료 서사
- **대죄 ↔ 성기사**: 초기 대립 구도

### 대표 캐릭터 요약
> **멜리오다스**는 겉으로는 장난스럽고 가벼운 주점 주인이지만, 실제로는 **3,000년의 무게와 반복되는 상실**을 짊어진 인물이다. 팬들은 주로 **그 낙차가 드러나는 순간**에 반응한다.

## 4. 실제 플레이 경험

### 핵심 플레이 루프
> 유저는 `스토리 진행 → 애니메이션 컷신 감상 → 스킬 카드 조합 전투 → 캐릭터 획득·강화 → 다음 챕터 또는 이벤트 콘텐츠`를 반복한다.

**비게임 출신을 위한 해설**
- **스킬 카드 배틀**: 매 턴 손에 들어온 카드 중 골라 쓰는 방식. **같은 등급의 같은 카드를 나란히 놓으면 더 강한 카드로 합쳐진다(랭크업).** 카드를 모아 '필살기'로 마무리하는 것이 이 게임 전투의 핵심 쾌감.
- 즉, **액션 게임이 아니라 전략 게임**이다. 광고에서 액션 RPG처럼 보이게 하면 장르 오인이 발생한다.

### 주요 콘텐츠
| 콘텐츠 | 성격 |
|---|---|
| **섬멸전** | 친구와 실시간 협력 전투 |
| **마수전** | 층을 오를수록 강해지는 도전 콘텐츠 |
| **마신왕전** | 주어진 조건에 맞는 스킬을 써야 하는 퍼즐형 도전 |
| 콜라보 이벤트 | 타 IP 캐릭터 한정 등장 (Re:제로·가치아쿠타 등) |

### 주요 재미 요소
| 재미 요소 | 유저가 느끼는 감정 | 광고에서 보여줄 장면 |
|---|---|---|
| 서사 | 원작을 애니메이션 품질로 다시 본다 | 컷신 클립 그 자체 |
| 전략 | 카드가 맞아떨어져 필살기가 터질 때의 쾌감 | 카드 합성 → 필살기 연출 |
| 수집 | 좋아하는 캐릭터를 얻는 만족 | SSR 등장 연출 |
| 협동 | 친구와 함께 보스를 잡는 소속감 | 섬멸전 협력 장면 |

### 대표 플레이 장면
- **가장 쾌감**: 카드 랭크업이 연달아 성공해 필살기로 마무리하는 턴
- **UI 없이 전달 가능한 장면**: 애니메이션 컷신. **이 게임은 컷신 자체가 최고의 광고 소재다**

- **관심 요소**: 좋아하는 콜라보 캐릭터를 얻는 것
- **클릭하는 메시지**: "○○가 참전한다" — **콜라보 캐릭터를 전면에**

### 유저의 핵심 욕망 (우선순위)
1. **좋아하는 캐릭터와 관계를 맺는 욕망** — 이 타이틀의 1순위. 수집형 IP RPG의 본질
2. **희귀한 것을 소유하려는 욕망** — 콜라보 한정 캐릭터
3. **서사에 몰입하려는 욕망** — 원작 재현 컷신
4. **동료와 협력하려는 욕망** — 섬멸전·길드

## 6. 팬덤과 반응 포인트

### 팬이 좋아하는 것
1. **애니메이션 품질의 컷신** — 이 게임의 최대 강점이자 7년을 버틴 이유
2. **원작 재현도** — 원작자 검수를 거친 캐릭터 구현
3. **대형 콜라보** — 타 IP 캐릭터 참전이 정기적 축제가 된다
4. **캐릭터 볼륨** — 7년간 누적된 방대한 캐릭터 풀
5. **후한 이벤트 보상** — 777 릴레이 캠페인 등 장기 캠페인

### 팬이 민감하게 반응하는 것
1. **멜리오다스–엘리자베스 관계 왜곡** — 이 IP 최대 지뢰
2. **캐릭터 성격 각색** — 원작자 검수 IP라는 점을 팬이 알고 있어 기준이 높다
3. **기존 캐릭터의 성능 도태** — 애착 캐릭터가 쓸모없어질 때
4. **콜라보 캐릭터 성능 편중** — 본편 캐릭터 소외 논란
5. **신규 혜택 편중** — 7년차 유저의 상대적 박탈감

### 팬덤의 대표 언어
- **"7DS"** — 국제 통용 약칭
- **"필살"** — 카드 조합의 최종 기술. 이 게임 고유 용어
- **"섬멸전"** — 대표 협력 콘텐츠명
- **"랭크업"** — 같은 카드 합치기

### 기존 팬에게 중요한 원형
- **멜리오다스와 엘리자베스의 관계**, 그리고 영겁의 윤회 설정
- **각 대죄 멤버의 문장과 상징색** — 캐릭터 식별의 핵심
- **밝고 채도 높은 소년만화 톤** — 다크화 금지
- **일곱 개의 대죄는 '죄인으로 불렸으나 실은 지키는 자들'** — 낙인의 역전 구조

## 7. 경쟁 및 비교 구도

### ⚠️ 최우선 구분 대상 — 자매작 「일곱 개의 대죄: Origin」

**같은 IP, 같은 개발사(넷마블F&C), 다른 게임이다.** 제작자가 가장 혼동하기 쉬운 조합이므로 반드시 분리한다.

|---|---|---|

## 8. 크리에이티브 DNA

### 비주얼 DNA
| 항목 | 핵심 특징 |
|---|---|
| 세계관 톤 | **밝고 따뜻한 소년만화 판타지.** 다크 판타지 아님 |
| 대표 색상 | 채도 높은 원색. 캐릭터별 상징색 뚜렷 |
| 조명 | 밝은 자연광. 그림자 얕음 |
| 카메라 | 애니메이션 문법 — 정면 바스트샷, 대사 장면 중심 |
| 액션 속도 | 카드 연출의 리듬. 정지 → 합성 → 필살기 폭발 |
| 캐릭터 연출 | 셀 애니 스타일 렌더링. 표정 연기 중요 |
| 이펙트 | 원색 계열 마법·검기. 문장(紋章) 발광 |
| 사운드 이미지 | 오케스트라 + 애니메이션 주제가 톤 |
| 감정 온도 | 뜨겁고 유쾌함. 동료애 |

### 브랜드 보이스
- **말투**: 대사체. 캐릭터가 말하는 형식
- **속도감**: 빠르고 경쾌
- **자주 쓸 어휘**: 동료, 죄, 문장, 필살, 브리타니아, 참전
- **피해야 할 어휘**: 절망, 어둠, 냉혹 (톤 불일치) / 지나친 성인 지향 표현
- **유머 허용 범위**: **높음 (40% 이상).** 원작 자체가 유머를 품고 있다 — 사내 타이틀 중 유머 허용치가 가장 높은 편

### 한 문장 카피 공식
1. `__________가 참전한다.` (콜라보 구조 — 이 타이틀 최다 활용)
2. `죄인이라 불렸다. 그러나 __________.`
3. `__________장, 이제 __________한다.` (카드 전투 구조)

## 10. AI 크리에이티브 활용 방향

| 세계관 확장 장면 | **중** | 대륙 지도, 지역 소개 이미지 | 원작에 없는 설정 창작은 IP 승인 필요 |
| 오브젝트 | **중** | 대죄 문장, 무기 실루엣 | 문장 형태 오류 위험 — 공식 아트 대조 필수 |
| 밈·숏폼 | **중** | 캐릭터 대사 밈 (원작 유머 톤 활용) | 성격 왜곡 주의 |
| 캐릭터 중심 이미지 | **하** | — | **원작 캐릭터 생성 비권장.** 얼굴·비율·문장 오류를 팬이 즉시 식별 |
| 실사화 | **하** | — | IP 톤과 정면 충돌. 금지 |
| 전투 영상 | **하** | — | 카드 UI가 핵심이라 AI 생성 부적합. 인게임 캡처 사용 |

### AI 제작 시 고정해야 할 요소
- **캐릭터 얼굴·비율·상징색** — 공식 아트 외 생성 금지 (`내부 자료 필요`)
- **일곱 대죄의 문장(짐승 문양)** — 형태 오류 빈발 영역
- **밝은 채도의 애니메이션 톤**
- **중세 판타지 시대성** — 현대·SF 요소 금지

### AI 제작 시 변형 가능한 요소

## 11. 아이데이션 스타터

### 1. 캐릭터 렌즈
**A. "죄의 문장"** — 일곱 개의 문장을 하나씩 보여주고 마지막에 전원 집결. `요소` 대죄 문장·상징색 / `반응` 캐릭터 식별의 쾌감 / `포맷` 15초 / `AI` 문장 오브젝트 (대조 필수)

**B. "3,000년의 낙차"** — 장난스러운 멜리오다스와 진심일 때의 멜리오다스를 교차. `반응` 팬이 가장 사랑하는 캐릭터성 / `포맷` 15초 / `AI` 비권장 — 인게임 컷신 활용

### 2. 세계관 렌즈
**A. "브리타니아 여행기"** — 대륙 각 지역을 여행 엽서처럼. `AI` 배경 생성 (적합도 상) / `포맷` 이미지 시리즈

**B. "다섯 종족"** — 인간·여신족·마신족·요정족·거인족을 체구 대비로 시각화. `반응` 세계관 이해를 한 컷에 / `포맷` 이미지·15초

### 3. 플레이 렌즈
**A. "세 장이면 끝난다"** — 카드 세 장이 합쳐지며 필살기로 이어지는 리듬만 반복. `반응` 장르를 3초에 설명 / `포맷` 6초 / `AI` 낮음 — 인게임 캡처

**B. "그 컷신, 다시"** — 원작 명장면이 게임 컷신으로 구현된 것을 나란히. `반응` 재현도 소구 / `포맷` 15초 / `리스크` 원작 영상 사용권 확인 필요

### 4. 유저 욕망 렌즈
**A. "○○가 참전한다"** — 콜라보 발표 포맷의 정형화. 매 콜라보마다 재사용 가능한 템플릿. `반응` 타 IP 팬 유입 / `포맷` 6초 / `리스크` 콜라보사 IP 가이드 준수

**B. "7년치 동료"** — 누적된 캐릭터 풀 전체를 스크롤로 보여준다. `반응` 볼륨 압도 + 기존 유저 자부심 / `포맷` 15초

### 5. 반전 렌즈
**A. "수배서"** — 대죄 멤버들의 수배 전단으로 시작해, 실제로는 왕국을 지킨 자들이었음을 뒤집는다. `반응` IP 근본 서사 / `포맷` 30초

**B. "주점의 하루"** — 전투 없이 주점에서의 일상만. 마지막에 문이 열리며 사건. `반응` 캐릭터 애착 / `포맷` 30초

### 6. AI 활용 렌즈
**A. "브리타니아 지도"** — 대륙 지도를 고문서풍 일러스트로. `AI` 일러스트 (적합) / `리스크` 실제 지역명 대조

**B. "일곱 개의 문장 배지"** — 문장 디자인을 굿즈처럼 배열한 이미지 시리즈. `AI` 오브젝트 / `리스크` 문장 형태 정확도 — 공식 아트 필수
