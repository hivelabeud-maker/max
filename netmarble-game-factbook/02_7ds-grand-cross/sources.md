## 검증 처리 원칙

### 원작 정보와 게임 정보의 분리
본 팩트북 §2(세계관)·§3(캐릭터)은 **원작 만화 설정**이고, §4(플레이 경험)·§7(비교)은 **게임 고유 정보**다. 두 영역을 혼동하지 않도록 문서 내에서 구분해 기술했다.
원작 설정의 1차 출처가 위키(비공식)이므로, **캐릭터 표현이 들어가는 크리에이티브는 반드시 사내 IP 가이드 및 원작사 자료로 재확인**해야 한다.

### 채택하지 않은 정보
| 항목 | 사유 |
|---|---|
| 개별 캐릭터 성능·티어 | 패치 변동. 크리에이티브 판단과 무관 |
| 유저 연령·성별 구성비 | 실측 자료 없음 → 추정 표기 + `내부 자료 필요` |
| 일곱 대죄 멤버 6인의 개별 설정 | 위키 단독 출처이며 분량이 큼 → `공식 확인 필요`로 표기하고 미기술 |
| 이동 주점 '보아 햇' 등 세부 지명 | 원작 영역, 게임 내 구현 여부 미확인 → `공식 확인 필요` |
| 구체적 매출·다운로드의 시점별 수치 | 시점 명시 가능한 것만 인용(10억 달러 / 7,777만) |

### 미해결 확인 항목
1. **일곱 대죄 멤버 개별 설정** — 각 멤버의 죄·종족·상징색·무기. 캐릭터 크리에이티브에 필수 → 공식 자료 확보 필요
2. **게임 내 구현된 지역·거점** — 원작 지명 중 게임에 실제 등장하는 범위
3. **콜라보사별 IP 표현 제약** — Re:제로·가치아쿠타 등 각 원작사의 가이드
4. **원작 애니메이션 영상 사용권** — "원작 vs 게임 컷신 비교" 아이디어 실행 가부
5. **7년차 유저 구성** — 잔류율, 신규 유입 경로(콜라보 비중) → `내부 자료 필요`
