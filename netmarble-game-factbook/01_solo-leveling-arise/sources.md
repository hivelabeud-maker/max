## 검증 처리 원칙

### 확정된 사항
- **「어라이즈」와 「어라이즈 오버드라이브」는 별개 제품**이다. 오버드라이브는 콘솔 싱글 패키지 게임. 본 팩트북 대상은 **모바일·PC 서비스 중인 「어라이즈」**. (검증표 §6 질문 1번 해소)

### 채택하지 않은 정보
| 항목 | 사유 |
|---|---|
| 유저 연령·성별 구성비 | 공개 실측 자료 없음 → 추정으로만 기술하고 `내부 자료 필요` 표기 |
| 캐릭터 티어표·성능 순위 | 패치로 상시 변동, 블로그 출처. 크리에이티브 판단 근거로 부적합 |
| 구체적 과금 금액·수익 구조 | 시점·지역별 상이. 정성 표현으로만 기술 |
| 성진우·차해인의 관계 묘사 | 원작 영역이며 각색 리스크가 큼 → "원작 대조 필수"로만 처리 |

### 미해결 확인 항목
1. **개발사** — 넷마블네오로 알려져 있으나 공식 표기 재확인 필요
2. **한세미 등 헌터의 역할·속성** — 미확인
3. **원작사 IP 가이드** — 캐릭터 표현 허용 범위. AI 제작 가부 판단에 필수 → `내부 자료 필요`
4. **콘솔·Steam 버전 서비스 현황** — 2025 하반기 출시 이후 운영 상태 미확인

### 기술적 제약 메모
넷마블 공식 도메인과 나무위키는 자동 크롤링 차단(403). 검색 색인 요약과 이를 인용한 매체 기사로 교차 검증했다. **원작 IP 관련 표현 기준은 반드시 사내 IP 가이드 원문으로 확인할 것** — 본 문서의 원작 관련 기술은 참고용이다.
