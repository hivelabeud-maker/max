## 검증 처리 원칙

### 원작 정보와 게임 정보의 분리
- **원작(SNK) 영역**: 「THE KING OF FIGHTERS」 시리즈 캐릭터, 대회 형식(3인 1팀), 필살기와 캐릭터 디자인
- **게임 고유 영역**: 방치형 구조(조작 없음), 5대5 팀 전투로의 확장, 네오지오 포켓 「KOF R-2」 계열 도트 재해석

핵심 차이는 **원작이 조작하는 격투게임인 반면 이 게임은 조작이 없다**는 점이다. 같은 IP지만 경험이 완전히 다르므로 §4·§7·§9에 반복해 명시했다.

### 채택하지 않은 정보
| 항목 | 사유 |
|---|---|
| **개별 파이터 이름·등급·성능** | 캐릭터 티어표는 패치로 상시 변동. 또한 **쿠사나기 쿄·야가미 이오리 등 간판 캐릭터의 게임 내 구현 여부를 1차 출처로 확인하지 못함** → 이름을 광고에 쓰기 전 확인 필요로 표기 |
| 게임 고유 서사 구조 | 공식 출처 미확보 → `공식 확인 필요`. 방치형 특성상 서사 비중이 낮아 크리에이티브를 서사에 걸지 말 것으로 권고 |
| 콘텐츠 규모(스테이지 12,600개 등) | 출시 시점 매체 리뷰 기준. 현행 수치 변동 가능 → `공식 확인 필요` 표기 |
| 유저 연령·성별 구성비 | 실측 자료 없음 → 추정 표기 + `내부 자료 필요` |
| 매출 성과 | 인기(다운로드) 순위만 확인. 매출 순위는 미확인이므로 기술하지 않음 |
| 권역별 성과 | "글로벌에서도 좋은 반응"이라는 정성 언급만 확인. KOF IP는 중화권·중남미 팬덤이 두터운 것으로 알려져 있으나 **본 게임의 권역별 데이터는 미확인** → `내부 자료 필요` |

### 상충 정보 처리
평가가 뚜렷하게 갈린다. 매체 리뷰와 인기 순위는 긍정적이고, 위키 평가 문서는 "다수가 실패작으로 평가"라고 기술한다.
본 팩트북은 **양쪽을 모두 기술**하고, 크리에이티브 판단으로 **"게임성을 과장하지 말고 캐릭터 수집과 레트로 비주얼로 소구할 것"**을 권고했다(§4·§9).

### 기술적 제약 메모
넷마블 공식 도메인과 나무위키는 자동 크롤링 차단(403). 검색 색인 요약 및 매체 기사로 교차 검증했다. **도트 그래픽의 출처(네오지오 포켓 「KOF R-2」)는 넷마블 보도자료가 1차 근거**이며, 캐릭터 관련 사항은 반드시 사내 IP 가이드로 확인할 것.
